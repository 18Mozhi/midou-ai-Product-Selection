# 选品库商品卡片层级重排

2026-10-18重新查看已登录的Ecom168监控概览和选品库、FindNiche公开商品列表、趋品AI公开工作台示意。参考入口分别为https://www.ecom168.com/monitoring-center/overview、https://www.ecom168.com/selection/library、https://findniche.com/zh/shopify-product、https://qupinai.com/。只借鉴分区、图片优先、价格层级和紧凑摘要；参考站营销数字与示意数据没有进入本项目商品资料。

商品卡片改为图片区来源标记、独立ASIN/待确认身份、两行标题及单行次要信息，再展示原始资料和底部决策摘要。ASIN与次要信息保留完整文本及原生悬停提示。标题使用不低于现有正文设置的字号，真实售价使用18–22px与正文设置的较大值；未知售价保留未采集样式，不显示0或估价。卡片改为10px圆角，结果区去掉额外顶部留白，使用实色分区。

缺少primary_product时也展示原合同中的四项位置（售价、评分/评价、公开购买提示、类目排名），各项明确未采集，并保留商品资料待采集。广告标记、观测时间、公开下限提示、证据、风险、评分、竞品、货源和利润状态均沿用已有值；没有把公开提示当精确销量或补广告私域数据。资料区起点一致，摘要保留两列并靠卡片底部对齐；旧全局dl margin重置曾覆盖自动边距，已用商品卡片范围的选择器修正。删除了不再适用的p:first-child旧规则。

## 验证与交付

桌面1280px与移动390px使用实际Vue的10项受控界面检查通过：图卡/列表、路由、来源身份、图片失败/未采集区分、真实资料及未知占位、价格至少18px、资料与决策区对齐、20商品首屏长标题、44px选择框和无横向溢出。四张原有首屏基线按新布局更新并查看；它们是测试夹具，不代表真实商品或采集验收。中途窄卡片ASIN换行和全局边距覆盖的失败均已修正，未放宽对齐断言。

仅更改前端呈现，无新增路由、API字段、数据库、依赖、权限或环境参数。服务端采集、评分和找货继续使用既有合同，OpenAPI仅注记未知字段的展示语义。通过既有deploy-baota.py本地构建发布，网站静态文件替换后刷新浏览器即可；本项无需配置调节。正式部署脚本仍负责既有宝塔服务切换。上线后另用真实商品验证并保存截图，不能用受控界面检查替代整条流程或全站UI验收。
