# 采集诊断目录：桌面处理说明入口

## 根因与最小修复

`/platform-admin/providers/adapters` 的处理说明原已在详情抽屉内，但桌面表格没有使用
`ResponsiveDataView` 暴露的 `show` 插槽参数，只有手机卡片能打开抽屉。
这让Windows桌面用户只能看到暂停摘要，无法阅读验证码、登录、限流或网络异常的操作说明。

`ProviderAdapterCenter.vue` 现在接收原 `show`，在原操作列增加“查看详情”按钮。
它仅选择已有行并打开原抽屉，不执行健康检查、外部采集、来源启停或恢复。
同一页其他来源也能查看原详情，既有健康检查按钮与禁用条件不变。

## 如何使用

打开“采集诊断目录”，在对应来源行点击“查看详情”（也可Tab聚焦后按Enter）。
阅读“健康探针”下原有原因与指引：

- 明确验证码：按已有链接打开星星采集节点管理，由你在当前会话完成验证，不自动解题。
- 明确会话失效：按已有指引重新登录；不把验证码误认为登录过期。
- 限流：等待解除，不反复检查或重登。
- 网络或未知：不猜登录状态，不据此重置会话。
- 原恢复门禁已经通过：仅指向采集调度的审计恢复入口，不自动解除熔断。

关闭按钮或Escape关闭抽屉并返回原按钮焦点；手机沿用原“查看详情”卡片。
这次不修改任何原因判断、节点地址、权限、健康API、配置、数据库或采集运行模块。
没有新增环境变量、接口字段、依赖或调节项；OpenAPI和env.example无需变更。
