# 选品库当前主品事实读取性能

## 真实问题和定位

2026-10-19 Chrome真实登录访问/opportunities?view=all，实际/api/v1/opportunities响应头耗时34484.845ms；规则、成员选项及费用规则响应约51–59ms，不是这些附属读取导致主要等待。MySQL5.7只读复现：总数查询2ms，20行商品事实查询超过5秒上限。拆分同一分页查询，主品身份约1894ms、关联当前事实超过5000ms、独立详情约1725ms。自己的Amazon记录中同一record_key有530–534个历史版本、1个active版本。

## 实现范围

仅改MySqlOpportunityRepository.list的行投影：当前组织/工作区的active归一化版本各自经独立有界派生表物化，使用已有idx_normalized_scope_status；种子记录仍要求active或superseded、原证据、原record_key、provider、组织、工作区及ASIN相符。分页先限定20行，主品身份算一次并复用到候选、竞争门、计数与main_asin输出。旧价格/评价/公开销量下限/赞助/排名的选择和最新真实详情优先规则保留，不把旧版本当新事实。

外层关联事实的作用域参数在前，内层主品身份作用域随后，原WHERE/筛选/分页参数最后；两份作用域均由同一已授权输入绑定，不拼接用户值。MySQL5.7 LIMIT防止派生合并、保留原排序。原总数及筛选语义不变；本次不声称所有筛选条件的统计查询均已优化。

不改get详情、采纳/决定/批量写入、归属、五质量门、评分、利润、完成标准、原始字段或缺失处理。无数据库迁移、新索引、新依赖、API字段、配置项、缓存期限或前端/Python/插件合同变化。不新增缓存事实；每次仍读取当前数据库。config/schema.json和真实.env无需更改。
