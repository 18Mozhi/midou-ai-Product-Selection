# 米兜智能选品：参考图与读取性能调整

## 原因与影响范围

- 工作台 automaticSelection 的四个独立查询串行；改为同时发起，仍使用同一测量时点、原 SQL/租户条件与统计口径。
- 选品库五个视图共用 MySqlOpportunityRepository.list；总数与当前页串行，改为并行；保留分页排序、推荐门、主品证据与价格查询。
- 1688 已保存对比使用 N+1 查询；改为一次批量读取同范围报价，不过滤历史报价。报价结果顺序沿用数据库读取顺序，不承诺未定义的排序。
- 情报首屏原本自动选择第一项并等待详情；取消自动选择。只有显式 topic 深链或点击才读取详情，关闭移除 topic，刷新不暗中打开。
- 情报列表与找货列表原本没有图片投影。情报每页一次批量读取最新 signal 与精确绑定的 normalized record；找货直接复用同任务/同范围原 1688 图搜 target 的 Amazon 参考图，不重新扫描所有主品详情。缺失保持 null，不伪造图片或报价。

## 对应需求

1. 本地消除读取串行/N+1；未改变采集并发、来源审批、冷却、风控、重试、质量门；真实采集提速仍需线上同条件测量。
   2–3. 用户可见主壳层、账号入口、文档标题改为米兜智能选品；使用用户 JPG 原始字节，未 AI 重绘。内部 scoutops 包/协议/生产目录不改名。
2. 移除情报、找货、选品库的第二条页面级路径，只保留壳层顶部面包屑。
   5–6. 情报列表显示图片、语言、来源、状态、信号、可信度及新鲜度。图片失败后尝试同来源 origin/favicon.ico，再失败显示中性本地图标；不调用第三方 favicon 服务。默认详情关闭，点击打开，桌面/手机均可关闭。
3. 主壳层 220px 导航、24px 页面标题、13–14px 正文、16–22px 页面间距；保留密度偏好与手机触摸区域。
4. 找货记录与详情显示同任务 Amazon 参考图；该图是提交时参考而非新的实时商品事实。
5. 外观偏好嵌入 /me?section=appearance，旧 /settings/theme 兼容跳转；移除 App 中独立页面入口，ThemeStudio 仅作为原偏好编辑组件复用，保持保存/冲突/权限处理。
6. 通知中心采用摘要条、分组筛选、独立消息行和线性图标；不改变已读、工作流、通知偏好或 SSE。
7. 依照九张参考图调整共用导航、卡片、选品工作台快捷入口、情报、选品库、供应链、组织/平台容器、个人中心与通知中心。Lucide 静态 SVG 来自上游当次 main commit，保留 ISC 授权，不新增依赖。不是已经通过逐图 95% 相似度验收。

## 使用与发布边界

- 进入情报列表点击一行打开详情，选择“关闭详情”回到完整列表。
- 个人中心 → 外观偏好可即时预览并保存主题；密度沿用现有本地会话行为，不新增服务端持久化契约。
- 无新增 env/配置开关/依赖/数据库迁移。API 仅增加可空只读图片/来源字段，OpenAPI 与 feature map 同步。
- 本次只本地实现与验证，未部署。以后发布需包含 frontend 与 backend，后端读取优化须经项目正式部署后由宝塔重启 Node 才生效；Python/AI 节点无需改动或重启。
- 本地 fixture 不证明来源可用、真实采集吞吐量、生产响应耗时或九页 95% 视觉还原。保留待真实验收事项，不降低门禁。
