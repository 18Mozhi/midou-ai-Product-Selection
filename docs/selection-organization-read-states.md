# 组织后台读取状态重制

按全站UI与布局重制要求，将组织后台的加载、首次读取失败及保留旧快照的刷新失败统一为全宽、紧凑、使用既有语义颜色的工作区状态。移除旧装饰符号、桌面遗留提示和重复加载样式；首次500/429失败在桌面和移动端均使用同一恢复面板，不再分成两套界面。

## 行为边界

父组件及首次失败组件的脚本、事件和模型绑定保持原样。请求追踪展开、原GET重试、会话失效、权限拒绝、请求顺序以及刷新失败时保留旧数据继续遵循原合同。后台刷新失败不增加新的局部重试动作。

没有新增API、环境变量、配置、依赖、数据库字段或权限；OpenAPI、环境示例、后端、Worker和Python消费方不适用。六个历史截图CLI先检查独占输出目录，避免旧预览锚点遮住禁止覆盖检查；默认源检查保持严格，旧截图、审批与捕获哈希未修改。旧限流对比测试明确读取历史输入，不作为新UI验收。
