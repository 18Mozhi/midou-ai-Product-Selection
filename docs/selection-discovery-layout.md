## 依据与改变

2026-10-19 依据已登录 Ecom168 的集中操作和克制分区，以及生产搜索弹窗实际截图继续重制。旧弹窗包含大蓝侧栏、GLOBAL SEARCH 装饰标题、固定 520px 分栏，空态背景还误用文字色。旧截图见本次前一发布回执中的 task-retirement-search-options-production.png，不能当作重制后验收。

改为顶部组织/工作区摘要、关键词与搜索按钮同行、类型/状态/负责人集中筛选、下方全宽结果。手机筛选为两列加全宽负责人，弹窗内部滚动，头部关闭和底部入口保留。去掉旧英文装饰、重复的会话范围说明和旧任务占位文案；负责人提示为仅机会可用。

删除 discovery-c-tokens.css 及导入，直接采用已有 --so-* 语义颜色。空态文字与面板背景分别使用文字和面板色，不再生成同色灰条。仅此弹窗取消背景模糊，不改变其他弹窗样式。旧左右布局规则直接替换，不追加一层兼容覆盖。

## 合同边界

脚本的请求、2–100 字符校验、limit=10、类型/状态/负责人参数、范围隔离、并发读取归属、取消、错误/权限/登录状态及焦点/Escape/返回处理保留。三个搜索类型沿用上一轮真实 API 合同：机会、证据、采集任务，不恢复业务任务筛选或快捷创建。旧共享 E2E 中的业务任务模拟结果改为真实合同允许的机会类型，导航及同路由测试继续执行。

不新增接口字段、API、持久化数据、依赖或环境变量；后端、Worker、Python、OpenAPI 和 env.example 无对应结构变更。Feature Map 同步前端源文件及测试。
