# 选品及后台共用状态面板重制

## 范围与依据

用户要求重做全部界面，主要借鉴 Ecom168 的工作区和商品列表密度。2026-10-18 实际检查生产选品库后，商品图卡已采用紧凑工作区，但 `UiStatePanel` 共用基础样式仍使用 390px 最小高度、24px 圆角、大阴影、27–38px 标题和渐变主按钮；手机端另有 420px 高度覆盖。

本次直接替换原始基础规则，不再叠加另一套主题。状态容器全宽、最小高度 220px、4px 圆角；标题 16px、图标 36px，主按钮使用实色且可点击高度不少于 44px。现有 compact 属性对应 160px 紧凑面板。关联编号区域自动换列并允许长编号换行。

加载骨架改为小型实色条和透明度脉冲；保留 reduced-motion 下停止动画。删除旧渐变扫描动画和未使用的段落装饰规则。

## 保留的合同

- 八种状态、文案、ARIA、错误编号脱敏与显示均保持原状。
- 主次操作、刷新、登录跳转、权限判断、组织隔离及 HTTP 映射保持原状。
- 来源适配器专属状态布局仍由页面样式管理，本次不宣称这些覆盖已全部清理。
- 未变更 API、OpenAPI、数据库、Python、环境变量、配置、费用及评分规则。

## 验证与使用

`tests/e2e/m04-02-opportunities.spec.ts` 在桌面和 390px 下验证空结果及读取错误的实际 Vue 页面：紧凑高度、字号、实色按钮、触控尺寸、无横向溢出、重试确实发起新请求；错误编号仍可见。既有空结果不允许手工创建的检查保留。

定向命令：`npx playwright test tests/e2e/m04-02-opportunities.spec.ts --grep "catalogue (empty|error) state|empty all-products view"`。端口按现有 Playwright 配置指定，复用本地依赖。

这是静态样式更新，无新增调节项。正式发布需重建并上传前端；本地 Vite 支持热更新，后端没有额外配置或重启要求。生产发布及真实整链日百品验收分开记录。
