# Glass Atlas 视觉更新 · 2026-10-16

用户要求以现代毛玻璃、动态加载和新的页面布局替换旧蓝白页面及 Signal Ledger 外观。本次更新共享主题、身份入口、角色导航和页面材质，不调整业务规则。

## 使用与维护

- 顶栏主题菜单和原主题设置页仍可选择主题并沿用原保存、撤销、重读流程。兼容 ID `deep-ocean` / `aurora-purple` / `cloud-white` 分别显示为“雾林 / 暮砂 / 晨雾”，不迁移偏好数据。
- `apps/web/src/glass-atlas.css` 定义共享材质、圆角、导航、登录页和动效，`design/glass-atlas-tokens.css` 集中定义颜色与阴影。`design/*tokens.css` 将页面中性及强调色接到语义令牌；成功、警告、危险和深色背景上的文字保留独立语义。
- 调整透明度使用 `--glass-translucent`，不支持模糊时回退到 `--glass-surface`；阴影与边缘分别使用 `--glass-shadow`、`--glass-line`；调整强调色使用 `--glass-primary` / `--glass-primary-strong`（共享 `--so-*` 和页面别名均从独立 `--glass-*` 色板读取，避免旧页面反向覆盖产生循环）。不要改主题 ID 或另加持久化字段。
- 背景使用静态光晕，玻璃模糊限定顶栏、登录容器、导航浮层与上下文面板。无 backdrop-filter 支持时保留浅色表面；系统减少动态效果时停用新增动画。
- `ui/async-surface.ts` 在真实组件分包加载超过 120ms 后显示现有骨架屏，缓存命中无额外等待；分包失败提供安全的当前页面重载入口，不展示异常内部信息；不增加 API 重试、人工进度条或完成计时器。API 加载继续由原组件状态控制。若需调整骨架显现阈值，仅修改该文件的 `delay`；它不是 API 超时。
- 页面独立复制的旧壳层样式已移交共享壳层，平台概览的第二条蓝色轨道改为横向标题区；组织概览在 1100px 以下采用单列，避免 768/1024px 表单溢出。
- 桌面保留各角色独立权限导航，840px 以下沿用原生 dialog 抽屉和四入口加“更多”的底栏，内容保留底栏安全间距。登录表单保留原鉴权、安全设置和 MFA 分支。

## 验证与证据边界

先运行 `npm run typecheck:web`，再执行受影响身份、导航、主题、搜索和首页的双端 Playwright 回归及 `npm run build:web`、`npm run verify:frontend-budget`、`npm run verify:docs` 和格式检查。

旧截图反映旧设计，不得覆盖历史审核包的哈希或把历史批准提升为当前签收。行为回归可使用 `--ignore-snapshots` 跳过旧视觉快照，但必须独立检查新桌面/手机截图、无遮挡、44px 触控及减少动态效果；这不等于生产或真实账号验收。新设计仍需用户视觉评审。

## 运行交付

不新增环境变量、配置项、依赖、API 字段或数据库迁移；OpenAPI 仅备注客户端表现更新。开发 Vite 热更新即可，Node/Python 无需因本次改动重启。生产前端需本地构建，并按既有宝塔部署流程发布，不能仅刷新浏览器获得未发布的本地代码。本次不擅自部署。
