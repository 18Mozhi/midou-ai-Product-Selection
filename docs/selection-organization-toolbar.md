# 组织后台标题与操作栏重制

依据当前用户要求和已实际查看的 Ecom168 工作区，组织后台九个页面统一为紧凑白底标题与操作区，移除大蓝横幅和渐变背景。保留角色、成员、工作区、团队、审批、数据、令牌和审计的业务表单与操作。

## 实现

organization-admin.css 删除八套重复标题颜色/字号声明及八处手机标题覆盖，共 32 条旧规则；organization-audit.css 的独立灰底标题覆盖同时删除，审计页也使用共用标题；由一个共用标题区管理尺寸、换行、边框和文字层级，标题 22px、说明 13px。移除标题/表单/状态按钮的渐变底色，使用现有主题主色；组织资料卡的五像素装饰线改为普通边框。保留此前按内容区宽度 836px 切换组织资料单列的修复。

没有修改组件字段、权限、请求、数据结构、审计或保存逻辑，没有新增依赖和配置。浏览器用例检查九页标题、实际刷新按钮及桌面/390px 手机无横向溢出；原保存、回读失败、版本冲突与数据/令牌阅读回归保留。测试响应为本地夹具，不证明生产写入或全部后台视觉完成。

## 使用与发布

沿用 /org-admin 及其现有子路由。前端构建后通过现有宝塔脚本发布并刷新浏览器生效，本项无需额外 Node/Python 重启；无新调节参数。OpenAPI 和环境示例不涉及。当前未部署。九页新标题、真实刷新按钮、横向排列及窄屏检查在桌面/手机共 18 项通过；组织后台实际 Vue 视觉基线另 2 项通过并经目视检查。原资料保存、回读失败、冲突及数据/令牌阅读在桌面/手机共 14 项通过。最终移除手机的旧纵向标题覆盖，标题与刷新操作并排。新增用例只追加到既有文件，旧业务用例正文保持不变。Web 构建、静态分析、文档、包体预算及真实性检查通过；整体真实采集验收继续按发布核对文档推进。
