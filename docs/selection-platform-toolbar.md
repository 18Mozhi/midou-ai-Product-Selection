# 平台后台标题和工作区布局重制

按用户全站重制要求，沿用已实际查看的 Ecom168 紧凑电商工作区参考。九个实际 Vue 组件共用 PlatformPageHeader，覆盖平台概览、组织/用户/管理员、角色权限、数据、治理、内容、通知、状态、接口证据、日志和开放平台十四个主入口。

## 实现与边界

标题采用 22px、说明 13px，实色白底、细边框和简洁操作区；手机标题 20px，操作自动换行。交互控件保留至少 44px、键盘焦点、禁用与读取状态。刷新、创建组织、创建用户、通知草稿、权限比较、时间窗口、日志导出和组织筛选继续使用原绑定。

删除分散在旧组件和样式文件中的 255 个旧标题、操作栏或内容教学栏选择器分支，不再靠叠加覆盖保留旧渐变横幅。平台概览从旧侧栏网格改为完整宽度；内容页删除无操作的三步教学栏；治理标题放在目录和正文上方，正文仍保留原事实与版本目录。账号页采用对应业务标题。

没有修改 API、OpenAPI、DTO、数据库、权限、审计、Python、模型、环境变量或依赖；没有迁移或删除业务数据。上述生产者/消费者合同与本次纯前端布局无关，不新增字段。来源、采集和运维等剩余页面以及部分后台正文旧样式仍需后续重制，本项不代表全站完成。

## 验证与使用

本地测试运行实际 Vue，新增十四路由桌面/390px 手机、三种兼容主题 ID 的布局检查。该专项以故意失败的读取响应验证恢复状态，并非真实平台数据；原 M06 浏览器用例另覆盖成功读取、筛选、创建和权限比较。受影响源级及业务检查、视觉基线、Web 构建和交付门禁的最终结果记录在发布核对文档。

发现并修复账号汇总页的旧高优先级双列规则压过手机单列的问题；桌面规则使用精确的 p39-page-grid 类，现有窄屏规则可以正常生效。原创建组织、权限比较与筛选保存逻辑未改。

使用原 /platform-admin 路由及其子入口，无新增调节参数。本项只需本地构建前端，通过固定宝塔部署脚本替换静态资源并刷新浏览器；单独此项不需要 Node 或 Python 重启。整个选品目标分支另含 Worker/API 改动，整体发布仍须遵循对应重启说明。当前未部署，不作为真实持续采集或每日百品验收。
