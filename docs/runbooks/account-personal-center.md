# Personal Center in account mode

The verified account opens Personal Center without a stored organization or workspace session. Followed intelligence, personal decisions and assigned tasks retain their original IDs. A record appears only if the current native owner and sealed owner agree with that account; shared or unassigned records require the sealed primary owner. Historical decisions by other actors are not rewritten as personal actions of the new owner.

Theme preferences, version checks and audit use authenticated account identity. The account response has no legacy coordinates. The profile no longer displays organization or workspace fields. This does not change profile sign-in, credentials, theme choices or session expiry.

No new settings. Build preferences, API and frontend and verify the Personal Center, authorization and theme preference fixtures. Deploy via the approved BaoTa coordinator and check the signed-in account's existing profile and saved theme after release.
