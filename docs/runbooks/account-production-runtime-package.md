# 账号切换：正式运行包

在现有本地工作区先运行 `npm run build`，再运行 `python -B scripts/account-release-package.py --inspect`。该命令只核对构建输出、迁移清单和脚本依赖；不会生成正式包、连接服务器或发布。

内部打包接口只接受同一干净提交的本地和 `origin/main`，重新执行项目源检查和本地构建。它把前端、后端、采集器与 0197 迁移所需全部本地脚本依赖装入同一个包，在 `release.env` 写明 `ACCOUNT_SCOPE_MODE=retired` 和精确构建版本；此文件仅可在正向迁移验证后启用。包不包含备份、数据库内容、证据、受限配置或依赖缓存。归档重开时验证全部成员、构建版本、迁移计划和每项 SHA-256；无任何上传或停服入口。安装后须由宝塔启动新版 Node 和 Python，并验证账号归属与权限，不能拿本地归档检查代替上线验证。

验证：`python -B tests/unit/test_account_release_package.py`；22 个工作区构建通过，使用本地候选的临时归档复核 1,224 个文件的摘要后删除。当前工作树不干净，未生成可供实际发布的归档，未上传、停服或迁移。
