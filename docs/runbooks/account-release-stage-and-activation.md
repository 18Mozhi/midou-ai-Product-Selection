# 账号切换：候选包接收与新版启动

只允许协调发布程序在正式节点使用这三个内部步骤。接收模块要求上传文件位于受限 `config/account-upload-<SHA>.tar.gz`、私有普通文件、传输与清单 SHA-256 匹配；只在同目录创建本次临时候选，不覆盖现有候选。`runtime/tmp` 可被项目运行账号写入，不能作为本次受保护的候选落点。失败只清理本次创建的候选；整次发布结束由调用方清理上传体。
