# 账号迁移：竞品及原快照

账号模式按封存归属读取竞品；共享和未分配记录只对主账号可见，独占竞品留给原账号。快照和变更保留原 ID 及证据引用，来源证据须与同一竞品、快照或原任务精确对应。不合并重复竞品，不替换或重建历史快照。

启用／暂停仍核对原竞品和版本。新增监控规则的同一幂等键只允许完全相同的竞品、指标、方向和阈值重试，并重新核对原规则的实际归属；不符返回 409，不新增规则、事件或投递。本段变更不启用旧手工采集入口，不调整既有阈值、权限或数据。

正式库只读核对得到 4,448 条竞品、7,875 条快照、1 条监控规则，最新快照引用不匹配数为 0。本地验证账号模式读取、状态操作、规则重试和竞品迁移。仍随正式协调发布启用，本轮未写库或停服。
