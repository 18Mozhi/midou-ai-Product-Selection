# 账号迁移：任务历史与 Worker

账号工作记录显示原任务 ID、指派人、来源、评论和事件，账号归属不覆盖原指派人。读取和写入复核封存所有权、原任务版本与幂等键，不查询已退役的组织成员目录，不开放转派。普通审批继续使用原指定审批人。

正式账号 Worker 只在固定 MySQL 5.7 业务库、通过启动回执检查后启用账号任务投影。新账号采购投递使用现有事件名，按原报价、找货、证据和采集任务的所有权消费，重放不会生成第二条任务。未将旧事件类型扩为可执行。正式库只读核对两类采购任务投递当前均为空。

竞品复核任务的原事件和交付重放在账号结构下不读已删除的组织和工作区列。没有新增环境设置；正式切换需协调发布及宝塔重启新版 Node。测试使用本地模拟记录，不改写正式任务或发布。
