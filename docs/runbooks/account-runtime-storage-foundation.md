# 账号切换：运行时启动与数据访问基础

`ACCOUNT_SCOPE_MODE` 默认 `legacy`，不改变现行启动和配置指纹。只有正式协调发布完成迁移校验后才将 `retired` 写入受限 `release.env`，再由宝塔启动新版 Node；不要手动开启。浏览器不读取这一配置。启动门禁要求固定生产回环 MySQL 5.7 业务连接，并只读核对全部 121 个指定回执、版本 25 归属封存及已验证主账号、旧运行组织／工作区表已移出和无独立采集运行。主账号邮箱是原组织管理员审批位的配置身份，不取代选品经理和历史签署人。
