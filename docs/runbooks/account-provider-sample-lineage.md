# 账号模式：采集来源的解析样本

- 平台解析样本继续使用原浏览器作业、采集任务、子查询和证据 ID。切换后，候选记录必须能从原任务追溯到封存的账号归属；子查询和证据必须属于同一账号、任务和来源。
- 固定样本时，后端在事务内重新检查已完成的浏览器作业和同版本的有效截图与 DOM 证据，并比较存储快照的摘要。关联或快照变化时返回 409，请重新选取候选记录；不改原证据。平台权限和已有样本审批流程不变。
- 旧的组织／工作区即时刷新与来源任务重放请求不再能创建任务。在通过上游鉴权并到达存储层后，账号模式返回 `409 provider_source_legacy_scope_retired`；这不是将旧请求转换成其他账号的任务。平台样本的解析重放是独立接口，不受该限制。
- 不增加配置项。正式发布后随协调发布流程启动新版 Node API；不要单独重启旧版进程。验证应覆盖同账号原作业可固定、他人或不匹配的证据被拒绝、快照变化时无写入。
