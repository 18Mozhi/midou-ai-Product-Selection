# 账号迁移：找货、报价与证据引用

找货记录保留原任务、候选、证据和报价引用。拥有当前账号的候选和证据才可确认报价；旧版本不覆盖，对比仍引用原版本及顺序。原引用不是有效选品 ID、但能与原采集任务和请求追踪配对的历史记录仍可按原归属只读，不补造选品、重跑或采购。

账号模式创建或软删除找货记录时，采集任务的实际账号必须与封存归属一致；任一不符即拒绝且不写入。采购入队继续检查现行报价、最低起订量和原证据归属，成功入队不等于外部采购。没有新增配置或独立运行服务，随正式协调发布和新版 Worker 启动生效。

正式库只读计数：找货记录 1,552，供应商报价、比较和采购任务各为 0。报价非空、版本、证据及重放场景由本地定向测试覆盖，不能把测试当成真实非空报价验收。本阶段未停机或写库。
