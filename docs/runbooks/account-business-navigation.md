# Business navigation in account mode

The verified member starts in the selection library. Old home bookmarks redirect there; deleted organization and workspace pages remain unavailable. The same business surfaces open the account's selections, topic-grouped intelligence, quotes, competitor rules, notification history, tasks and approvals. Navigation does not grant approval: the existing server-side checks, current assignee and sealed primary slot still decide who can act.

The member shell can switch to the platform shell only when the account has actual platform role assignments. Platform account pages omit organization details and organization mutation controls; account-based UI does not query the old member global search. The personal shell does not show scope links while the guard is still loading.

No new setting. Build API and frontend and validate both legacy and account navigation against the same route catalog. Restart Node and install the frontend through the BaoTa coordinator. Post-release use a verified member and a separately authorized operator to check the retained routes; build and fixture results do not replace that acceptance.
