# M02-02 宝塔发布与回滚

## 发布

1. 本模块无新增数据库迁移或环境变量变更。构建并通过 M02-02 门禁后，按项目固定流程从本地运行 `python scripts/deploy-baota.py` 发布；不得在服务器 Git 拉取或构建。该固定部署器会按宝塔项目模型短暂停止并重启 Node、校验迁移白名单并检查服务；Worker 与 Python Crawler 不需要因本次 Vue 页面改动而重启。
2. 部署前确认工作树仅含本次归属明确的已提交变更；部署后核验 live/ready/version 与本次版本 SHA。不要新增面板外服务或虚构 SSO/邮件配置。
3. 手工抽查登录、注册、找回、验证链接、重置链接、组织/工作区选择与三步引导；同时检查桌面、390px、键盘和失败恢复。登录品牌入口高度不得低于 44px；390px 下辅助账号入口应为两列且每项仍不低于 44px。

## 故障定位

- 401 或链接失效：重新登录或重新申请单次链接；429：等待后重试；503/网络失败：在宝塔检查 Node API 与 MySQL/Redis 就绪状态。
- 无组织属于真实空状态；点击“创建并进入选品空间”必须由后端事务创建固定个人空间并选择会话，不得由前端生成示例数据。已有组织但没有活动工作区仍需管理员恢复或创建工作区。
- 向管理员提供页面显示的 `request_id`；不得提交密码、验证码、Cookie 或令牌。

## 回滚

回退须按部署记录确认的宝塔可用恢复路径恢复上一稳定版本并重新核验 live/ready/version；不得假设部署器提供 Web-only 原子回滚。数据库、API、Worker、Crawler 与历史审计不变，不执行 down 迁移，也不删除身份或租户数据。
