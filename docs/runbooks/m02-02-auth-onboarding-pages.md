# M02-02 宝塔发布与回滚

## 发布

1. 本模块无数据库迁移、环境变量或后端路由变更；构建并通过 M02-02 门禁后，仅在宝塔网站发布新的 Vue Web 静态资源。
2. Node API、Node Worker 与 Python Crawler 不需要重启。不要为视觉页面新增面板外服务或虚构 SSO/邮件配置。
3. 手工抽查登录、注册、找回、验证链接、重置链接、组织/工作区选择与三步引导；同时检查桌面、390px、键盘和失败恢复。登录品牌入口高度不得低于 44px；390px 下辅助账号入口应为两列且每项仍不低于 44px。

## 故障定位

- 401 或链接失效：重新登录或重新申请单次链接；429：等待后重试；503/网络失败：在宝塔检查 Node API 与 MySQL/Redis 就绪状态。
- 无组织/工作区属于真实空状态，需由管理员配置，不得在前端生成示例数据。
- 向管理员提供页面显示的 `request_id`；不得提交密码、验证码、Cookie 或令牌。

## 回滚

回退 Web 静态资源到上一提交并在宝塔重新发布即可。数据库、API、Worker、Crawler 与历史审计不变，不执行 down 迁移，也不删除身份或租户数据。
