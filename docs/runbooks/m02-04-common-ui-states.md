# M02-04 宝塔发布与回滚

## 发布

1. 本模块没有数据库迁移、API 路由、环境变量或后端进程变更。通过 M02-04 门禁后，仅通过宝塔网站发布新的 Vue Web 静态资源。
2. Node API、Node Worker 与 Python Crawler 均无需重启，不得为状态组件创建面板外服务。
3. 抽查 `/ui-states` 的八种状态、未知路径 404、高影响确认的勾选/短语校验、Escape 取消、桌面和 390px 布局。

## 故障定位

- 状态文案不符合实际 HTTP 结果时，先核对所属业务模块传入的状态；通用组件不访问 API，也不自行猜测权限。
- `request_id`/`trace_id` 未显示时，核对是否为空、超过 128 字符或包含不安全字符；不要放宽为任意文本。
- 弹窗无法确认时，检查影响确认框与确认短语；不得通过移除校验绕过高影响确认。

## 回滚

在宝塔网站回退 Web 静态资源到上一提交即可。无需重启后端或执行 down 迁移；没有数据库、队列、文件或审计数据需要删除。同步回退引用新组件的前端页面，避免组件合同不匹配。
