# 从市场情报进入关联选品

2026-10-19真实Chrome确认：市场情报详情已有来源证据，但没有进入关联选品的入口。真实持久化链中，opportunities.source_type=trend_topic与source_ref_id保存直接主题归属；trend-projection-persistence还将原情报的trend_signal保存到同组织、工作区的opportunity_evidence_links。只按标题搜索会混入其他商品，也会漏掉从普通情报发现的商品。

复用GET /api/v1/opportunities，新增可选查询参数source_topic_id，须是有效UUID。计数与当前页共用同一筛选：主题、选品及其证据链接、信号均须同组织和工作区；匹配直接主题归属或该主题已保存的trend_signal证据。不存在、跨工作区或只有同名标题的主题不返回记录。空值、非法UUID及数组不退回全库，而返回400。未提供该参数时原列表行为不变。原opportunity:read、会话派生范围、分页和未归档默认规则保留，无数据库结构或历史事实改写。

市场情报详情仅在当前成员已有opportunity:read时挂载“关联选品”，每页5条，selection_view=all包含低分、未推荐与利润未知记录，保留原主品身份、综合评分、竞品候选、货源候选与利润状态；不将候选数当作详细竞品或可用货源，不把关联记录当作完成产出。点击商品进入现有详情，from携带完整情报URL供返回。无关联时明确显示尚无记录，不声称后台正在发现。读取失败只影响此区，原情报证据继续显示；403/401清除该区数据，403不提供盲目重试。普通错误可局部重试并显示脱敏请求标识。翻页、主题/工作区变化及离开缓存页时取消旧请求，代次和上下文校验防止迟到响应覆盖；页数缩减时有界回到第一页。
