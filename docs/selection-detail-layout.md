# 选品详情布局重制

## 当前结构

本次依据用户明确要求，以商品资料和竞品分析为中心替换旧版“蓝色目录侧栏 + 十项编号目录”。同行参考与实际核对边界见 `docs/selection-core-rebuild.md`，当前实现使用既有 Vue 页面，不是概念图。

- 顶部商品资料区：主图、市场、类目、主品 ASIN 链接、来源、更新时间、综合评分、利润和证据状态。无主图与图片加载失败分别呈现，不用装饰图片代替商品证据；未评分显示破折号。
- 六个直接入口按结论、竞争、利润与成本、证据、风险、决策历史排列。桌面横向排列，手机三列换行；同一个导航 DOM 服务两种视口，删除旧桌面/手机双份目录和编号装饰。
- 市场、AI 辅助、业务血缘、经营复盘暂归“更多记录”。选择后菜单关闭；Escape 关闭并恢复键盘焦点。现存 URL 的 tab 参数和历史入口仍可读取。这只是减少主导航，尚未完成旧功能模块删除，不能称为全部精简完成。
- 结论先呈现评分明细，再呈现竞品与货源进度。评分维度以表格展示真实权重、输入分、加权分、证据数和缺失项，不在浏览器重新算分。增加 `market_demand`、`data_quality` 的中文名称，避免直接显示内部代码。
- 推荐判断不再重复商品头部的评分、证据、风险数字；保留五项质量门、采纳/观察/驳回、原因确认和只读权限。移除推荐头部的嵌套背景卡片，评分与进度使用分隔线组织。

## 保留与运行

API、数据库、评分规则、费用口径、权限、采集调度与后台不变，无新增依赖或环境变量。没有删除历史数据，也没有将旧业务面板已经删除作为交付结论。全站重制、旧模块清理、通用品类费用和每日百品验收继续由主重制目标推进。

本次仅前端静态包变化：本地构建后按固定宝塔部署脚本发布静态文件；浏览器刷新加载新资源。单独更新这些 Vue/CSS 不需要重启 Node 或 Python。本次未部署生产。
