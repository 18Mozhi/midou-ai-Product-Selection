# 自动商品渠道不再依赖手工监控关键词

## 真实问题与定位

用户要求连续采集、识别商品并自动进入后续分析。当前就绪检查已不要求监控订阅，但投影持久化仍仅允许命中监控关键词或有新闻主品选择结果的Amazon记录创建机会。旧线上c26e2b5也要求matchedRuleIds.length，直接商品渠道因此受手工关键词限制。

2026-10-17使用现有SSH凭据和product_scout业务账号执行MySQL5.7.44只读事务、回滚后退出：近24小时12254条投影成功、678个新主题、0个新机会；两个启用监控规则、一个暂停，规则匹配事件0。Amazon榜单归一化总16629条、近24小时新增11580条；eBay总1005条、近24小时新增674条。最新100条Amazon榜单记录经当前amazonAsin函数校验均有效，但仅20个不同ASIN，不能算100个品。完整投影状态另有历史745个bad-null死信、729个空结果，未改动或重放，未将其当成近期全部成功。

该证据说明采集与主题投影并未全部停止，旧关键词入口条件是当前代码中的实际阻断；并非所有下游问题已归因或解决。Amazon商品及1688仍禁用并登记旧解析器，新闻RSS仍待审批，新代码未部署。

## 改动

已有自动商品渠道中的真实Amazon商品，允许不命中手工监控规则直接进入原分析队列。渠道仍使用isAutomaticProductDiscoveryProvider的固定目录/类别规则，并明确排除1688来源；全部路径继续要求amazonAsin严格核对HTTPS、www.amazon.com、实际商品路径和字段一致性。普通新闻、未经过主品选择的Amazon搜索结果、供应商记录、频道主页或伪域名不因此成为主品。

监控规则的原匹配、订阅、提醒和显式规则搜索仍保留。原新闻分类、主品选择与证据链继续运行。机会按原主题/工作区去重，租约、事务、证据关联、自动评估与下游详情/竞品/1688排队保持；未改变跨机会ASIN归属，也未回放已完成的旧投影。

新候选保持insufficient_data，matched_rule_ids可以为空，不补造规则匹配、AI关联、评分、利润或完成事件。下游禁用时不创建其采集任务。仅入分析队列不代表达到推荐、5–10竞品、具体1688采购价或每日100个整链标准；原完成证明仍要求情报关联等事实，新入口不会绕过它。
