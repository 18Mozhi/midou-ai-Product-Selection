# 用户侧只保留选品与情报主流程

依据用户当前要求：自动获取情报、关联商品、Amazon 主品和竞品分析、评分、1688 找货、选品库是用户主流程；后台账号、组织、来源、采集和运维继续保留。

## 本轮界面与请求边界

- 市场情报只读取主题列表、详情和来源证据。保留关键词、市场、分类、状态、排序、分页、来源时间线、原文和手机详情返回。刷新按钮仅重新读取情报，不再发起来源采集写操作。
- 移除成员页面的关键词监控创建／启停、关注、主题合并拆分、相关性写入和质量工单表单。删除四个没有其他生产消费者的旧 Vue 组件及对应样式。管理能力不再因为成员本人同时拥有管理权限而混入用户页面。
- 不再读取监控规则或治理队列来决定是否显示情报；这些接口异常不应使已可读取的情报不可用。旧 rules／governance／followed 视图链接回到情报列表，保留主题和搜索筛选。
- 首页只读取既有 home-dashboard 摘要，保留5秒可见页刷新、授权失效清除缓存、今日完整链路数量与推荐清单。删除监控设置／恢复表单及混合事项侧栏；第四个统计入口显示已有的累计采纳数量，直接进入已采纳选品筛选。

## 保留与未改变

本轮不删除数据库记录、不暂停存量监控调度、不修改评分、推荐或每日100品验收规则。已有后台来源、采集管理、数据质量、账号、组织和运维页面，以及既有 API 权限、写入合同和审计均保留。前端移除入口不等于新增 API 访问限制；后台兼容接口的退役需另行核实消费者，不能据本轮宣称所有旧服务逻辑已删除。

没有新路由、API字段、环境变量、依赖、数据库迁移或Python输入。OpenAPI和环境示例无对应契约变更。正式宝塔发布前端后刷新生效；完整发布脚本仍按原流程统一管理已有服务，无新增生产服务。

## 验证口径

新增测试执行真实 Vue 脚本，验证只读请求、空／失败不造数据、工作区切换取消旧请求、旧链接回退、首页只读取摘要及授权过期清缓存。既有后端治理、监控和权限合同测试仍保留；UI断言同步到精简后的入口，不跳过后端功能验证。

上线后分别检查首页、情报列表、主题详情、来源原文链接、手机列表／详情返回和旧链接回退。截图与自然运行结果记录本地收据；未运行的完整视觉 E2E 不计作通过。Amazon详情访问和每天100个完整选品链仍需独立验收，本轮不能替代它们。
