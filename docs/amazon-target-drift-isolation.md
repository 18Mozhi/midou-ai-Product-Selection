# Amazon单目标解析失败与来源结构变化

## 生产依据

2026-10-18生产Amazon来源在一次source_changed后由版本11停用到12，155个后续情报搜索因停用被阻断；米兜默认工作区已有活动评分规则，但尚无主品选择。失败目标为Porsche 2035 supercar preview，当前对同一目标按现有公共采集策略重放返回HTTP200、16个可解析商品。历史失败HTML没有留存，不能断言旧页面为空、验证码或具体结构错误；也不能据当前重放伪造历史成功。

## 行为

适配器升为amazon-public-product-adapter-v8，解析字段版本仍为amazon-public-product-v5。目标原有一次确认重试保留；目标仍报source_changed时，若不是标准storage box检查页，则先验证该检查地址的采集策略，在同一取消信号和既有超时内最多额外检查一次。标准页可解析时，目标仍以parse_failed失败，不返回控制页商品、不保存目标事实、不计入流程完成；只有这种已验证的Amazon局部失败不计入来源全局熔断。

标准页同样结构失败时保留source_changed及原来源自动停用、版本和审计；限流、权限、策略阻断和取消继续传播。标准健康检查自身失败不再递归探测。其他来源不应用Amazon的局部失败例外。控制页只是来源健康证据，不代表目标内容、销量、评论、广告或利润。

## 验证与运行

新增回归在旧实现下复现错误的全局结构失败分类，覆盖局部失败不替换结果、真实结构变化、控制页限流、目标仍失败且不写事实、来源健康记录和原任务隔离。原结构变化停用回归继续保留。完整检查与发布结果另记本地收据，不能据此宣称未来所有网页均可读取或死锁完全消失。

不新增API、字段、环境变量、数据库结构、依赖、权限、前端或Python输入；既有parse_failed/source_changed分类继续使用，OpenAPI和环境示例无新增字段。通过既有正式宝塔脚本发布并重启唯一Node项目ai选品。已经停用的来源不由启动或此代码自动启用，须在真实健康检查后通过现有配置/审计服务恢复；受该次停用影响的任务只按明确范围、原业务回放与幂等合同恢复，不直接改状态、清队列或批量重放旧失败。日百品及整体验收未完成。
