# 前十项需求再次核验：导航连续性

## 已定位的漏项

真实生产从工作台进入个人中心时，App 卸载 NavigationShell 并挂载 AccountShell。AccountShell 自带另一套顶部与侧栏，搜索、上下文、手机抽屉均不一致。此前只把外观组件嵌入个人中心，未使个人中心留在原业务导航中，不能视为第9项完整满足。

修复由 App 在成员页与个人中心之间保留同一 NavigationShell 实例。AccountShell 只负责六个个人分区的内容，外观沿用该内容槽。直接打开个人中心不依赖组织导航批准，非阻塞读取既有导航信息恢复同一授权菜单与工作区名称；失败时仍显示个人中心；导航链接仍须在目的页核验原服务端权限，不扩大能力。组织/平台仍有各自合法菜单，不应为统一样式抹去授权差异。

另一个跨路由变化是行政壳层强制 compact；现统一保留用户本次会话明确选择的密度，避免离开/返回页面时偷偷改变字体间距。主题仍尊重账号偏好，不将石墨强制覆盖为蓝色。

## 使用、发布与边界

- 个人中心 → 外观偏好始终保留业务顶部、侧栏和移动菜单。旧 /settings/theme 仅作兼容跳转，不存在独立外观壳层。
- 无新 env、CLI、API 字段、数据库结构、依赖或 Python 契约；OpenAPI 与 .env.example 无需变化。
- 仅静态前端变更，正式 frontend-only 发布后浏览器刷新生效，无 Node/Python 重启。
- 查询耗时、HTTP耗时与真实采集完成是不同指标。Amazon source_changed/disabled、1688 network_error/open 和 CAPTCHA 不通过样式修复解决，不绕过保护。
- 验证结果和前十项真实体验证据追加至原交付角色账本；未验证的项不得写成通过，不承诺未经逐图证明的95%还原。

发布后真实复查还发现嵌入外观组件仍继承独立页面的1120px居中宽度和大标题。进一步移除嵌入状态的第二个main、装饰英文栏，改为全宽个人设置面板、20px分区标题、13px说明和紧凑状态条；不改保存与即时预览契约。

真实首屏复查取消嵌入页头继承的172px最小高度，避免标题缩小后仍残留大块空白；双端断言同时覆盖该最小高度。

直接刷新个人中心的导航资料改为非阻塞读取：组织导航403或范围缺失不能阻挡个人资料/外观内容，跳转业务目的页仍重新核验原守卫。此读取解决刷新后工作区占位和组织/平台入口丢失，不新增权限或接口。

通知中心补充本轮视觉修复：移除厚重侧边条，用清晰未读圆点区分状态；未处理/处理中/已关闭使用原workflow_status对应的语义色徽标，时间降为普通字重，消息行补齐hover与键盘焦点。不变更已读、处理状态、分组、偏好或SSE行为。

桌面宽度至少 1101px、窗口高度 480–920px 时，侧栏只滚动中间的路由组，顶部工作台切换及底部工作区、设置和帮助仍然可见；键盘聚焦会滚到对应入口。全高桌面、手机抽屉、唯一顶部面包屑及权限保持不变。仅前端静态变更，无需后端重启。

1600px 及以上，选品、组织和平台共用的侧栏及顶部搜索优先使用本地 Segoe UI、等线，保留现有主题字体回退。平台菜单标准密度使用 15px，保持原来的行高空间和固定工具区。侧栏切换入口仅展示已知的工作区、组织名称，缺失时显示「切换工作区」，不拼接被截断的占位语句；目标路由和权限不变。仅前端静态文件变更，无需重启后端。

1600px 及以上、标准密度下，组织与平台顶栏操作区共用 24px 间距，帮助与账号前使用细分隔线；跨两个后台切换时保持帮助、主题与账号入口横向位置稳定。选品顶栏、紧凑密度、移动端、按钮权限和操作不变；只需更新前端静态资源。

标准密度、1536px 至小于 1600px 时，组织和平台后台共用搜索框宽度、8px 圆角和 20px 工具间距；在后台首页、子页和两个后台之间切换时搜索入口不再变形。宽屏参考布局、紧凑密度、移动端、顶部唯一面包屑与原授权不变；仅更新前端静态资源。

桌面商业工作台从侧栏启用的 841px 断点起，为系统原生文档滚动条预留空间，从较短的治理概览切到较长的工作区管理时，顶栏、搜索入口、侧栏与内容列不横跳。滚动仍由文档负责，仅在浏览器实际测得非覆盖式滚动条占宽时预留，覆盖式或隐藏的滚动条不额外占宽；手机和非工作台路由不变。仅更新前端静态资源。

宽度 841–1100px 且高度至少 480px 的桌面工作台，侧栏只滚动路由列表，底部工作区、设置和帮助固定可见。帮助说明以底部工具区全宽展开，不被侧栏边缘截断。原宽桌面和不超过 840px 的移动抽屉规则保留；不改变链接、权限、面包屑或搜索。仅更新前端静态资源。
## 宽屏共用色面

1600px 及以上标准密度，顶栏与侧栏共用浅主题底色，与内容画布形成区分，不按路由切换样式。移动端、紧凑密度、菜单权限和单顶部面包屑不变，仅更新前端静态资源。

1600px 及以上、标准密度下，成员侧栏底部只保留一个 10px 内边距，移除原来侧栏和工具区叠加的 32px 留白。工作区、设置、帮助仍固定在底部，触达尺寸不变；选品、情报、选品库、找货、通知及个人中心共用相同规则。桌面短屏保留可滚动菜单，紧凑密度、移动端、组织和平台后台不变。仅更新前端静态资源，无需重启后端。

## 侧栏菜单滚动

发布树统一使用现有侧栏分组容器。短屏桌面仅中间菜单区域滚动，工作台切换及底部入口留在视口；宽且高的桌面保持原布局，移动端继续使用原导航。聚焦底部链接后可用 Enter 打开，当前项高亮及顶栏面包屑不变。不改权限或后端配置，仅重新构建前端静态资源。
