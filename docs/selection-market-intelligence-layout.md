# 市场情报工作区重制

用户要求摆脱旧 AI 样式，并让情报服务于自动选品。本项延续已查看的 ecom168 商务工作区方向：清楚的操作、筛选和事实内容，而不是大面积介绍卡。

## 页面

- 大蓝色教学横幅改为紧凑白底标题栏，刷新来源、新建监控直接可见。详细采集状态折叠保留，读完只标识“记录已读取”；“启用规则数”只表示配置事实，不证明当前来源健康或连续采集。
- 情报列表使用分页内连续序号、主题、市场、来源、新鲜度和真实信号数；不生成趋势分、增长率或缺失置信度。
- 桌面列表与证据详情分栏并各自滚动；手机保持列表→详情→返回的单栏流程。筛选按两行排布，避免按钮竖排，证据指标不再挤成窄列。
- 移除装饰色块、无用横幅颜色和重复证据标题；详情使用正常内容字号，帮助区改为平面白底折叠区。

保留已有筛选、URL 状态、分页、监控规则、关注、原文证据、质量工单、合并/拆分及权限和生命周期处理。不修改后端来源、评分、数据格式、采集频率或生产运行配置。本项不是全站 UI、真实持续采集或每日百品的完成声明。

## 2026-10-19 情报切换等待态

实际生产手机操作中，点开另一主题后，在该详情请求返回前仍显示上一主题的标题、指标与原文证据。现在点击不同主题立即进入详情等待态，隐藏旧事实，沿用现有请求代次、取消与权限处理；手机等待期间仍可返回列表，再次打开同一待取主题继续等待。详情返回后才展示对应事实。仅调整前端展示，不改 API、数据、来源、评分或生产配置；静态包更新后刷新生效。

新增慢请求浏览器回归，同时检查桌面与390px手机，明确拦住第二个主题的响应，验证旧标题、指标和证据不再出现，放行后只显示新主题。测试使用本地夹具，不作为真实商品完成证明。
