# 选品运行启动一致性

## 实际断点

生产来源当前仍登记旧解析版本，但 API 在监听端口前已有 ensureCatalog 同步，无需另加数据库迁移或手写升级。原同步对全部已有来源无条件写 updated_at，即使定义完全未变；公共来源启用检查要求真实烟测时间不早于 updated_at，例行启动会因此无谓使有效测试过期。

另一个断点是统一 Backend 同时启动 API 与 Worker。Worker 可能在 API 同步目录前领取旧解析版本任务；Amazon 适配器严格检查解析版本，旧版本不能冒充新版本运行。

## 当前行为

目录同步先比较实际定义。JSON 文本及已解析对象按真实结构比较；名称、URL、访问方式、字段、解析器等均未变化则不更新、不推进 updated_at，updated 计数只计算实际修改。定义确有变化时沿用原事务更新和时间戳，让原烟测门对真正变化继续生效。来源 enabled/disabled、审批、超时、调度与配置版本不由同步擅自改写。

Backend 内的 Worker 等到 API 的现有版本化健康探测通过后才启动；API 必须先完成目录同步再 listen。等待期间不启动 Worker，API 未就绪、超时恢复或已进入关机时不提前采集。独立 Worker 测试模式没有 API 依赖时维持原行为。API 已就绪后的原 Worker 崩溃重启、退避、熔断、退出转发与状态文件合同保留。未增加健康接口字段、服务、端口或配置。

## 验证与发布

51 项目录同步、来源版本/权限/启用、统一进程管理和发布回滚证据检查通过，包括无变更不写、JSON 格式等价、真实升级、停用保持、事务回滚、Worker 等待 API、关机等待和 API 就绪失败。API/Backend 构建通过；模拟子进程只验证监督顺序，不冒充宝塔真实重启或在线采集验收。

无数据库迁移、环境变量、前端/Python/插件/API 载荷变化，不绕过公共来源审批或实际烟测。按固定脚本本地构建发布，随后由宝塔重启唯一 Node 项目：`/www/server/panel/pyenv/bin/python /www/server/panel/script/restart_project.py nodejs ai选品`。Python 无需因本项重启。本轮未发布、未重启、未写生产数据库，未新建临时服务；测试自己的临时状态目录由测试 finally 清理。
