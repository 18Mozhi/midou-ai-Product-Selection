## 阻塞纪律

- 不使用真实生产账号、真实客户通知、真实支付或不可逆操作解除阻塞。
- 用户提供条件后，仍必须按单一页面/单一链路建立分支、前置证据、完整回归和验收门禁。
- 阻塞解除前，相关来源/渠道/生产能力不得在报告或 UI 中写成“通过/已启用”。
