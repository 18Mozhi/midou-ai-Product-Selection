# 《完整优化升级方案》

本方案以每个真实路由为单位。每行依次覆盖：页面定位/使用者/核心任务；保留与合并；信息架构、区域、主要/次要操作、表格/筛选/表单/弹窗；加载/空/错/无权、反馈/动效/响应式；权限差异、跨页联动、接口和数据状态；验收标准。没有建议删除现有业务能力。

## 小功能统一但逐页适用的验收

- 搜索/筛选/重置/排序/分页：请求参数、URL 状态、空结果、越界页和刷新逐页验证。
- 全选/批量：只作用当前授权集合，返回逐项结果，失败可重试且不重复成功项。
- 复制：只复制非秘密值；Token/密钥仅创建时一次性展示。
- 删除/撤销/取消：按业务状态机区分，必须有影响说明、原因和审计，不能用“删除”替代可恢复归档。
- 导入/导出/上传/下载：真实接口、大小/格式/权限/过期/失败清理；不得用 Mock 文件宣称完成。
- 刷新/重试/暂停/恢复/取消/状态/日志：保留 run_id/request_id/trace_id 和每次尝试，不覆盖历史证据。
