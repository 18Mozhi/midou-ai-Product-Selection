### P73 `/:pathMatch(.*)*` — 页面不存在

1 页面/路由：fallback 404；2 角色：任何用户；3 目标：解释不存在并安全恢复；4 截图：`output/playwright/not-found/`；5 入口：返回最近有效页面、返回今日行动、品牌首页；6 结果：每个入口、长路径、多标签、离线后已加载页面单独验证；7 接口：不适用；8 数据：只读本地最近有效路由，不写业务数据；9 权限：不把 404 解释为无权限；10 正常：通过；11 空：不适用；12 加载：静态；13 接口失败：不适用；14 超时：不适用；15 无权限：不泄露受限资源；16 表单：不适用；17 重复：安全回退；18 刷新/返回：通过；19 分辨率：390/768/1024/1440；20 UI：独立信号页；21 功能：失效最近路由 P1 已修；22 性能：本地预览 6 个资源、无 API；23 安全：不显示 query/hash；24 缺失：真实 Nginx HTTP 404 状态码阻塞；25 建议：部署后验证代理状态码，不改变当前恢复入口。

## 每页通用“不应改变”能力

不得通过删除筛选、分页、批量、审计、权限、状态、真实接口或错误恢复来简化页面；优化必须保持 `route-catalog` 的标题、权限、Surface、cache policy 和真实数据合同。
