# 《前端功能测试用例与结果》

## 1. 测试方法

真实页面验收使用 Chromium 打开路由并操作；契约/组件 E2E 的拦截仅用于可控制造空、失败、超时和权限状态，不能替代真实接口通过结论。真实页面证据位于 `output/playwright/`，稳定回归位于 `tests/e2e/`。

| 用例       | 操作                       | 预期                                       | 结果/证据                                                 |
