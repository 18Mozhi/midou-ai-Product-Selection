# 新情报摄取与找货积压隔离

## 生产依据

2026-10-18 北京时间04:29，只读核验发现59个商品补证/找货等活动任务与8个全量来源任务共用预算；两个到期组织均被共享预算挡住，当前尚无情报选主品事件。初始只核对了旧找货排在新情报前；后续实跑进一步确认找货使用high、全量来源使用normal。修复针对这一可复现的摄取阻塞，不声称它是整链零产出的唯一原因。生产来源审批、真实字段缺失与竞品质量仍各自验收。

## 调度行为

全量来源的单组织预算改为计入自身活动任务，使用已有同组织、同工作区、`actor_type=system` 的 `hotspot.automatic.scheduled` 事件证明来源。规则采集的预算仍计入全部组织活动任务。全局积压上限继续计算所有活动采集任务。预算值、来源批量与周期不变，不新增并发或服务。

全量情报新任务使用high。状态机的 scheduled/retry/rate_limited 入队和 queued 领取使用相同排序：有真实系统来源事件的旧normal全量任务按high领取，critical仍最先，其他任务的显式优先级不变；同档先全量情报，再按可用时间和 ID。不提升显式low来源任务。既有执行中租约不抢占，单机 Worker/Crawler 互斥及租约恢复不变；不按可由调用方填写的 request_id 判断来源，不改变历史任务或事件。
