# 选品工作台重制（2026-10-21）

## 范围与参考

用户要求采集暂不改，由用户自行测试；本次只重做 UI、布局与用户操作流程，必要后台全部保留。已实际查看登录后的 ecom168 `/monitoring-center/overview` 与 `/selection/library`，选品库为空，因此只借鉴可观察的固定侧栏、轻量顶部栏、统计/筛选/结果分区，不声称看到了该站真实商品行。去除其 AI 标签、渐变宣传和冗余入口。

## 新流程

- 首页：紧凑日报（今日整链完成、新增主品、合格推荐）→累计选品分布→真实结果清单。未知数不伪装成零。
- 选品库：标题→结果视图→名称/市场/高级筛选→八列数据表→分页。列为商品、售价、购买/排名、评价、进货价、竞品/货源候选、结论、操作。中等屏幕只在表格内部横向滚动，手机同数据纵向排列。
- 商品详情：回到原筛选列表→主品身份与事实→评分/竞品/货源成本/证据/决策分区。保持现有 API、权限、写入版本与决策理由校验，不触发采集。
- 市场情报和1688找货沿用真实记录，采用一致的平面标题、筛选与数据面板。平台/组织/账号/来源/采集管理/运维入口和能力校验保留。
- 登录/组织选择去除渐变背景与浮层阴影；成员顶部移除重复主题切换入口，个人中心外观偏好保留。删除重复图卡渲染和专属样式，不再让同一结果存在两套布局；替换首页样式，不继续叠加旧大圆角/夸张字距样式。

## 发布与回退

在干净且与 origin/main 一致的正式本地 main 工作区运行：

```powershell
python scripts/deploy-baota.py --frontend-only
```

此模式不可与其它部署选项混用；不复用未验证 dist，始终本地 build:web。只更新宝塔网站ID29、`/www/wwwroot/ai选品/frontend`；不停止/启动/重启 Node、Worker、Python，不执行迁移，不修改 env、来源、队列、运行会话或数据库。先核对网站身份、Git祖先和本次变更范围；使用现有发布锁。覆盖文件备份至项目 backups/frontend-提交号，静态资源先写，index最后原子替换，逐字回读；保留旧哈希资源供已打开标签使用。写入异常自动恢复被覆盖文件。

发布后 `/frontend-release.json` 是前端身份，后台 `/api/v1/health/version` 仍报告原后端版本，这是刻意保留而非发布失败。公开回读首页/选品库的HTML哈希和前端版本文件；本地回执 `.artifacts/verification/frontend-only-production-evidence.json` 不含秘密。运行源码/配置哈希及进程PID前后必须相同。用户刷新页面即可，无需服务重启或新增配置。

失败自动回退已覆盖字节；运维人工回退可依据备份中的 rollback.json 只恢复对应 frontend 文件，先核对项目根、备份提交与网站身份，不清理旧资源、不重启服务。后台功能/采集验收不纳入本次 UI 验证，不宣称每日100品达标。
