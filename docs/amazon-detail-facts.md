## 发现与修复

旧解析器的金额清理将空白文本变成 Number(空串)，写出 0；缺少图片时，URL 解析把空地址解析为商品详情页。当前主图在 leftCol，src/data-old-hires 在 landingImage 的 id 前面，旧代码只扫描 centerCol 并依赖属性顺序，真实页面均未取到主图。

新增 Amazon 专用事实解析，不改变其他供应商的金额或图片规则：

- 金额只接受明确数值、既有三位币种码及已支持货币符号，保留非美元币种与千位分隔；空白、仅符号、非金额文案保持 null。空评价数和空 JSON-LD 星级也不再转成零。
- 详情读取 corePriceDisplay_desktop_feature_div / corePrice_feature_div 内实际 a-price 的 a-offscreen 金额，排除 a-text-price 划线价。中心栏之外的主报价块必须明示 data-csa-c-asin 与目标一致。不能拿页面其他推荐商品或无身份报价补填。
- 真实主报价位于右侧购买区的情况已实测；不把范围硬限在 centerCol 导致报价再次丢失。价格区原文包含 ASIN 一并保存，source_paths 标明 primary_offer。
- 主图只读 leftCol 的 img#landingImage，属性顺序独立，优先有效 data-old-hires、再 src；图片必须是既有 Amazon 图片主机的 HTTPS /images/I/ 地址。缺失及非法值保持 null；搜索图片也不再回退到详情页。
- 同一主品 JSON-LD 原有有效事实优先，仅缺失字段可由实际 HTML 补充。价格/图片原始区域与对应字段路径共同保存，包含仅有 JSON-LD 与栏外主报价时的证据包。脚本、样式和注释中的伪标签不能提供事实。

解析版本升为 amazon-public-product-v5、适配器 amazon-public-product-adapter-v7。目录使用共用版本常量，自动来源调度白名单同步为 v5；旧配置不能给新结果挂旧版本。历史证据不重写。
