# 每日选品流程产出

## 已确认口径

2026-10-17 用户明确：每天至少 100 个完成情报、主品、5–10 个竞品、评分、1688 货源整条流程的商品，包含低分、不推荐。目标不再使用合格推荐数。同日补充确认：允许明确标注“利润未知”的已分析商品计入 100 个。仅放开利润未知，其他环节与非利润评分证据仍须完成；评分权重、阈值和合格推荐规则保持不变。

## 首次完成记录

评分 Worker 在当前评分写入后（包括 completed_with_warnings）、自动评估 Worker 在评分输入未变化且已完成本次分析后（包括利润等待状态），复用父事务和已取得的机会行锁核验事实。检查同组织/工作区的情报关联事件及原记录、真实 Amazon 主品、最新有事实依据的数值评分和采购价。采购价必须关联该机会的 1688 找货任务与原始归一化证据，商品链接、CNY 价格一致，有商品和供应商名称，排除新人价；利润已计算时，利润评分仍须引用当前采购证据；利润未知时不伪造数值，保留利润评分缺失原因，要求市场、竞争、风险和数据质量四项均有数值与证据，其他非利润评分分项没有缺失，评分覆盖率至少 80%。当前利润状态必须是数据不足，结论只能为数据不足、观察或不推荐，不得据此推荐。竞品复用既有推荐门的真实详情证明，排除主品并按 ASIN 去重，记录 5–10 个实际竞品及其快照/证据引用。

达到上述流程条件后，在既有 opportunity_events 记录 opportunity.selection_pipeline_completed，resource_type=selection_pipeline，resource_id 仍为机会 ID，新记录 payload contract=selection-pipeline-v2。记录包含主品 ASIN、情报证据、竞品、评分运行和采购来源；没有最低评分、必须推荐或低风险条件。完成记录明确保存 analysis_status、profit_status、score_coverage_percent、score_missing_fields 和 profit_missing_fields。只有利润未知可按本次确认计入；缺少数值评分、其他非利润评分、情报、竞品或具体报价的记录仍不算完成，不能用缺失值当零分。

历史 v1 完成事实保留不重写；日报同时识别 v1/v2，以首次完成时间合并去重。同一机会/ASIN 在父事务内先核对已有事件，不重复写入或改写首次时间；异常随评分/评估事务回滚并沿用原重试。不同机会出现同一 ASIN 时，日报以整个工作区最早完成时间去重，因此刷新、重试和次日再次评分不会重复冲日目标。按北京时间日历日半开区间计数，机会发现时间不限制流程完成时间。已完成后归档或作出不推荐决定不抹去历史完成事实。

自动评估确定当前利润缺失时，将当前利润状态置为 insufficient_data，历史利润运行不改写；列表、商品头和成本区显示“利润未知”，已有历史计算结果仅作为历史明细，不再冒充当前利润。

本版本开始记录首次核验完成，没有伪造或回填旧商品的历史完成时间。旧证据已失效或流程不完整不会生成记录。记录不等于已实现不间断运行或每日百品。

## 接口与使用

GET /api/v1/me/home-dashboard 的 automatic_selection.daily_production 增加可选 completed_count：该北京日期首次核验完成的工作区独立 ASIN 数。date、timezone、discovered_count、qualified_count、target_minimum=100、measured_at 保留。原发现数与合格数仍是当天新建主品的当前快照，不再充当流程目标；它们与完成记录不是同一统计口径。

首页显示完成整条流程、当天新增主品和新增合格推荐，进度只取 completed_count。旧服务没有新字段或未读取时显示未读取并隐藏进度，不回退到新增/推荐数，不补零。海外浏览器仍显示北京时间；零、超过 100、整体未知和仅缺完成字段均有测试。沿用既有每 5 秒及聚焦读取，离页停止。
