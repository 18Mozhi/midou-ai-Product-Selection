# 平台角色权限比较布局重制

用户要求全部 UI 与布局重制，账号目录后的权限比较也移除旧蓝色侧栏。角色选择和说明在顶部并排，下方全宽筛选和权限记录；手机保留双角色对应，结果在窄屏堆叠为有字段标签的记录。旧重复导入、侧栏宽度与三个旧断点覆盖删除，十九个独立颜色变量改为十五个共享语义别名，支持现有主题。

仅修改权限路由作用域的 CSS 和样式加载，PlatformRoleComparison 与 PlatformAccountCenter 脚本、模板和事件不变。五项 URL 筛选、真实角色目录 GET、差异、同角色、重置、失败保留数据与重试不变。共享管理员比较区的通用三条布局规则保留，其余新样式均带 permission-page 前缀。账号目录旧变量已删除，因此主题测试同步检查实际剩余弹窗变量，不要求恢复废弃颜色。

实际编译发现原根变量经 scoped 导入后生成 html[data-v]:has(...)，无法匹配根元素。改由父组件独立非 scoped 样式加载唯一变量文件；变量仍由 html:has(权限页) 限定，两个 scoped CSS 不再重复导入。浏览器增加变量已解析且背景非透明的实际计算值检查，避免仅凭源码声明认为颜色生效。

全局无障碍输入框规则把复选框放大为 44px；权限页单独设定方框及逻辑最小尺寸为 18px，标签保持至少 44px，实际浏览器同时核对两者。两个权限 CSS 净减少 66 行。

无新增 API、数据字段、权限、数据库、环境变量、依赖、Python 输入或运行服务；OpenAPI 与环境示例无对应变动。由既有脚本发布前端静态资源后刷新生效，无单独 Node/Python 重启要求；整个重制分支其他后端变更仍按对应说明重启。本项尚未部署，不代表全站 UI 或每日百品验收。
