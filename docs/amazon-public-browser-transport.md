# Amazon 匿名公开浏览器采集

本次将 Amazon 公开页面接入已有浏览器作业队列，解决普通 HTTP 请求受拒时无法使用已验证可读的匿名浏览器页面的问题。没有新增服务、依赖、数据库迁移或公开接口；来源仍为 public_page，条款、robots、熔断、组织工作区和全局浏览器租约继续执行。不会自动越过验证页。

## 配置与使用

宝塔受限 product_scout.env 中设置 AMAZON_PUBLIC_BROWSER_PROFILE_ID 为已有 Amazon 来源下的专用空档案 UUID。该档案必须由现有凭证资产服务加密保存，内容只能是 1024 字节空 tar 的 gzip，不含 Cookie、登录状态或用户数据。领取作业校验档案 ID、来源、资产类型、状态和指纹；Node 执行器解密后再次核验空档案内容。空值保持原 HTTP 方式。

AMAZON_PUBLIC_BROWSER_NAVIGATION_TIMEOUT_MS 默认 60000，可设 1000–120000，只影响标记为 amazon_public 的任务；其他浏览器任务仍使用 PLAYWRIGHT_NAVIGATION_TIMEOUT_MS。单次运行仍由 PLAYWRIGHT_RUN_TIMEOUT_SECONDS 限制，健康检查的搜索和同一 ASIN 详情共享此总期限。现有全局租约限制并发，不因本项提高。

通过固定宝塔部署命令发布后，Node API/Worker 和 Python 采集服务均需要重启以加载代码及环境；部署脚本执行重启。手动重启只使用项目 AGENTS.md 指定的宝塔命令。无需迁移数据库。恢复 HTTP 可清空专用档案配置并通过宝塔重启，历史证据不重写。

管理员在来源适配器页运行已有健康检查。浏览器模式使用当前会话的组织和工作区，真实搜索结果与同一商品详情都解析成功才返回 ready；不会把检查记录保存为商品事实。检查通过后按已有审计恢复操作关闭熔断，调度器才恢复正常任务。不能以单页可读、搜索成功或局部测试代替此步骤。

## 数据与证据

适配器版本为 amazon-public-product-adapter-v14，标准化字段版本仍为 amazon-public-product-v5。内部浏览器计划增加可选 fail_on_http_error，以及 evidence.dom_selectors、ancestor_ids、strip_non_content。选择器最多 12 个、祖先 ID 最多 8 个；未设置时保持现有行为。

详情证据只裁取真实主图、标题、评分、主报价、购买提示、详情与有限公开评价区域，并保留实际 leftCol/centerCol 祖先。合并同一祖先，避免多个 centerCol 造成后续字段丢失；仅对脱离页面的克隆去掉脚本和样式，不修改真实页面。DOM 250000 字节、JPEG 800000 字节上限不变。

消费者验证两份证据的来源地址、ASIN/搜索词、时间、SHA256、类型、大小和格式。解析到的时间来自真实浏览器抓取时间。价格、销量提示、广告标记和评价缺失时保持未知，不使用推荐商品补齐主品，也不推算竞品真实广告花费。

## 验证边界

单元测试覆盖 URL、空档案、证据篡改、身份错配、未知价格、配置和作业领取限制；真实 Chromium 本地夹具检查主区域裁剪和原页面不变，既有 1688 加密浏览器集成回归仍保留。这些测试不代表 Amazon 生产网站持续可用。

生产还必须验证真实健康检查、正常任务经过 Python 领取与 Node 标准化、真实主品与 5–10 竞品、1688 货源及评分落库。每天 100 品按北京时间首次完成整链的不同主 ASIN 计数，低分、不推荐和明确标注利润未知可计入；诊断抓取、未完成分析和伪造字段不能计入。
