# Amazon 健康检查覆盖搜索和抽样详情

## 实际依据

2026-10-18 北京时间08:03，现有正式采集策略及代理下，标准 storage box 搜索可解析；真实失败商品 B0FHJYHHN6 的原详情地址和短 dp 地址均返回 permission_denied，曾有真实报价的 B0CB5W829V 详情当前也返回同类失败。条款仍 approved 且未过期。旧健康记录的 ready 只证明搜索可读，不能证明详情可采集；不据此推断永久故障或所有 ASIN 的状态。

## 新检查

适配器版本 v11，解析字段版本仍为 amazon-public-product-v5。健康检查先解析原固定搜索页的一条真实结果，再使用其有效 ASIN 请求标准详情页。详情请求前检查该地址的既有公共采集策略；仅两阶段均解析成功且详情身份相符时返回 ready。无有效结果、权限拒绝、限流、缺失页面、策略阻断或取消仍返回原错误分类和 degraded。

不硬编码另一件商品作为成功结果，不遍历详情、不追随验证地址、不解决验证码、不切换代理、不伪装浏览器、不新增重试、并发或服务。沿用原健康取消信号和超时预算，不要求已知价格才能证明页面可解析。一次抽样成功不代表所有详情或所有必需业务字段可用。

健康结果只返回原状态、时延、错误码和说明，不返回或持久化搜索／详情商品，不计入产量，也不自动启用来源、批准条款或恢复熔断。现有审计恢复仍要求晚于熔断时间的真实 ready 记录；详情不可用时保持等待，不能再把搜索成功用于放行。

## 验证与操作

新增测试覆盖详情成功但价格未知、验证页、HTTP403、429、404、搜索失败、取消，以及独立进程中的详情 robots 阻断。原真实事实提取、验证页隔离、来源结构变化及 LAN 健康回归继续保留。

无新 API 字段、数据库结构、环境变量、依赖、前端或 Python 合同；OpenAPI 只更新健康含义。正式宝塔脚本发布后重启既有 Node 项目，让 API 和 Worker 注册 v11。用现有来源适配器健康检查操作读取结果；degraded 时不得作为恢复依据。生产实测与发布结果记录本地收据。该修正不等于解决详情访问或每日100个完整选品链。
