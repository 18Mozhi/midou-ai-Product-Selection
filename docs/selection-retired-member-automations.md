2026-10-17，按本次“成员端只保留核心选品流程”的要求实施，本地尚未部署。

## 实际删除与旧链接

删除 `AutomationRuleCenter.vue`、`automation-rules.css`、`automation-rule-tokens.css`，共 1,648 行。移除异步组件注册和已无所属页面的“运营工具”面包屑映射，不仅隐藏菜单。

`/automations` 转到 `/opportunities`，沿用选品库权限，清除旧 `rule`、`action` 等查询参数与 hash。没有创建、恢复、暂停、试运行规则的成员入口，也不会因旧编辑深链接触发旧接口。平台治理继续展示已有自动化规则的事实、版本、频控和详情，但不再展示指向已退役成员编辑器的链接；其他治理分类的入口和操作保留。

## 后端和历史边界

不删除历史规则、数据库表或持久化数据，不改自动化 API、授权、幂等、审计和 Worker。连续选品由既有后端情报关联、商品采集、周期刷新、证据评估与评分链路承担，不依赖已删除的成员规则编辑组件。后端事实保留不代表已完成生产持续运行或每日百品验收。

旧 UI 测试文件及永久截图保留为历史材料。只读归档固定在 Git `a273eb914055247a8122b400249e7edcd3274904`，读取限制为三个已删除前端文件和原浏览器测试；不能读取其他文件，不能将旧源码注入当前构建。旧五个页面捕获命令遇到退役组件会明确拒绝，启动服务或生成截图之前退出。旧页面的离线行为/字段/颜色核验不再充当当前产品验收；后端测试继续核验当前 API、迁移、Worker、版本与原因合同。

## 验证和使用

正常使用选品工作台、市场情报、选品库和 1688 找货。旧自动化链接自动回到选品库。无需新增依赖、环境变量、配置开关或迁移；OpenAPI 没有 API 变化，前端路由清单、生成物与 Feature Map 已同步。

定向浏览器回归在桌面和 390px 手机各通过八项，覆盖退役入口、目标权限、查询/hash 清除、无旧接口请求，以及平台治理的真实现行组件查询、详情、失败保留和切换生命周期。这些用例使用本地接口夹具，不证明生产 API 或真实采集。

13 个单元/后端文件共 155 项通过，包含退役保护、历史字段/所有权、当前弹窗/颜色、治理数据合同与后端规则更新。前端类型检查、构建、路由产物、静态分析、文档和包体预算通过，构建资源数降至 198。新增实际 HTTP 业务覆盖后，真实性检查已通过（27/55，0.4909）；整体全量结果见 selection-release-verification.md，尚未发布。
