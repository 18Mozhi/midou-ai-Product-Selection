# 组织资料工作区重制

依据用户当前的全站 UI/布局重构要求，以及已经实际查看的 Ecom168 工作区参考，组织资料正文改为顶部组织身份和四项事实、紧凑六项运行摘要、下方全宽编辑表单。取消旧资料/表单双栏、固定最小列宽、渐变指标卡和独立蓝色配色。九页共用工具栏继续沿用已重制版本。

`OrganizationAdminCenter.vue` 的脚本保持逐字一致，全部原生事件和表单绑定集合不变。名称、Logo HTTPS 地址、时区、数据保留天数、默认工作区、变更原因以及原生约束、版本、幂等、审计、保存/回读状态继续沿用现有链路，没有新增 HTTP 字段、权限、配置、依赖或后端写入。

旧 `organization-admin.css` 删除 42 个资料/指标相关选择器及无内容容器块，约 214 行。其他组织页面仍依赖的共享样式和颜色文件保留，待各页面正文完成重制后再清理。新工作区样式使用现有 `--so-*` 语义变量，以实际内容宽度在 820/520px 切换摘要与表单列数；不新增业务设置。组织后台手机底栏单独限制为 13px、有界文字，保留完整菜单文本和可访问名称，避免五字菜单互相重叠；成员和平台底栏不受此选择器影响。
