# 找货工作区布局重制

依据本次用户目标及已核对的 ecom168 商务工作区、FindNiche 商品列表方向，当前找货页改为紧凑标题、直接操作、统计行、搜索和任务/报价主从区。不是同行像素复刻，也不以历史预览稿代替当前 Vue。

删除顶部重复导航、四步教学条和无业务用途的 journeyStage 计算；四张统计卡改为语义化统计行。顶部保留费用规则入口和发起找货，新增“刷新记录”复用原 GET 读取，不派新采集任务。任务列表删除每项重复“查看详情”文字，增加选中状态的 aria-pressed；手机改为两列有界列表，详情仍可访问。

源 CSS 中删除旧导航、流程、标题、卡片、列表及不存在教学横幅的规则，重写相应布局，不把新样式叠在旧规则上。降低过重字重和报价主字段蓝色装饰线。报价、缺失项、证据、异常、登录失效、权限、删除确认、确认报价和对比/采购操作仍沿既有实现，本轮不改它们的业务与接口合同；其他用户模块仍按总目标继续精简。

预览验证删除 scripts/lib/sourcing-page-preview.mjs 的旧 body/CSS 注入；CLI 直接渲染当前 Vue 和生产样式，并仅对真实源文件建立指纹。历史 design-plans 中的设计参考保留，不再注入验证页面，不作为新布局签收证据。

## 使用与发布

访问 /sourcing，顶部发起找货或刷新记录；左侧选择记录，右侧查看采集进度与货源报价。手机记录列表显示在详情上方，列表内滚动不代替页面详情滚动。实际缺失项和有条件价格保持原提示。

没有新增配置、依赖、API 字段/路径、权限或数据库结构，也没有修改后端、Python 输入或插件载荷。前端仅需按项目固定部署脚本上传本地构建的静态文件；纯前端不需要额外重启后端。本轮未部署，线上仍为 c26e2b522bc616cbc2a67b01185d832f93789174。

## 验证边界

实际 Vue 浏览器检查刷新无写请求、记录选中状态、无横向溢出、桌面及 390px 手机截图；永久截图使用合成业务数据。既有找货、报价缺失、对比、成本确认、采购、失败与异步归属流程需要完整回归。公开采集和每日百品仍需单独真实运行验收。


本轮结果：最小 8 项找货/报价回归通过；完整相关 30 项回归通过。找货整套桌面 27、手机 27，共 54 项通过，含新截图基线、只读刷新及选中状态。移除注入后的实际 Vue CLI 手机 smoke 为 8 项检查、0 写入、0 导出图片；Web 类型/构建、样式、静态分析、文档/路由地图、运行文档和前端 204 资源预算门禁通过。初次最小验证中，旧测试仍要求教学流程条；现已改为检查新直接操作和选中状态，原报价、证据、对比及采购约束断言保留，复测通过。

变更前分支 codex/selection-core-rebuild、HEAD 34ea36ad8c50eac1e78fe58021c95c9d219f439f；唯一工作树，仅本分支未合并 main。既有 verification/state.json 改动不提交。永久合成桌面/手机基线保留，Playwright 内部临时产物自动清理，测试与预览进程退出；不把合成数据当作生产采集验收。
