# 31项全量失败修复

## 原始结果与共同根因

2026-11-03首次全量单元测试为3768项、3737通过、31失败；完整原始输出保留，
没有以定向通过替代全量，也没有删除失败测试。

- 已退休CSS仍被部分历史证据检查直接从当前目录读取，触发ENOENT。
  复用既有retired-runtime-css哈希固定读取器，只对登记的八个历史CSS读取原Git版本；
  其他路径仍读取当前文件。旧图片、原哈希和审批状态不改写，不恢复退休CSS到运行时。
- P34组合器要求原始驱动哈希，而调用方误传了后来新增历史预览保护的CLI版本。
  调用方改读原哈希对应的Git字节，组合器的原哈希、逐锚点、错误输入拒绝全部保留；
  外层CLI禁止用退休CSS生成当前截图的保护不变。
- 原P37审计截图的脚本输入同样从原捕获哈希读取，仍经原校验器验证。
- 现行OpenAPI有229个路径、262个操作；验收manifest/schema及测试仍固定225/258。
  同步为真实清单，保留60条受保护路由、六角色、五维API证据及失败关闭条件。
  没有新增或变更产品API，也没有执行生产验收、创建账号或写数据库。
- 队列领取测试缺少已实现的竞品补采排序断言；更新精确SQL后缀而不改变实际调度策略。
- 找货测试仍要求已退休按钮、状态文案仍要求内联；分别核查退休状态和真实共享状态函数，
  不恢复旧按钮、不修改产品操作权限。
- 报价对比组件超过既有120行上限：将原CSS移为同组件scoped外部样式，
  原规格提示函数移为纯显示辅助函数，表格结构、数据、交互及报价事实不变。
- 报价确认上下文标签恢复既有13px最低字号，不给门禁增加12px例外。
