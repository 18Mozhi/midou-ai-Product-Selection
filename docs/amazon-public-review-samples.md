# Amazon 公开评价节选

依据用户要求补充商品和竞品评价数据。2026-10-17 在 Chrome 及无 Cookie 的匿名 HTTP 访问中核对同一公开商品页；匿名返回 HTTP 200，实际解析得到 8 条样本，8 条均有星级、原文日期、款式与已购标记，6 条展示有用票数。这是单页验证，不是生产连续采集或全量评价验收。研究标签页已关闭，原始页面仅在内存解析，未保存真实评价测试夹具。

## 解析和证据

仅解析当前商品页 `ul#localTopReviewsList` 内 `div[data-hook=review]`。真实字段来自 `reviewTitle`、`reviewRichContentContainer`、`review-star-rating`、`review-date`、`format-strip`、`avp-badge`、`helpful-vote-statement`；不扩大到其他国家评价、搜索页或页面脚本中的伪节点。

每商品最多 10 条，标题 300、正文 2000、日期及款式各 200 字符；只提供节选。日期保留展示原文，不猜时区；不同款式保留原始标识，不冒充当前子 ASIN 独占评价。无认证/票数为未知，不补成未购买或零票。仅实际已购徽标转 true。原始评价根片段随既有证据包保存，标量 `review_samples_json` 随规范化记录写入，沿用证据保留与租户隔离。解析器 v4、适配器 v6；无数据库迁移。

API 只白名单输出 review_id/title/text/rating/date_text/variation_text/verified_purchase/helpful_votes，不输出评价者身份和原始 HTML。保留组织、工作区、来源、证据和 ASIN 连接约束；无有效样本时省略 review_samples，旧数据不伪装已补采。

## 使用

选品详情的商品对比下方展开“公开评价样本”，可分别阅读主品和竞品。展开不发送额外请求。详情请求 `GET /api/v1/competitors?opportunity_id=<UUID>`，按当前选品与会话租户查询；无参数普通竞品列表保持轻量，不携带正文，单竞品详情允许样本。非法 UUID 拒绝，查询参数不能覆盖会话组织或工作区。

不新增配置、依赖、API 写字段或评分权重；节选不推算销量、广告成本或情感分数。仍需补采其他商品、全量评价与真实运行验收；每日 100 品目标尚未验收。
