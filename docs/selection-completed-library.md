# 已完成分析商品入口

此前工作台已有整链完成进度，但选品库只有推荐、候选、采集中和全部视图。利润未知的真实完成商品不属于推荐，用户必须进入全部商品并搜索标题。现在工作台提供“查看已完成分析（全部日期）”，选品库提供“已完成分析”视图，地址为 `/opportunities?view=completed`；原默认推荐视图、旧书签和逐品决策保留。

## 读取口径

`GET /api/v1/opportunities?selection_view=completed` 复用原身份认证、当前组织/工作区授权、分页、搜索及显式筛选。列表与总数使用同一个SQL谓词，只接受当前范围内worker写入的 `selection_pipeline` / `opportunity.selection_pipeline_completed` 事件、v1/v2完成合同及10位字母数字主品ASIN。按大写ASIN查找最早完成事件；同时间使用事件ID决定唯一原始商品。其他组织/工作区、无效事件及后续刷新不能抢占原始商品。历史归档商品也可查看，显式生命周期筛选继续生效。

这是全部日期的历史完成清单，不能把总数当成今日产量。工作台今日计数继续采用北京时间首次完成日，既有统计SQL不变。低分、不推荐和明确利润未知的完成结果均保留；列表展示原有当前真实商品、评分、采购价和利润状态，不把历史完成证明当作当前推荐资格。完成事件来自原Worker质量校验，本次读接口不能创建、补写或伪造完成事件。

## 配套与使用

API producer/service/repository、Vue路由恢复/读取/列表和工作台入口、OpenAPI、Feature Map同步。Python、插件payload、后台管理、数据库结构、来源开关、权限、评分、推荐质量门及采集调度不变。没有新依赖、环境变量或用户调节项。固定部署脚本上传前端并通过宝塔重启Node加载后端；无需数据迁移，也不需要重启独立额外服务。
