# 产品列表的信息密度

依据已实际查看的 FindNiche 产品列表和 Ecom168 工具布局调整选品库卡片，不改变数据合同或评分规则。

- 桌面最多四列，1100px 以下三列，840px 以下保持两列；列表模式仍为单列。
- 真实商品图保留完整比例；无主图或加载失败显示原有准确状态，图片区缩为 64px，不再用大块空白和单字“图”占位。
- 缺图文字为左上角 44px 选择目标留出空间；保留标题两行、事实资料、决策摘要、竞品、货源和利润状态。
- 保留缺图的无障碍名称、失败后恢复逻辑、分页、筛选、详情入口、批量操作及后台权限。

实现位置：`OpportunityListPanel.vue`、`commerce-workspace.css`。没有新增配置、环境变量、依赖或接口；发布静态前端后刷新页面生效，无须单独重启后端。

验证应包含真实图、待采集图、加载失败图，桌面与 390px 手机，图卡/列表切换、标题与选择框不互相覆盖。类型检查和构建不能代替渲染验收，也不证明自动选品或每日 100 个整链商品达标。

## 移除旧目录样式入口

商品目录不再挂载 `opportunity-list` 类。实际组件检索确认旧列表行、概览和图片只由该已替换目录使用后，从 opportunities.css、automatic-selection.css、member-workspace-polish.css 删除 78 个对应选择器（365 行旧规则）；混合选择器保留详情、证据和决策面板部分。名称类似的写入作用域字符串不是 CSS，不作删除。

新目录的图片、两列决策指标、四列桌面卡片、手机双列及列表模式由 commerce-workspace.css 管理。旧四列指标、手机纵向结果工具栏、缺图内部色块不再进入目录。手机图卡/列表按钮保持至少 44px 高。原有详情样式、筛选状态、只读提示、权限、数据及模态操作逻辑保留。

本轮类型检查、构建及上线渲染结果单独记录；删除旧 CSS 不等于完整 UI 或自动选品流程已经验收。
