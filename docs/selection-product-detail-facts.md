# 选品详情主品资料与评分排版

详情顶部直接展示已有 `primary_product` 中的售价、评分/评价、平台购买提示与类目排名，并标明商品采集时间和广告观察状态。购买提示只表示平台公开数量下限，不作为精确销量；广告字段缺失显示“广告标记未提供”。价格、评价等零值原样展示，空值不补造。

评分概览压缩重复标题、字号和间距；已知维度的 `.input` 缺失项显示中文评分资料名称，未知字段保留原值，便于核对。保留缺失项展开、评分规则入口、重评分、竞品和货源操作及读权限状态。

本次复用现有详情 API 和事实字段，不改评分、质量门、完成口径、数据库、权限、依赖或环境变量。详情事实与列表共用后台主品身份/版本筛选，不以机会更新时间冒充采集时间。主图失败占位与运行信息键盘展开保留。

使用：选品库打开商品即可查看；页面数据缺失时通过现有采集与自动分析补齐，不在前端编造。无需新增调节参数。前端静态包更新后刷新页面生效；本改动自身不需要重启后台或采集服务，正式发布仍遵循既有宝塔部署流程。

验证：Web 类型检查、机会详情真实性回归与预览契约；桌面和390px手机的空值/零值/公开下限/广告未知/键盘展开/无横向溢出浏览器检查。生产整链与每日100品验收单独记录，本次UI改动不代表该验收通过。

同时移除已无任何生产引用的4个旧色值定义（选品列表hover和市场情报已删除弹窗的3个颜色），同步严格配色契约计数。扩大检查中3项同样在改动前发布工作树失败；清理后重新验证，不放宽引用完整性断言。
