# 重制后的后台保留回归

用户要求保留后台、账号、组织、采集与运维功能。本轮以工作分支实际界面进行整体发布检查，不恢复旧顶部导航或旧配色来满足历史截图。

## 本轮修复

- 固定侧栏的组织后台、平台后台和返回成员工作台链接补齐既有手机菜单中的辅助标签。目标地址、上下文切换条件及权限不变。
- 组织资料概览固定两列最低宽度总计 836px，但旧响应式规则只看 760px 视口，导致 768px 或扣除侧栏后的内容区溢出。概览改用自身内容宽度的容器查询，不够 836px 时变为单列；宽屏原双列保留，不改资料保存流程。
- 账号筛选在手机上 Teleport 到 body 后，原来依赖账号页面祖先的样式失效，控件缩到 21–27px。筛选组件增加自身作用域的布局、主题色和至少 44px 控件样式，覆盖账号、组织与管理员筛选，不改字段和请求。
- 原因弹窗可在异步加载时以 open=true 首次挂载。输入框监听器此前只处理后续变化，首次打开不能正确聚焦。初始化时也执行原重置与聚焦逻辑，继续沿用原输入限制、取消、焦点返回和 API。
- 导航回归改为核对真实固定侧栏、保留的角色入口与手机抽屉；成员路由测试使用现有选品库入口。管理员创建界面颜色断言采用已实施的商务蓝与焦点色，保留悬停、键盘焦点及写入边界检查。

- 清理已删除选品横幅遗留的未引用颜色变量，颜色检查仍要求声明与实际引用完全相等，未削弱颜色作用域或真实性门禁。

## 验证与发布边界

窄屏回归覆盖 390、768、1024、1440px。保留原输入保存、迟到响应隔离、权限、幂等、取消与键盘回归，不仅核对页面可见。

本轮无 API、数据库、环境变量、依赖、Python、Worker 或持久化数据格式变更，因此 OpenAPI、示例环境文件和数据库迁移不适用。前端发布后生效，无独立重启要求；整体发布仍遵守既有宝塔脚本与 main 同步门禁。
