# 自动选品真实运行核对

## 验收口径

按用户明确回复，每日目标是至少 100 个不同主品完成情报、主品、5–10 个相关竞品、分析评分和 1688 货源链路。低分、不推荐，以及明确标注“利润未知”的已分析商品允许计入。其他证据、商品身份、竞品和供货匹配门槛不因此降低。跨主品是否共享同一 ASIN 的竞品关联仍待用户选择，未改变数据库关系。

## 验证边界与历史 UI 资料

重构前完整测试基线为 3123 项、3034 通过、89 失败。失败集中在旧 UI 的源码指纹、已保留截图输入、共享页头断言及入口代码行数预算。历史截图、审批 JSON 和哈希不改写，历史测试明确读取固定提交 `c26e2b5` 的源码及 E2E 输入；当前构建工具默认仍读取当前文件，不能借历史审批通过新版检查。

当前 UI 的页头和样式断言继续读取实际文件。字体默认保留 13px 最小值，仅列明的辅助信息及移动记录操作选择器允许 12px；其他小字仍被设计门禁拒绝。Worker 入口仍禁止 SQL 和 Worker/Repository 类，400 行预算统计非空组合代码，保留可读空行。完整回归为 3142 项全部通过、零跳过，22 个工作区构建、153 项文档文件门禁、运行文档、497 个静态分析文件与代码格式检查通过。没有改写旧截图或审批记录，也没有以历史审批代替当前 UI 验收。

最终提示词不额外排除实体商品类目，调整后重新构建 Worker 并通过 54 项定向检查；真实新闻再次分类为 851/1062ms。未重复执行与该文字调整无关的历史截图全量扫描。
