# 找货页进度与缺失状态整理

2026-10-18线上Becko找货记录没有候选，来源受阻1/1；页面同时显示缺失项蓝框、满格蓝色进度和空报价蓝框，supplier_listing重复两次。该字段实际来自core-collection-projection-worker在候选总数为零时的missing列表，不是未知接口字段。

SourcingWorkspace将来源进度改为状态、已结束来源数及成功/等待/失败/受阻的紧凑语义计数，移除进度条和四格指标框。数量及状态仍直接使用原collection_progress，不把来源结束当作采集成功。无候选时只在报价空状态显示一次缺失项；有候选时在原详情位置显示待补齐字段。supplier_listing显示供应商商品资料，其他字段仍使用原映射，未知代码保留可追溯性。删除无候选时“必须人工确认”的重复指令，不改变报价资格或确认操作。

进度区域采用分隔线，空报价和ERP线索采用白底；删除旧进度、指标格与响应式覆盖样式，以及确认已无引用的浅蓝变量。来源阻塞、排队、执行、失败及未知的原说明分支、任务明细权限、刷新、报价、采购和对比调用均保留。

本轮先验证12项双端状态用例，覆盖六类真实状态分支、中文缺失项仅一次、四项计数和没有满格进度条。完整找货回归与受阻视觉基线继续核对对话框、权限、迟到响应、分页和原报价/采购合同。受控数据不是线上货源可用性证明；既有契约文案断言已随新命名区域同步，未修改历史证据。

实际完整浏览器批次70项中68项通过、2项旧缺失提示断言失败，更新到当前文案后2项复验通过，不混称一次全量全绿。61项颜色/主题检查通过，17项相关契约批次中的旧进度文案断言更新后，所在三项模块检查复验通过。新增受阻截图在发布门触发模拟截图比例限制，复核发现手机图片受固定导航遮挡，因此删除该组无效视觉断言及基线，保留全部状态和计数断言；实际变化的原报价布局基线仍保留。前端类型及构建通过。未重采本机之外的平台基线。

纯前端展示改动，无API字段、路由、数据库、Python、环境变量或依赖变化，OpenAPI和环境示例不适用。对应生产者字段已核对，消费者为原组合函数和组件，没有新增外部payload。通过既有deploy-baota.py发布静态包后刷新生效，无调参要求，官方脚本仍由宝塔管理现有项目。外部1688续期、Amazon采集稳定性、全站重制和每日100个整链商品仍须独立验收。
