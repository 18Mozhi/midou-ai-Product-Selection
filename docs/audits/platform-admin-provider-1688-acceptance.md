## 问题记录

### P36-01（P2）刷新失败清空已验证事实

- 所属模块 / 类型：1688 验收 / 功能与可靠性。
- 问题描述：刷新失败时页面被全屏错误替换，运营人员失去上一次可验证事实。
- 复现步骤：成功进入页面，切换浏览器离线，点击刷新。
- 预期 / 实际：应保留旧事实并提示失败；修改前旧事实消失，只剩错误状态。
- 证据：修改前真实浏览器离线操作与修改后 `offline-preserved.png`、`timeout-preserved.png`。
- 涉及文件 / 接口 / 数据：`Alibaba1688AcceptanceCenter.vue`；验收 GET；六张只读事实表。
- 影响范围：平台来源管理员在短暂网络或服务故障时无法继续判断门禁。
- 修复建议：区分首次加载失败与刷新失败，刷新失败只更新反馈，不清空已有数据。
- 验收标准：离线、接口失败和 12 秒超时均保留旧门禁、矩阵和最近读取时间；已通过。

### P36-02（P2）刷新缺少超时与重复触发保护

- 所属模块 / 类型：1688 验收 / 功能与性能。
- 问题描述：请求无页面级截止时间，加载期间也没有明确防重复状态。
- 复现步骤：挂起验收接口并连续触发刷新。
- 预期 / 实际：应在有界时间内恢复并拒绝重复触发；修改前可能持续等待且反馈不足。
- 证据：定向 Playwright 用例和 `timeout-preserved.png`。
- 涉及文件 / 接口 / 数据：`Alibaba1688AcceptanceCenter.vue`、`m03-07-provider-sources.spec.ts`；只读 GET；不写库。
- 影响范围：慢接口场景的页面可恢复性与服务端额外请求压力。
- 修复建议：增加 12 秒 AbortController 截止时间、加载禁用和函数级重复保护。
- 验收标准：挂起时只有单次刷新链路，12 秒后按钮恢复且旧事实仍在；已通过。

### P36-03（P2）固定样本入口未定位 1688

- 所属模块 / 类型：1688 验收 / 联合流程。
- 问题描述：旧入口只进入包含 181 个来源的通用目录，未定位当前 Provider。
- 复现步骤：点击“定位 1688 固定样本”。
- 预期 / 实际：应只显示关联 1688；修改前进入未筛选目录。
- 证据：真实浏览器修改前后点击结果；修改后 URL 含 `provider_id`，目录显示 1 个来源。
- 涉及文件 / 接口 / 数据：`Alibaba1688AcceptanceCenter.vue`；来源目录 GET；`providers`。
- 影响范围：固定样本收口路径变长且容易操作错误来源。
- 修复建议：把验收响应中的真实 Provider ID 传入来源目录查询参数。
- 验收标准：点击后页面明确提示已定位关联来源且仅展示 1688；已通过。

### P36-04（P3）业务结论层级弱且暴露原始枚举

- 所属模块 / 类型：1688 验收 / UI、易用性与可访问性。

- 复现步骤：桌面或移动端打开修改前页面。
- 预期 / 实际：应先说明业务结论、门禁顺序和动作；修改前技术状态抢占主层级。
- 证据：修改前后桌面、移动端截图。

- 修复建议：采用“结论 → 三道门 → 覆盖矩阵 → 下一步 → 最近运行”结构，原始枚举折叠展示。
- 验收标准：主层级仅显示中文业务状态，移动端顺序完整，技术枚举仍可查看；已通过。

## 本页优化方案与验收边界

- 页面定位 / 核心任务：生产启用门禁事实页；管理员先判断是否可启用，再按阻塞项补登录档案、运行证据、固定样本和审批。
- 应保留：真实数据库聚合、三道强制门、覆盖矩阵、负责人、技术详情和两条下一步入口；不得弱化为通用后台仪表盘。
- 应删除或合并：主层级不重复技术枚举；无业务价值的原始字段集中到技术详情，不删除可审计能力。
- 新布局：结论置顶，三道门按 1–3 排序，覆盖矩阵独立，下一步与最近运行收尾；桌面多列、移动端单列。
- 组件级方案：稳定刷新按钮、live region、门禁卡、覆盖卡、动作导航、原生 `details`；保持现有 API 客户端和路由组件边界。
- 交互与状态：成功显示最近读取时间；失败、离线、超时保留旧事实；首次失败显示重试；无权限由平台路由保护；加载时禁用重复触发。
- 权限差异：只有具有 `provider:configure` 的平台角色可读；无权限不降级返回部分事实。
- 数据变化：本页只读，不创建、修改、删除或启用来源；实际启用仍由既有配置 API 和三道门控制。
- 不应改变：接口字段、MySQL 结构、Worker/Crawler 调度、固定样本审批和来源启用规则。
- 验收标准：页面、接口、权限、失败恢复、两条联动、桌面/移动端、构建和日志检查全部有证据；真实 1688 登录运行、验证码放行、字段回放及审批在没有真实登录档案时继续标记阻塞，不能宣布生产来源已启用。
