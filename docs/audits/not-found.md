## 4. 每个可操作入口的测试记录

### 4.1 品牌“智能选品”

- 前置条件：未知地址已显示404。
- 操作：点击“返回智能选品今日行动”。
- 预期 / 实际：SPA进入 `/home`；实际一致。
- 重复点击：首次导航后本页卸载，不存在本页重复提交。
- 权限：本页不判断；目标页执行其原有权限和接口合同。

### 4.2 返回最近页面

- 前置条件：先访问 `/ui-states?state=blocked`，再访问未知地址。
- 操作：点击“返回最近页面”。
- 预期 / 实际：返回 `/ui-states?state=blocked` 且恢复“依赖暂时受阻”；实际一致。
- 隐私：404只显示“将返回：界面状态”，不显示 `state=blocked`。
- 边界：最近地址为 `/retired/module?filter=stale` 时按钮降级为“返回今日行动”，不进入404循环。

### 4.3 返回今日行动

- 前置条件：没有独立有效最近页面，或当前提供次要返回入口。
- 操作：点击“返回今日行动”。
- 预期 / 实际：进入 `/home`；实际一致。
- 重复点击：首次导航后本页卸载，无写入、幂等或重复提交风险。

### 4.4 当前地址

- 普通路径：精确显示 `/catalog/deleted-entry`。
- 查询与哈希：`?filter=qa-only#details` 不渲染。
- 长路径：超过96字符时截断为省略号，DOM和布局均不溢出。
- 异常文本：Vue文本插值转义；页面不使用 `v-html`。

查询、筛选、排序、分页、新增、编辑、查看业务详情、复制、删除、批量、表单、弹窗、上传、下载、导入、导出、刷新按钮、重试按钮、暂停、取消、状态日志在该404页均不存在，不能标记为通过，结论为“不适用”。

## 6. 逐页面 UI 审计与优化方案

### 页面定位、使用者与核心任务

这是全角色都可能遇到的恢复页面，不是开发工具。核心任务只有两个：确认地址不存在；用最短路径回到一个真实、已登记且安全的页面。

### 当前问题与证据

- 修改前信息架构把内部状态验收台整页暴露给最终用户，12个入口中只有品牌与两个返回动作属于404业务。
- 用户可点击“加载、空结果、错误、无权限、恢复”等按钮改写真实404结论。
- 失效最近地址可形成404循环，再次点击后URL仍不存在但界面变成空结果。
- 完整最近URL及查询参数直接展示；“或该入口不属于当前角色”把404与403混淆。
- 移动端先展示完整状态组件库，用户需要长距离滚动才能找到真正恢复动作。

### 优化目标与新布局

- 页面区域固定为：品牌头部 → 404信号视觉 → 原因与当前路径 → 恢复动作 → 事实边界页脚。
- 桌面双栏让视觉与恢复信息同屏；780px以下改为单栏，操作按钮全宽。
- 视觉延续概念图72的“信号未抵达”语义，但仅用主题令牌和CSS，不新增图片、动画资源或装饰性业务数据。
- H1是“没有找到这个页面”，当前地址使用次级信息卡；最近目标只显示路由中文标题。

### 组件级与交互调整

- `App.vue` 将 `/ui-states` 与兜底路由拆开，分别挂载 `UiStateShowcase` 与 `NotFoundPage`。
- `NotFoundPage` 使用 `router.resolve` 校验最近地址；`meta.notFound=true` 时回退 `/home`。
- 主操作是“返回最近页面”或“返回今日行动”；只有存在独立有效最近页时才显示次要“返回今日行动”。
- 路由变化后把焦点放到H1；不自动倒计时、不自动跳转、不播放持续动画。
- hover只做1px位移，`prefers-reduced-motion` 下关闭过渡。

### 各状态、响应式、权限与联动

- 加载、空白、错误、无权限和接口超时不在本页伪造；静态页只表达404。
- 390px下视觉缩至270px，当前路径改为上下布局，按钮全宽；桌面最大内容宽1180px。
- 页面无角色差异；目标页继续执行原有会话、capability和数据隔离。
- 与 `/home`、最近有效路由、浏览器历史联动；不新增业务接口和状态变化。

### 不应改变的原有能力

- `/ui-states` 的八状态、URL状态恢复、确认弹窗和内部验收能力全部保留。
- `navigation-memory.ts` 的安全同源存储键、最近成员页和最近组织逻辑不变。
- 路由目录中的兜底路径、标题、`notFound`标记和缓存策略不变。

### 验收标准

1. 开发与生产构建的任意未知深层路径都显示一个可见H1和专用404。
2. 页面不存在状态选择器、确认演示、示例编号或业务数据。
3. 查询参数和哈希不渲染；当前路径不超过96个显示字符。
4. 有效最近页可恢复；失效最近页不得再次进入404或改变404状态。
5. 品牌、主操作和次操作分别到达声明目标。
6. 刷新、前进、后退、长地址和多标签页不改变404事实。
7. 390/768/1024/1440无横向溢出，交互目标不小于44px。
8. 页面不新增 `/api/` 请求、持久化、权限推断或后台任务。

## 8. 性能、安全与企业级缺口

- 性能：本页无API、轮询、图表或大数据；专用页DOM和可操作入口从修改前12个降为默认2个。本地生产预览实测 `domInteractive=19ms`、`loadEventEnd=36ms`、6个已加载资源性能条目、0个API资源；该本机结果仅作为相对证据，不外推生产SLA。
- 容量：只渲染一个最长96字符的路径；不存在分页、列表或并发请求容量风险。
- 安全：查询与哈希不渲染；文本由Vue转义；不输出Cookie、Token、密钥、完整隐私数据或权限事实；失效路由失败关闭。
- 主题：深海蓝、云雾白、极光紫真实截图均保持同一文案、入口和恢复目标，只改变主题令牌视觉。
