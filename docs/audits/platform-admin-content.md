# `/platform-admin/content` 逐页 UI、功能与链路审计

## 页面审计记录

1. 页面名称和路由：内容管理，`/platform-admin/content`；平台后台 / 运营中心 / 内容管理。
2. 服务角色：具备 `platform:operate` 的平台超级管理员、平台运营管理员；平台安全管理员实测 403，未登录实测 401。
3. 业务目标：跨组织读取热点主题事实，按主题、分类、市场和持久化状态检索，对展示/无关/过期状态执行有原因、幂等、版本锁和审计的人工复核。
4. 当前截图：修复前桌面 [desktop-current.png](../../output/playwright/platform-admin-content/before/desktop-current.png)、修复前 390px [mobile-current.png](../../output/playwright/platform-admin-content/before/mobile-current.png)、修复后桌面 [desktop-fixed.png](../../output/playwright/platform-admin-content/after/desktop-fixed.png)、修复后 390px [mobile-fixed.png](../../output/playwright/platform-admin-content/after/mobile-fixed.png)。
5. 可操作入口：刷新、搜索、状态筛选、筛选、重置、列设置、首列冻结、密度、上一页、下一页、移动端记录详情、技术详情、展示、无关、过期、审核原因、取消、确认更新、面包屑、导航与返回用户工作台。
6. 控件结果：逐项结果见“前端功能结果”；不存在“其他按钮正常”的合并结论。
7. 接口：`GET /api/v1/platform/management?domain=content&query=&status=&page=&page_size=`；`PATCH /api/v1/platform/management/content/{topicId}`。真实结果见“接口结果”。
8. 数据表：`trend_topics`、`organizations`、`workspaces`；写链路另涉及 `trend_events`、`platform_management_operations`、`platform_audit_events`；上游投影涉及 `normalized_records`、`raw_evidence`、`trend_projection_jobs`、`trend_signals`、`trend_topic_keywords`。
9. 权限与隔离：该页是明确的平台全局视图，不按当前组织隔离；API 强制 `platform:operate`。超级管理员 200、运营管理员 200、安全管理员 403、匿名 401。响应未返回 Cookie、Token、密码、凭证或原始采集正文。
10. 正常状态：MySQL 5.7 隔离库 136 条（135 条基线加 1 条 Worker 投影证据）可读取；基线 135 条展示 7 页，状态统计为 90/25/19/1。
11. 空数据状态：无匹配查询返回 200、`items=[]`、过滤总数 0，页面显示“当前筛选没有记录”并保留重置与重新加载入口。
12. 加载状态：首次加载显示读取状态；已有数据刷新时保留事实，刷新按钮变为“刷新中…”并禁用。
13. 接口失败状态：首次失败进入故障态；已有事实失败保留上一份事实并显示可执行错误提示。
14. 超时状态：内容读取使用 15 秒 `AbortController` 超时，提示“读取超时，已保留上次成功数据，请稍后重试”。
15. 无权限状态：安全管理员 API 403，匿名 API 401；页面由平台导航守卫进入访问保护态。
16. 表单校验：审核原因 `required`、2–300 字；后端再次校验状态、版本和原因。无效读状态实测 400。
17. 重复提交：确认按钮在请求期间禁用；API 使用 `Idempotency-Key`，同键重放实测 200 且未重复写事件。
18. 刷新和返回：已应用搜索、状态、页码写入 URL；`?status=archived` 刷新后仍保持归档筛选；`?page=2` 刷新后仍为第 2 页。
19. 分辨率：1440×900 与 390×844 实测 `scrollWidth <= innerWidth`；桌面宽表只在表格容器内滚动，移动端使用卡片与具名详情抽屉。
20. UI/交互问题：修复前 100 行同时渲染并撑宽页面、无重置、无分页、归档无文案、置信度显示技术枚举、当前状态仍可重复点击；本批均已处理。
21. 功能问题：修复前全量 135 被报为 100、分页参数无效、非法状态返回成功空集、中文查询 503；本批均已处理。
22. 性能问题：读取从单次最多 100 行改为每页 20 行；当前 `%query%` 和状态计数仍会随全量主题增长而扫描，列为 `CONTENT-P4-011`，未在禁止数据库结构变更的本批新增索引。
23. 安全问题：未发现跨租户泄漏，因为产品契约就是平台全局；写接口已验证同源、权限、幂等、版本锁、原因和审计。未输出任何密码、Cookie、Token 或完整隐私数据。
24. 企业级缺失：缺少独立内容归档/恢复工作流、批量复核、保存筛选视图、导出和全文检索容量方案；这些不是当前页面既有能力，不在本批伪装为已完成。
25. 优化建议：见“逐页面优化升级方案”；保留跨组织事实、三目标审核、四状态读取、版本锁、原因、幂等、趋势事件、平台审计和 Worker 上游投影。

## 逐页面优化升级方案

- 页面定位/使用者/核心任务：平台内容运营事实台；平台运营和超级管理员；快速找出跨组织主题并进行可追责复核。
- 保留能力：跨组织读取、搜索、状态筛选、三目标审核、必填原因、版本锁、幂等、趋势事件、平台审计、Worker 趋势投影、桌面列控制和移动详情。
- 删除或合并：不删除业务功能；当前状态动作从可写按钮收敛为禁用反馈，避免重复写。
- 信息架构：页面说明 → 已应用筛选 → 五项状态事实 → 20 条内容记录 → 分页与观测时间；技术 ID 继续折叠。
- 新布局：桌面使用受控宽表，移动使用卡片/抽屉；摘要不随当前状态筛选失真，分页文字明确过滤结果总量。
- 主要操作：筛选、复核；次要操作：重置、刷新、列设置、密度、翻页、技术详情。
- 表格字段：主题/分类/热度、组织/工作区、市场/语言、信号/来源、置信度/最近观测、状态、操作。
- 筛选条件：主题/分类/市场文本，active/irrelevant/stale/archived；应用后写 URL，草稿不提前请求。
- 表单字段：目标状态、2–300 字审核原因；当前状态不可选取为重复动作，提交期间禁用。
- 弹窗/抽屉：审核使用原生具名 dialog；移动详情显示业务事实，ID/版本置于“技术详情”。
- 状态设计：首次加载骨架文案；空结果保留重置；失败/超时保留旧事实；无权限进入访问保护；成功反馈明确已写审计；冲突提示刷新后重试。
- 动效：只保留现有抽屉/弹窗过渡，不增加阻碍信息读取的装饰动效。
- 响应式：760px 以下卡片，触控目标不小于现有 `--so-touch-target`；桌面宽表内部滚动，不扩大文档宽度。
- 权限差异：运营和超级管理员可读写；安全管理员和匿名不得读取；不引入组织级角色。
- 页面联动：上游 normalized record → Worker trend projection → topic；审核写入 topic/event/audit；下游趋势与机会页消费更新后的真实状态。
- 涉及接口/状态：GET management；PATCH content；读取四状态，写入三状态，版本逐次 +1。
- 验收标准：135 条真实基线显示 7 页；中文检索 200；非法状态 400；四角色结果符合矩阵；审核、重放、冲突、恢复和审计计数可复验；1440/390 无页面横向溢出；控制台无非预期错误。
