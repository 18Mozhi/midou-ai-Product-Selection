## 状态与 UI 逐页审计

- 信息架构：修改前关键新建表单在兼容矩阵之后，1024 像素点击顶端入口仍停在 `scrollY=0`，用户看不到结果；修改后采用“业务说明与动作 → 指标 → 资产 → 档案 → 兼容矩阵”的阅读顺序，所有写操作进入模态任务流。
- 布局与视觉层级：标题区区分最近读取与三个主要动作；真实数据卡增加 Provider 归属，运行档案补全引用关系和版本；未改变暗色平台 Shell、共享表格和确认组件。
- 留白与密度：1440 像素保持多列信息效率；1024 像素动作换行；390 像素单列卡片和底部编辑面板，无横向溢出。
- 字体、色彩与状态：沿用设计令牌；成功和危险反馈不只依赖颜色，均有文本与 live region；秘密字段保持 password 类型。
- 弹窗与动效：使用固定遮罩、明确标题和最大高度滚动，不增加装饰性动效；移动端靠近底部便于触达。
- 空白、错误、加载、无权限：四类状态分别表达，不用空数组掩盖错误；刷新故障与首次故障区别处理。
- 数据可读性与路径长度：Provider 名称进入资产 / 档案主层；来源页深链一步到正确表单，避免先进入页面再手选 15 个登录来源。
- 新用户理解：上传说明明确 Cookie / storageState / Netscape / `.tar.gz`，强调只写不回显；轮换并不等于目标站点登录成功。
- 基础可访问性：具名 `dialog`、`aria-modal`、live region、首字段焦点、Escape、焦点返回、键盘焦点约束和原生校验均有自动化证据。

## 问题记录

### P37-01（P1）`provider_id` 深链错误选择来源

- 所属页面 / 类型：凭证与档案 / 联合流程与数据归属。
- 问题描述：来源页传入真实 Provider UUID 时旧页面只读取 `provider_code`，因而默认选中第一个登录来源。
- 复现步骤：打开 `/platform-admin/credentials?provider_id=<第二来源UUID>&mode=login`。
- 预期 / 实际：应定位第二来源；修改前实际选中列表第一项 1688，存在把登录资料挂到错误来源的风险。
- 证据：修改前真实浏览器深链与新增 `provider_id` 精确定位 E2E。
- 涉及文件 / 接口 / 数据：`CredentialAssetCenter.vue`、E2E；Provider 选项 GET；`providers` 与后续凭证归属。
- 影响范围：从来源管理和 1688 验收进入凭证配置的完整链路。
- 修复建议：优先按 `provider_id` 精确匹配，旧 `provider_code` 仅作兼容。
- 验收标准：两个不同 Provider 的深链分别定位自身，表单与状态卡一致；已通过。

### P37-02（P2）顶部动作打开页面下方隐藏表单

- 所属页面 / 类型：凭证与档案 / UI 与可访问性。
- 问题描述：修改前编辑器位于长兼容矩阵之后，点击顶部按钮既不滚动也不聚焦；1024 像素用户看不到任何结果。
- 复现步骤：在 1024×768、`scrollY=0` 点击“凭证资产”。
- 预期 / 实际：应立即看到并进入表单；修改前焦点留在按钮且表单位于折叠线下。
- 证据：修改前 1024 截图、浏览器焦点 / 滚动值；修改后桌面与移动弹窗截图。
- 涉及文件 / 接口 / 数据：页面组件和 CSS；不改接口与数据库。
- 影响范围：全部创建、轮换、档案和登录资料操作。
- 修复建议：改为固定具名模态框并实现焦点生命周期。
- 验收标准：任意视口一步可见，首字段聚焦，Escape / 取消关闭且焦点返回；已通过。

### P37-03（P2）刷新无截止时间且失败覆盖已知事实

- 所属页面 / 类型：凭证与档案 / 可靠性与性能。
- 问题描述：三项读取发生部分失败或长时间挂起时，旧实现缺少页面级截止、重复保护和旧数据保留。
- 复现步骤：成功读取后令资产接口返回 503，或延迟超过 12 秒并连续刷新。
- 预期 / 实际：应保留统一的上次快照并允许重试；修改前可能转为全页错误或持续等待。
- 证据：故障注入浏览器结果、刷新保留 E2E、12 秒计时验证。
- 涉及文件 / 接口 / 数据：页面组件；三项 GET；只读六张核心表。
- 影响范围：平台安全管理员短暂网络、数据库或服务故障期间的判断连续性。
- 修复建议：三项响应全部成功后再原子提交，12 秒 AbortController、重复触发保护、成功读取时间和保留事实提示。
- 验收标准：503、离线、超时均保留旧资产 / 档案 / 兼容状态，按钮恢复且无额外刷新链路；已通过。

### P37-04（P3）资产与运行档案缺少来源上下文

- 所属页面 / 类型：凭证与档案 / 信息架构与数据可读性。
- 问题描述：修改前卡片突出内部资产信息，但未把 Provider 归属放在主层，跨来源管理员需要靠兼容矩阵反查。
- 复现步骤：创建至少两个来源资产并比较卡片。
- 预期 / 实际：安全操作前应直接确认归属；修改前主卡片信息不足。
- 证据：修改前空状态和修改后真实数据截图。
- 涉及文件 / 接口 / 数据：页面组件；读取接口；不改变表结构。
- 影响范围：轮换和撤销前的人工核对效率。
- 修复建议：资产 / 档案主卡展示 Provider，档案补充引用资产与版本。
- 验收标准：无需展开技术详情即可确认来源和引用；已通过。

### BLK-P37-01（阻塞）真实浏览器下载被本机扩展接管

- 所属页面 / 类型：凭证与档案 / 客户端环境。
- 问题描述：静态 ZIP 直接请求 200，但真实 Chrome 点击由本机迅雷扩展拦截为 204，自动化没有收到下载事件。
- 复现步骤：在当前测试机点击“浏览器助手”。
- 预期 / 实际：浏览器应下载 ZIP；实际请求被第三方扩展接管。
- 证据：静态资源 200、ZIP 类型和字节数；点击网络记录 204 且无下载事件。
- 涉及文件 / 接口 / 数据：浏览器静态资源；不涉及数据库和凭证值。
- 影响范围：当前测试机的用户级下载验证。
- 严重等级：P3 环境阻塞，不判断为产品接口失败。
- 修复建议：在无下载接管扩展的隔离浏览器复验；不为绕过用户扩展修改业务代码。
- 验收标准：隔离浏览器产生下载事件，文件为非空 ZIP；待外部环境复验。

## 单页优化升级方案

- 页面定位 / 使用者 / 核心任务：平台安全资产控制台；安全管理员以最少暴露完成“确认来源 → 加密写入 → 关联运行档案 → 验证兼容 → 轮换 / 撤销”。
- 应保留：AES-GCM、只写不回显、非秘密指纹、不可变版本、幂等、不可逆撤销确认、真实兼容推导、移动摘要、列设置 / 冻结 / 密度。
- 应删除或合并：不删除业务能力；仅把四类散落内联编辑器合并为统一模态交互，把重复的技术枚举放到次级层。
- 新布局 / 区域：页头业务解释和最近读取；主要动作；指标；凭证资产；运行档案；兼容矩阵。所有编辑保持上下文，不将用户送到页面末尾。
- 主要 / 次要操作：主要是配置网页登录、创建凭证、创建运行档案；次要是刷新、下载助手、轮换、撤销和查看技术详情。
- 表格字段 / 筛选：兼容矩阵保持来源、状态、登录资料、运行档案；当前数据量无搜索筛选。达到百级资产时再基于真实 API 增加来源、类型、状态、到期范围筛选与服务端分页，不能只在浏览器过滤部分数据。
- 表单字段：保持现有来源、名称、类型、编码、秘密、到期时间以及档案代码、名称、语言、时区、状态；不把主密钥或明文读取加入页面。
- 状态设计：首次加载骨架 / 文本；真实空状态；首次失败独立恢复；刷新失败和超时保留旧事实；无权限不渲染局部资产；成功与失败均有 live region。
- 交互与动效：打开即聚焦、Tab 约束、Escape / 取消关闭、焦点返回；只使用必要遮罩过渡，不牺牲高密度信息读取。
- 响应式：≥1180 多列；1024 动作换行；390 单列与底部模态，兼容矩阵转摘要卡，禁止横向滚动。
- 权限差异：没有 `key_rotation:manage` 时后端统一 403，不能靠隐藏按钮代替授权；平台全局资产不伪造租户隔离字段。
- 页面联动 / 数据状态：来源页带 `provider_id` 进入；加密写入创建 current + version + operation；档案创建关联资产；轮换产生新版本并可能恢复受阻任务；撤销使兼容状态立即回落。
- 不应改变：API 字段、数据库结构、主密钥配置、Worker/Crawler 所有权、第三方登录规则、凭证轮换与真实登录成功之间的边界。
- 验收标准：本页所有入口逐项有结果；三项 GET 与五类写 / 异常合同有证据；真实 MySQL 5.7 密文和审计成立；桌面 / 1024 / 390、键盘、失败恢复、权限和后台轮询均验证；阻塞项不能写成通过。

## 性能、安全与企业能力缺口

- 性能：三项首屏读取并发且 12 秒有界；本地 181 个来源仍可流畅渲染。缺少面向数千资产的服务端分页、搜索和容量压测，列为 P4 后续能力，不能宣称大规模容量已验证。
- 安全：响应无密文、nonce、认证标签或秘密；同源、会话、权限、幂等、Provider 绑定、格式与域名均失败关闭。未做本批次渗透测试和真实跨浏览器恶意档案测试，标记未验证。
- 审计：版本与操作链已验证，但页面没有独立“查看单资产审计时间线”入口；可联动平台审计页，属于 P4 企业可追溯性提升。
- 生命周期：合成 1688 Cookie 已完成创建、关联、轮换、撤销和临时清理；真实 1688 账号登录、Cookie 过期、验证码 / 风控、页面结构变化、真实解析、失败重跑和服务重启恢复因缺少合法测试账号与可复现风控条件继续阻塞。
