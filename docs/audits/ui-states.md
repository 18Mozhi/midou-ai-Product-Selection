## 4. 状态审计

| 状态                   | 实际结果                                                                                           |
| ---------------------- | -------------------------------------------------------------------------------------------------- |
| 正常 / 默认            | 页面加载为空结果示例；所有正文、编号和动作可见                                                     |
| 空数据                 | 使用 `empty` 状态；不会伪造列表或指标                                                              |
| 加载                   | 骨架、文字和 `aria-busy` 同时存在，不展示旧业务数据                                                |
| 接口失败               | 本页不调用接口；`error` 示例可重试到恢复状态                                                       |
| 超时 / 限流 / 依赖失败 | `blocked` 明确列出原因并提供重试与影响说明                                                         |
| 无权限                 | `forbidden` 不展示受限数据，提供返回与申请边界说明                                                 |
| 登录过期               | `expired` 导航登录页，不自动重放操作                                                               |
| 恢复                   | `recovery` 明确“最新检查通过”并允许继续                                                            |
| 404                    | 未知地址显示最近有效路径；展示页自引用时不会死循环                                                 |
| 表单校验               | 确认框未勾选、短语缺失或不精确时确认按钮禁用                                                       |
| 重复提交               | 确认后弹窗立即关闭，第二次点击目标不存在；本页没有业务提交                                         |
| 刷新 / 返回            | `?state=` 刷新保持；浏览器后退、前进恢复相应状态                                                   |
| 多标签页               | 状态由各标签 URL 独立表达；只共享既有安全最近路径，不共享业务数据                                  |
| 离线                   | 页面静态资源已加载后状态切换可用；首次离线加载受静态站点缓存策略约束，未宣称离线应用               |
| 长文本 / 异常编号      | 编号只允许 `[A-Za-z0-9._:-]{1,128}`；非法值不渲染；文本允许换行                                    |
| 分辨率                 | 1440×1000、390×844、390×667 均验证；390px `scrollWidth=390`                                        |
| 键盘 / 可访问性        | Tab 可达、焦点轮转、Escape、`alertdialog`、`aria-modal`、`aria-live`、`aria-busy`、44px 按钮均验证 |

查询、筛选、排序、分页、新增、编辑、查看、复制、删除、批量、上传、下载、导入、导出在该内部状态展示页均不存在，不能标记为通过，结论为“不适用”。

## 5. UI 逐页评价与优化方案

### 页面定位、使用者与核心任务

该页不是业务工作台，而是状态合同验收台。使用者需要在一个页面内快速比较 8 种状态、操作恢复路径、检查安全关联编号和验证高影响确认，不应被业务导航、模拟数据或虚假成功干扰。

### 当前信息架构与应保留能力

- 左侧保留页面定位、状态选择和确认弹窗入口；右侧保留状态预览、关联编号、动作和明确的“非业务结果”说明。
- 保留 8 种状态枚举、中文语义、非颜色状态符号、真实下一步、404 最近路径和高影响确认失败关闭。
- 不增加统计卡、表格、筛选器、图表、装饰性业务数据或后端演示接口。

### 新布局与组件级调整

- 桌面维持双栏，状态选择与预览同屏；移动端维持单栏、4 列状态按钮和全宽动作，避免增加操作路径。
- 状态选择器关联 `aria-controls=ui-state-preview`；当前状态继续使用 `aria-pressed`。
- 动作结果紧邻状态预览，以独立 `role=status` 文本呈现，避免点击后“看起来没发生”。
- 高影响弹窗最大高度使用动态视口，正文在弹窗内滚动；确认/取消保持可达，背景禁止滚动。

### 各种状态、反馈、动效与响应式

- 加载保留骨架动画，并继续尊重 `prefers-reduced-motion`。
- 成功、失败、阻塞、无权限均同时使用符号、标题和文字，不依赖颜色。
- 状态切换写入 URL，不新增自动轮播或装饰动效；刷新和历史导航是主要连续性机制。
- 390px 不横向滚动；390×667 弹窗内部滚动；桌面保持信息同屏效率。

### 权限差异、页面联动与数据状态

- 本页没有权限差异或数据状态变化；无权限与过期仅展示合同，不推断真实身份。
- `/home`、`/login` 和未知路由只验证站内导航；目标页的接口、权限和数据不计入本页通过结论。
- 不应改变 `UiStatePanel` 在业务页只发事件、由所属业务模块决定 API、幂等、审计和权限的原有能力。

### 验收标准

1. 生产构建 `/ui-states` 必须存在一个可见 `main`，不得 HTTP 200 空白。
2. 8 个状态按钮逐个可达，状态、URL、刷新和历史导航一致。
3. 每个状态动作必须导航、切换状态或给出明确反馈，不得静默无效或伪造业务成功。
4. 高影响确认必须失败关闭；390×667 下弹窗与底部动作可达，背景锁定并在关闭后恢复。
5. 页面停留期间无 API、数据库、Worker、Crawler、上传、下载或通知副作用。
6. 桌面/移动 E2E、生产预览、类型检查、合同测试和构建全部通过。

## 6. 问题记录

### UI-STATE-001 — P1 — 生产构建路由空白

- 所属页面 / 类型：`/ui-states` / 功能、发布。
- 问题描述：权威路由被 `import.meta.env.DEV` 二次屏蔽，生产构建返回应用 HTML 和正确标题但不渲染任何页面主体。
- 复现步骤：构建 Web；启动 `vite preview`；打开 `/ui-states`；检查正文和 `main`。
- 预期 / 实际：预期渲染状态验收台；实际修改前 `body.innerText=""`、`mainCount=0`。
- 证据：`before-production-blank.png`；生产浏览器 DOM 结果。
- 涉及文件：`apps/web/src/App.vue`。
- 涉及接口 / 数据：无。
- 影响范围：发布后内部验收页完全不可用；不影响其他业务路由。
- 修复建议：权威 `route.meta.view=ui-states` 始终渲染，仅把任意 `?view=` 调试入口保留在 DEV。
- 验收标准：生产预览正文非空、`mainCount=1`、状态标题可见。
- 结果：已修复并通过。

### UI-STATE-002 — P2 — 状态刷新链路和动作不可验证

- 所属页面 / 类型：状态选择与所有状态动作 / 功能、交互。
- 问题描述：按钮切换不写 URL，刷新丢失；开始创建、调整筛选、返回工作台、重新登录、继续等多个动作静默无效；错误“返回上一页”只切空状态且无说明。
- 复现步骤：打开页面；选择任意非空状态并刷新；逐个点击状态动作；观察 URL、状态与反馈。
- 预期 / 实际：预期状态可恢复且每个动作可验证；实际刷新回空，多项按钮点击后 URL、状态和反馈均不变。
- 证据：修改前真实 Playwright 快照与动作后 `status=[]`；修改后 E2E 16/16。
- 涉及文件：`UiStateShowcase.vue`、`tests/e2e/m02-04-ui-states.spec.ts`。
- 涉及接口 / 数据：无。
- 影响范围：无法用该页可靠验收组件合同，操作文案与实际行为不一致。
- 修复建议：枚举写入 `?state=` 并监听路由；动作必须导航、切换或显示诚实反馈；同页最近路径避免自引用死循环。
- 验收标准：刷新/前进/后退一致，全部状态和动作有断言。
- 结果：已修复并通过。

### UI-STATE-003 — P2 — 短视口确认弹窗底部越界

- 所属页面 / 类型：高影响确认弹窗 / UI、可访问性。
- 问题描述：390×667 下弹窗高约 695px、底部约 713px，超过视口且背景仍可滚动。
- 复现步骤：设置 390×667；打开确认弹窗；测量弹窗边界与 body overflow。
- 预期 / 实际：预期底部动作可达且背景锁定；实际底部越界、`bodyOverflow=visible`。
- 证据：修改前/后短视口截图；修改后边界 18–649px、`bodyOverflow=hidden`。
- 涉及文件：`ConfirmDialog.vue`、`onboarding-navigation.css`。
- 涉及接口 / 数据：无。
- 影响范围：短屏用户可能无法可靠完成或取消高影响确认；共享确认组件的现有消费者受益但事件合同不变。
- 修复建议：动态视口最大高度、弹窗内部滚动、背景滚动锁与卸载恢复。
- 验收标准：弹窗边界不超视口、按钮可见、Escape 还焦、关闭后 body 恢复。
- 结果：已修复并通过。

### UI-STATE-004 — P4 — 全局 favicon 请求 404

- 所属页面 / 类型：全站静态资源 / 建议性基线。
- 问题描述：开发与生产预览均请求 `/favicon.ico` 并返回 404。
- 复现步骤：全新浏览器打开页面；查看控制台。
- 预期 / 实际：预期静态图标存在或不发起请求；实际记录一条 404。
- 证据：修改前后全新会话控制台均为同一 favicon 404。
- 涉及文件：全局 HTML/静态资源，非本页文件。
- 涉及接口 / 数据：无业务接口、无数据。
- 影响范围：浏览器控制台噪声与品牌细节，不影响本页功能。
- 修复建议：在后续全局静态资源批次补充真实 favicon 并验证生产路径。
- 验收标准：全新会话不再出现 favicon 404。
- 结果：未修复；严格保留为范围外基线。

## 7. 性能、安全与企业级缺口

- 性能：页面仅静态 Vue 组件，无 API 等待、轮询、分页或大数据量；1440 与 390 实测即时交互。未发现本页容量风险。
- 安全：不输出密码、Cookie、Token、密钥或隐私数据；关联编号强制安全字符和 128 长度；确认弹窗默认失败关闭；无跨租户数据面。
- 企业级缺口：P1–P2 已在本批闭环。剩余仅全局 favicon P4；离线首次加载、真实权限申请、真实业务写入不属于该内部展示页，不能以 Mock 补齐或宣称通过。
