# 货源报价不进入情报分析

## 依据与实现

用户要求先分析情报寻找Amazon商品，再通过LAN1688取得进货报价。2026-10-18北京时间04:46只读核验发现7787个1688趋势投影排在20个新RSS任务前。旧代码还把1688当作电商趋势来源、供应商名称映射为新闻发布方。这些入口现已删除；趋势补偿不再为新1688规范化证据创建任务。

历史已排队任务不删除、不改原始报价。Worker照常逐个领取租约，以既有空结果完成路径处理，每轮最多20个不支持的来源任务；若提前遇到有效任务，当轮继续正常分析。过期租约、完成失败传播、事务与历史补偿周期保留。历史供应商主题仍可读取，不伪装成已分析新闻。

报价继续由找货投影和自动评估读取，六个LAN节点、主品图片、进货价格、匹配、评分、Amazon发现与竞品详情不变。不以报价条数或旧主题数充当每日整链完成数。
