# 组织成员、工作区与团队目录重制

依据当前用户的全站 UI、布局和流程重构要求，以及已经查看的 Ecom168 工作区，组织后台三个目录改为紧凑、实色、数据优先的工作区。

- 成员列表、筛选和分页前置，邀请表单与邀请历史移到其后；列表提供页内“邀请成员”入口。
- 工作区和团队采用全宽目录、全宽所选详情，取消旧窄目录/侧详情双栏。页内“定位所选详情”只改变当前页面片段。
- 统计改为有边框的紧凑指标行，移除大渐变面板、装饰首字块、重复说明标题和空态装饰符。团队列表使用原生 `ul/li/button`，保留原选择处理器和稳定 ID。
- 删除旧组织样式中的 416 个相关选择器，原文件净减少 1689 行；其他域的选择器未纳入删除。清理三个确认未被任何生产组件引用的 `--oa-*` 颜色变量。新样式使用现有 `--so-*` 语义变量。

## 运行边界

三个子组件及 `OrganizationAdminCenter.vue` 的脚本逐字不变，原生事件与表单绑定集合不变。原筛选、排序、分页、邀请角色、创建约束、版本、幂等、审计、默认工作区不可归档、团队创建后重读失败恢复及成员关系写入均沿用已有链路。没有新增依赖、环境变量、HTTP 字段、数据库或权限规则。

桌面/手机业务回归 28 项通过，包含邀请原因弹窗取消/焦点/单次提交、工作区创建归档、团队创建和成员分配、创建成功但读取失败后的仅重读恢复，以及成员邀请结果。全宽布局、页内跳转目标可见、团队原生按钮和无横向溢出共六项检查通过。Web 类型检查与构建通过。浏览器使用已有本地 API 响应夹具，不证明生产写入或真实选品整链产出。
