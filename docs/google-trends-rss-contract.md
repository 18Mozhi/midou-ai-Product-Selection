# Google Trends RSS词条与证据合同

## 真实依据

2026-10-18北京时间05:05，美国现有固定RSS返回10个词条，均没有guid、共用同一个link；旧通用解析器使用link去重，只有1个独立身份。description为空，新闻标题位于ht:news_item/ht:news_item_title。此次专用解析依据实际XML，未猜测JSON接口、免费API密钥或私有端点。

官方[Trending now说明](https://support.google.com/trends/answer/3076011?hl=en)列出RSS导出；[使用与引用说明](https://support.google.com/trends/answer/4365538?hl=en)要求引用Google并遵守其条款，且明确Trends与Google Ads为不同来源。现有采集策略检查允许该固定RSS，真实健康检查可解析；这些仅是技术证据，不代替第三方许可授予或生产整链验收。

## 解析与保存

已有10个Google Trends目录项采用google-trends-rss-v1及google-trends-rss-adapter-v1；其他RSS/Atom保持原解析器与身份。词条身份根据版本、原始公共链接、原始标题和发布时间确定，与排列顺序及采集时间无关，重复相同词条只保留一次；缺少发布时间以source_changed失败，不补当前时间冒充发布时间。observedAt为实际采集时间，published_at保留原始发布时间。

原始新闻标题按原文拼接为最多2000字符的上下文，保留XML及字段溯源。规范记录键保持词条身份，证据去重键额外包含原文内容哈希：相同内容跨任务复用，内容变化保存新的不可变证据与记录版本，不覆盖历史。流量档位保留在原始XML，不伪造成销量、广告花费或利润。普通RSS及按任务保存商品快照的合同不变。

健康检查读取最多20个样例，而非只看第一条。目录、注册工厂、自动规则/全量来源、立即刷新来源、首页可用来源与实时核验脚本同步识别新解析版本。生产启动同步目录合同不批准条款、不清空熔断；只有经当前健康检查和内部审查的具体来源可按已有业务服务放行，其他国家不批量批准。
