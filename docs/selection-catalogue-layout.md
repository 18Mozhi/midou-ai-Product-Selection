# 选品库布局重制

按用户重制要求，参考已登录 Ecom168 的固定侧栏、标题操作行与分区筛选组织，选品库移除旧大蓝横幅及渐变标题，使用紧凑标题、操作行、页签与筛选区。图卡/列表及真实主品资料保持现有数据语义。

## 本次范围

- `OpportunityWorkspace` 标题改用独立目录工具栏；创建、规则管理、手工添加、ERP 导入和只读状态保留原权限与触发逻辑。
- `OpportunityListPanel` 使用目录控制区，四个商品视图在手机同一行；市场、完整度、阻断原因、阶段、负责人、关键词、全部视图决策状态沿用原请求。
- 规则配置状态压缩为摘要行，真实完成数、下一步、未知状态与可展开五项明细保留。该区域仅说明配置准备情况，不能当成采集已运行或商品已合格。
- 删除所有旧 `opportunity-hero`、`opportunity-view-bar` CSS 规则，以及只剩这些旧规则的 `OpportunityWorkspace.css`、`opportunity-selection-entry.css` 和对应引用。新样式位于 `apps/web/src/selection-catalogue.css`。

## 验证与使用

在 `/opportunities` 使用原四个视图和筛选。桌面直接筛选，手机通过高级筛选抽屉；配置明细仍可展开。无需新增配置。

定向浏览器验证检查标题透明背景、旧结构不存在、首个商品进入首屏、图卡/列表切换、手机筛选保留、视图对应真实请求。完整选品回归覆盖创建、权限、异步返回隔离、详情、评分、竞品、找货与决策。截图必须来自真实 Vue 组件和明确模拟的数据，不能当成生产数据验收。

本项只改前端展示，无 API、数据库、环境变量、依赖或 Worker/Python 运行合同变更，OpenAPI 不适用。发布需本地构建前端并通过既有宝塔部署脚本发布；本项代码不要求 Node/Python 重启，整体运行包发布仍按现有脚本执行。当前未部署，不代表整体 UI 重制、持续自动选品或每日百品已验收。

本地验证结果：19 项机会模块检查通过，桌面与手机共 126 个独立场景通过，另有 6 项定向检查；前端类型检查与构建、格式、文档、路由、静态检查、资源预算均通过。只有列表截图基线更新，详情基线未变。临时截图清理，测试服务停止；未部署。
