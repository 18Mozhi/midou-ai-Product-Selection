# UI 重构与五项问题验收

用户目标：实质重构 UI/布局；修复审批页面切换后布局错位；增加退出登录；登录默认恢复当前组织/工作区并进入用户工作台；持续监听并输出真实新品。五项全部验证前不能签收，不以单项通过代替全目标。

## 同行调研与设计方向

已访问官方页面及实际界面参考：

- [Helium 10 Black Box](https://kb.helium10.com/hc/en-us/articles/6710274045339-Black-Box-Product-Tab-Overview)：筛选条件、结果工具条、商品结果为主，深入筛选收进侧边抽屉。
- [Jungle Scout Opportunity Finder](https://support.junglescout.com/hc/en-us/articles/360037689513-Opportunity-Finder)：市场/类目/筛选与结果层次明确；只参考交互结构，不移植其评分或业务规则。
- [Linear Inbox](https://linear.app/docs/inbox)：队列优先、低干扰的状态与详情阅读层次。

下一版应将首页改为实际商品发现工作台，以结果流、监听状态和待处理事项分区；压缩重复标题/上下文大栏，重新组织导航、页面工具条和详情阅读区域。毛玻璃用于边界和浮层，不以换色、增大圆角代替布局设计。普通用户界面不放开发与验收说明。

## 运行与调节

- 首页仅在页面激活且浏览器可见时每 5 秒重新读取汇总，重新聚焦立即读取；离开缓存页中止请求并停止计时，401/403 清除旧快照。该间隔是 HomeDashboard.vue 的 HOME_REFRESH_INTERVAL_MS，不改变后端采集频率；实际来源和监控规则仍按既有分钟间隔、限流和队列预算运行。
- 退出入口位于角色壳层顶栏及个人中心；复用既有 POST /auth/logout，成功或会话失效完整跳到 /login，失败保留提示并允许同幂等键重试。
- 当前或最近有效组织/工作区恢复后进入 /home；仅有一个有效组织时使用其有效默认工作区。没有历史且多个组织的默认政策仍待明确，不跨租户猜测。
- 来源全受阻或失败不能再标记空成功，复用 completed_with_warnings；首页对应规则显示需要检查。API、Worker 需要通过宝塔重启加载新运行包，静态前端需上传后刷新。
- 2026-10-16 用户明确允许既有公开商品来源，并确认以 user-approved-20261016 长期有效登记。Amazon 美国畅销榜和 eBay 美国热门折扣分别通过服务器真实匿名解析探针后，逐条保存为定义版本 2，保留原始 60 分钟/并发 1/超时 30000ms/重试 2。历史熔断分别通过既有健康门禁恢复；最终持续产出仍需实际任务和入库证据，不以探针或审批代替。

没有新增依赖、环境变量、路由、API 字段、数据库迁移；匹配关键词、来源门槛、推荐五项质量门和权限保持原约束。没有修改历史审核状态或 verification/state.json。测试曾意外覆盖旧图包三张图片；原清单和哈希保留，恢复及独立候选的具体情况见 [历史测试图恢复记录](ui-regression-evidence-recovery-20261016.md)。这三张图尚未恢复为原哈希，不能描述为历史证据完整通过。
