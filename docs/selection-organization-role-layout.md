# 组织角色与权限工作区重制

本次按用户的全站 UI、布局重制要求，沿用已经查看的 Ecom168 工作区方向，重做 `/org-admin/roles` 正文。

- 紧凑四项指标和横向分区，替换独立大指标卡。
- 角色目录与所选详情改为上下全宽，去除首字装饰块；提供本页定位入口。
- 能力矩阵按接口实际角色数量生成列，横向滚动限制在矩阵内部。
- 数据范围先展示当前会话及实际成员，范围定义改为紧凑行并置后。
- 指定资源授权列表及详情全宽，创建和延长表单使用统一实色、13px 文字、44px 控件与关联错误提示。
- 删除旧共享 CSS 中 180 个角色域选择器、净 650 行，以及组件内旧 scoped 样式。删除一个已无生产引用的 `--oa-danger` 变量。593 条非角色页面规则的选择器、声明、媒体范围及顺序逐项对比保持一致。
