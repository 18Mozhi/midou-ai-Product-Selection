# M02-03 三套导航壳层

## 范围与视觉依据

本模块交付普通成员、组织管理员和平台管理员相互独立的顶部栏、侧栏、移动导航与路由状态。布局依据概念图 11、15–17、55–71，以及高清图 `01_scoutops今日行动中心驾驶舱.png`、`09_赛博风组织管理后台仪表盘.png`、`10_霓虹科技平台驾驶舱_dashboard.png`。图片中的指标、头像、通知数和业务数据均不作为事实，本模块不提前实现 M02-05/M02-06 或后续业务页面。

## 服务端 Guard 与数据边界

- `GET /api/v1/me/landing` 先验证 HttpOnly 会话，再按真实平台角色、当前组织管理员角色、普通成员上下文的优先级返回 `/platform-admin`、`/org-admin`、`/home` 或 `/select-context`。公开根路径 `/` 和登录/MFA 成功后都消费该结果，不再默认打开成员壳层或设备会话。
- `GET /api/v1/me/navigation?shell=member|organization_admin|platform_admin` 再由 `AuthorizationService.guardNavigationShell` 读取真实角色、能力及可选租户上下文。
- 成员壳层要求活动成员资格和已选组织/工作区；组织后台额外要求 `organization_admin`；平台后台要求任一真实平台角色，且不依赖组织上下文。
- 每次允许或拒绝写入现有 `authorization_decisions`，保留 actor、组织/工作区（适用时）、代表能力、结果、原因、`request_id` 与 `trace_id`。前端菜单只是服务端结果的展示层，不能代替后续 API/Worker/导出/文件/事件/SSE Guard。
- 菜单只使用服务端返回的 capabilities 过滤。三个壳层不会互相混入菜单，也不读取其他组织数据。

## 持久化、异步与配置

导航摘要从 M01 的会话上下文、成员、角色、能力和平台角色实时派生，无需新增数据库迁移；审计复用已有决策表。本模块为同步只读请求，不新增 Worker、Crawler、Outbox、Redis 队列、文件、导出或 SSE。浏览器继续只使用既有 `VITE_API_BASE_URL`，无需新增环境变量、密钥或面板外服务。

## 页面与异常状态

桌面采用独立顶部栏、侧栏和主内容区；成员壳层提供组织/工作区、搜索、创建、通知和个人入口，组织/平台后台不暴露需要成员工作区上下文的搜索与通知入口。840px 及以下的三个壳层统一显示最多四个有权主入口和一个“更多”，固定底栏恒为五列；“更多”打开完整的权限过滤抽屉，创建选品、邀请成员和新建组织不再占用第六个底栏位置。加载、401 登录失效、403 无权、409 未选上下文、429 限流、依赖失败均提供文字、下一步及可用时的 `request_id`。

浏览器历史由 Vue Router 管理，业务组件按需加载并由最大 12 项的 `KeepAlive` 保留有界页面状态。`docs/feature-map.json` 的前端路由路径必须唯一，`/me` 只允许映射到一个 `PersonalCenter`；采集调度菜单与页面一级标题统一为“采集调度”，页面内部模块标题不得冒充第二个页面标题。390px E2E 滚动到采集调度页的最终运行交接信息后，直接比较该元素与固定底部导航的视口边界，重叠像素必须为 0。
