# M02-04 通用状态组件

## 范围与依据

本模块提供加载、空、错误、无权限、登录过期、依赖受阻、恢复、404 和高影响确认弹窗的统一合同。404 视觉层级参考概念图 `72_404页面.jpg`，其余状态继承图片包总览、M02-01 主题令牌和 P02 响应式规则。组件只表达真实状态和下一步，不生成业务数据、权限结果或成功结论。

## 状态与交互合同

- `state-contract.ts` 固定状态枚举、HTTP 状态映射、安全关联标识过滤与确认校验；401、403、404、限流/超时/依赖失败不会混成普通空状态。
- `UiStatePanel` 同时提供文字、符号、说明、动作以及安全格式的 `request_id`/`trace_id`；颜色不是唯一语义。
- `ConfirmDialog` 使用 `alertdialog`、`aria-modal`、初始焦点、Escape 取消和焦点循环。高影响操作必须确认影响范围；配置确认短语时还必须精确输入。
- 确认组件只发出 `confirm`/`cancel` 事件，不能自行调用 API。实际写入仍由所属业务模块执行权限、幂等、版本锁、审计和错误处理。

## 数据、API、权限、异步与配置

状态是当前浏览器渲染信息，无需数据库迁移，不持久化组织或工作区数据。组件消费现有 OpenAPI 成功/错误信封，不新增字段、路由或权限。它不访问 MySQL、Redis、Worker、Crawler、Outbox、文件、导出、事件或 SSE，也不新增环境变量。无权限状态只能显示服务端拒绝，不得在浏览器推断或提升权限。

## 集成与异常

`/ui-states` 是开发与验收展示面；未知前端路径渲染 404。页面提供桌面、390px 和键盘路径。错误、受阻与恢复均有明确动作；关联标识不符合 `[A-Za-z0-9._:-]` 或超过 128 字符时不显示，避免把任意敏感文本当作诊断标识输出。
