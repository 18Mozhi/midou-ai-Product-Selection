# M02-01 设计令牌与主题

## 范围

本模块保留 `deep-ocean`、`aurora-purple`、`cloud-white` 三个持久化兼容 ID，但用户界面分别显示为“信号纸”（默认）、“档案纸”和“净页白”。三套纸张共享“Signal Ledger / 信号账页”设计语言、`standard` / `compact` 两档页面密度和同一个主题设置页。主题只改变纸张底色及语义色明度；密度只改变桌面导航间距和正文留白；权限、组织/工作区范围、功能可见性和业务结论保持不变。完整页面、按钮与弹窗设计依据位于 `design-plans/ui-redesign-2026-09-05/`。

## 数据与同步合同

- `user_ui_preferences` 以 `user_id + organization_id + workspace_id` 唯一，默认未落库时返回 `deep-ocean`、`source=default`、`version=0`。
- PUT 使用 `expected_version` 乐观锁和 `Idempotency-Key`；偏好、审计、幂等操作在一个 MySQL 事务提交。
- 会话必须已选择活动组织与工作区；服务端重新校验活动成员、组织和工作区，不接受浏览器传入范围。
- 审计只保存主题标识、范围、版本、`request_id` 与 `trace_id`，不保存 Cookie、令牌或页面数据。
- 密度不扩展现有 API、数据库或浏览器存储白名单：成员后台在当前单页会话内切换，组织和平台后台进入时使用紧凑密度，离开后台后恢复成员会话选择。
- 当前桌面表格统一使用会话内列显示、首个可见列冻结和局部标准/紧凑密度控制；至少保留一列，设置不写入 API、数据库或浏览器存储。移动端继续使用摘要卡片和详情侧栏，不受桌面列设置影响。

## 不适用项

- 偏好写入是同步用户操作，不创建 Worker、Crawler、Outbox、队列、SSE 或重试任务；失败直接返回明确错误并允许用户刷新恢复。
- 不新增环境变量、密钥、文件、导出或下载合同。`config/env.example` 保持不变，生产 API 继续使用既有 MySQL 与会话配置。

## 无障碍合同

状态同时使用图标、文字和说明；图表同时提供数值、时间范围、来源与新鲜度。主题和密度选择使用 `radiogroup`/`radio` 语义并支持键盘，焦点样式与减少动态效果偏好均由令牌层统一处理。正文和表单控件保持 16px 基线，元数据与辅助说明不低于 13px；所有密度和断点均保持 44px 触控目标。主题页同步预览成员、组织和平台三套壳层。

所有业务原生弹窗通过统一控制器进入浏览器模态顶层，由浏览器约束页面外焦点，支持 Escape 关闭并在关闭后把焦点归还给触发控件。通用高影响确认框和移动筛选抽屉保留自有呈现，但同样显式实现 Tab 焦点环、Escape 关闭与触发控件焦点归还。

## 语义颜色合同

语义颜色门禁覆盖独立 CSS 与 Vue 单文件组件的 scoped style；除 `design/tokens.css` 的主题定义外，生产样式不得直接写十六进制、`rgb()`、`rgba()`、`hsl()`、`hsla()` 颜色或 `!important`。`signal-ledger.css` 是所有生产页面的视觉合同层，页面必须使用背景、纸张、正文、边框、主色、信号、状态和图表角色，避免主题切换后出现固定颜色区域。

- 业务组件只能消费 `--so-bg`、`--so-panel`、`--so-text`、`--so-border`、`--so-primary` 及成功、警告、危险、信息等语义角色，不直接固定主题色值。
- 柔和背景、强调边框和遮罩由令牌层使用 `color-mix` 派生。普通内容不使用漂浮阴影；只有模态签认单和索引下拉可使用硬边位移阴影表达层级。
- 主色或状态色背景上的文字使用 `--so-on-primary`；正文与次要说明分别使用 `--so-text` 和 `--so-text-muted`。朱砂色只突出每页主动作和重要索引，酸性绿只标记待关注信号，核验绿只表达通过或已连接状态。
- 所有圆角令牌为 0，业务页不使用蓝紫渐变、霓虹光晕或圆角卡片墙。页标题使用中文宋体类展示字，正文使用界面字体，元数据使用等宽字体；认证内容最大宽度为 1440px。
- 通用确认框采用“动作级别、标题、说明、影响范围、必要签认、取消/确认”的影响清单结构；原生原因弹窗和发现弹窗遵守同一朱砂顶线、方形纸张与焦点归还合同。
