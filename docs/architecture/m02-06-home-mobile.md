# M02-06 首页与移动壳

## 范围与依据

本模块实现 `/home` 的今日行动、变化雷达、我的关注、数据健康和空状态布局，以及 390px 首页和机会详情路由骨架。视觉直接参考高清“今日行动中心驾驶舱”和概念图 11–14、53–54；业务真相遵循总纲 3.2。P03–P05 尚未交付的趋势、机会、任务和来源数据不会用示例指标替代。

## 真实读取模型

`home_dashboard_items` 是可重建首页投影，保留组织、工作区、受众用户、类型、标题、原因、站内路由、capability、行动优先级、负责人标签、截止时间、来源数、观测时间、严重级别和来源版本。UUID 与 capability 使用 ASCII，文本使用 `utf8mb4`，兼容 MySQL 5.7。

`GET /api/v1/me/home-dashboard` 先解析活动会话上下文并同步审计 `task:read` 授权，再按精确组织、工作区、capability 和站内路由查询。健康项必须精确命中当前用户；其他项允许工作区共享或当前用户受众。行动由 MySQL 按 `逾期 > 阻断 > 高风险 > 高价值 > 普通` 排序并最多返回五项，其他区块也有固定上限。

## 生产者、异步与非目标

本模块只提供同步投影读取。未来 P03–P05 的所属资源模块在自身真实事务完成后维护投影；本模块不创建 Worker、Crawler、Outbox、队列、事件、文件、导出或 SSE。机会详情只提供响应式路由与信息分区骨架，不读取、计算或显示 P04 尚未交付的评分、利润、风险和证据。

无数据时返回四组空数组，前端提供“开始一次选品、添加竞品、从 1688 找货”入口并明确未接入状态。无新增环境变量或密钥，浏览器继续只使用既有 `VITE_API_BASE_URL`。
