# 选品库主品资料

商品图卡与列表直接显示主品售价、评分和评价数、公开购买提示、类目排名、广告标记及资料时间。缺失显示待采集，不生成估算销量或广告花费。

## 数据合同

`GET /api/v1/opportunities` 和机会详情的 `OpportunitySummary` 增加可空 `primary_product`，见 OpenAPI 与共享 `SelectionPrimaryProductFacts`。价格、币种、评分、评价数均来自原始 Amazon 标准化记录；公开信号只投影购买提示、排名与实际广告标记，不传评价正文或私有广告指标。购买数量为公开下限，不等于精确月销量。

关联证据与详情快照均限制当前组织、工作区、机会和已确认主品 ASIN，并校验 Amazon 商品网址。按实际观察/采集时间选择较新记录，同时间优先详情；新记录缺字段不借旧值补齐。图片只允许已有 Amazon 图片主机，不再拿新闻图片或其他竞品图片代替主品。

## 查询与运行

列表先按原筛选排序分页，再物化每行主品身份，避免为每条证据重复执行身份子查询。MySQL 5.7 使用现有原始证据索引，不新增表、索引或依赖。真实生产数据库只读事务验证 20 条列表耗时 839ms，写入零次；这是单次查询证据，不代表并发性能或生产部署验收。

页面提供图卡/列表切换，无新增配置。发布需要本地构建前端与后端，经既有宝塔脚本上传并重启 Node 项目；Python 未改，不需要因本项重启。当前仅本地实现，未部署，持续采集和每日百品尚未验收。

## 验证

单元测试覆盖最新事实选择、缺失状态、图片主机、租户/ASIN 关联、白名单字段及分页物化；现有机会模块与合同测试覆盖读写权限及详情。浏览器分别验证桌面和手机图卡、列表、事实显示与缺图状态。

本地验证：61 项相关单元/合同检查通过；桌面和手机共 126 个独立浏览器场景覆盖通过，新增资料区另做定向复验。前后端、Worker 构建及文档、路由、静态检查和前端预算检查通过。临时截图在检查后删除，回归基线为永久测试资产。
