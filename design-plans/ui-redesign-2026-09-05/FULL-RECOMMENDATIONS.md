# ScoutOps 全套 UI / 布局 / 样式 / 效果重构建议

## 0. 重构结论

本稿不是旧 UI 的换色或微调。旧版的深色海洋主题、蓝紫强调、固定左侧栏、等权指标卡、圆角面板、证据轨构图全部停用。新方向“信号账页 / SIGNAL LEDGER”把产品定义为跨境选品团队的决策编辑台：市场噪声进入信号目录，真实资料进入账页，最终动作以可追溯签章完成。

## 1. 全局设计语言

- **使用者**：刚看完市场/竞品/供应链变化，马上要分配任务、审批或记录决定的选品经理、采购成员和治理人员。
- **物理隐喻**：研究纸、油墨、荧光批注、朱砂签章、版本账线。
- **产品签名**：页面上方的“信号带”持续显示范围、核验时间、待处理量和数据状态；高影响动作进入“影响清单 + 决策签章”。
- **导航**：桌面从左侧树形栏改为顶部身份条和横向模块索引；页面内部只显示当前任务的章节索引。
- **布局**：列表使用连续账页；详情使用卷宗；规则使用版本簿；管理端使用异常优先的运营台账。
- **视觉**：米白纸张为主，油墨黑建立层级，朱砂仅用于唯一主行动，荧光绿只标出当前范围与待决事项。
- **字体**：中文衬线承担标题和结论，无衬线承担正文与控件，等宽字体承担编号、时间、版本和状态。
- **边界**：0 圆角、无渐变、无装饰性阴影；结构由账线、纸张层和密度变化形成。

## 2. 组件与交互合同

- 主按钮每页最多 1 个，44px 最小热区，文案使用动作 + 对象，完成后进入下一节点时显示箭头。
- 次按钮不使用品牌色；危险按钮使用深红并强制进入影响确认，不用普通浏览器 confirm。
- 输入框使用内嵌灰纸层；错误、帮助、字符限制紧贴字段，不在页面顶部统一堆放。
- 列表筛选、选中数量、批量操作与结果总数保持同一视觉水平线；移动端变成全屏筛选页。
- 弹窗不使用圆角悬浮卡片，统一为“编号、动作标题、影响清单、输入/校样、审计字段、操作区”。
- 加载、空、错、无权限、离线、受阻、会话过期、恢复八态都必须说明影响、保留内容和恢复动作。
- 动效只使用 opacity/transform：按钮 120–160ms，面板 220ms；高频表格和命令入口不做入场动效。

## 3. 响应式合同

- 1440px：身份条 + 横向模块索引；内容最大宽度 1380px；主次区域按页面任务不对称分配。
- 390px：页面变成行动卷轴；数据表变成字段化记录；详情签章区移到正文之后；底部命令坞固定 4 个高频入口 + 更多。
- 触控目标不小于 44×44px；固定底栏预留安全区；标题、操作区、长路由和技术编号不得造成横向滚动。
