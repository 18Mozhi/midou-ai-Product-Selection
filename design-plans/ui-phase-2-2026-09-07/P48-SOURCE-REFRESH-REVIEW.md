# P48 · 来源目录刷新保留实际 Vue r1

## 本批范围

以当前真实路由 `/platform-admin/providers/sources`、ProviderRuntimeSurface → ProviderSourceCenter、现有刷新函数和 M03-07 的 146 条权威 fixture 为准。本批覆盖刷新中、刷新成功、429、503、500及12秒超时，明确刷新期间和非权限失败后继续显示上一次成功目录。Vite 只在审核宿主中精确变换当前 SFC 并加载 P48 刷新 CSS；**生产 SFC、脚本、API、权限、数据库和数据均未改，未部署**。

pbakaus/clarify 用于区分“正在更新”“更新完成”“暂时受阻”和“普通失败”，让每个反馈说明保留了什么及下一步动作；jakubkrehel/better-accessibility 用于稳定 `aria-live` 宿主、44px重试、键盘激活、禁用按钮前的标题焦点和完成后的焦点保持。

## 刷新与恢复

- 刷新开始后，146条结果口径与当前页20条来源继续显示；提示不虚构百分比、阶段或完成时间，旧请求号立即清除。
- 刷新成功采用绿色状态边和简短“来源目录已更新”，请求号进入原生“技术详情”，不再挤在旧米灰提示条正文中。
- 429与503继续使用现有三次安全GET重试；500只尝试一次；三者失败后均明确“已保留上一次成功加载的来源目录”。
- 12秒超时显示已有真实超时文案，不展示初次加载的旧请求号。
- 失败状态只保留一个“重新加载目录”入口；原标题区刷新按钮在该状态隐藏。键盘触发刷新后焦点先移到持续页面标题，失败时进入重试按钮，重试成功后回到标题。
- 401/403刷新失败继续沿用生产当前行为，本批不重新设计，也不把保留旧目录视为已批准的权限策略；该会话/权限边界需单独确认。
