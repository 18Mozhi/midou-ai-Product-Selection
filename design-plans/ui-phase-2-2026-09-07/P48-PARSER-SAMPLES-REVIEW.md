# P48 · 固定样本 / 回放 / 独立复核实际 Vue r1

## 本批范围

以真实 App、ProviderSourceCenter、ProviderParserSampleDialog、ProviderParserSampleReview 和 M03-07 固定样本合同为准，对“固定样本回放”任务窗做隔离评审实现。覆盖读取中、候选作业、双空态、可复核、创建人不可自审、已批准、已驳回、回放一致、发现差异和解析失败十种读取状态。审核宿主只精确替换实际父子 SFC 并注入专属 CSS；**生产 SFC、样本/回放/复核 API、数据库、权限、环境、依赖和线上数据均未改，未部署。**

pbakaus/distill 用于收敛判断路径：一个任务面只回答“这个真实样本能否代表当前解析器，并完成独立复核”；来源身份和数量留在蓝色标题区，三项启用门连续展示，回放结果优先呈现，候选与已固定样本按步骤分区，解析器版本和错误码渐进展开。

## 固定、回放与复核

- 三步核对固定为“真实浏览器作业 → 当前解析器回放 → 独立复核”，并明确三项都完成后才满足来源启用所需的固定样本条件。
- 候选作业主层只显示采集时间、真实结果数和“固定为样本”；浏览器作业 ID 不进入主要界面，解析器版本放入技术详情。
- 回放只解析已保存快照，不重新打开外部页面；一致、差异、解析失败都使用文字结论，差异逐字段显示基线值与当前值，错误码折叠。
- 已固定样本显示固定时间、最近回放、复核状态和复核结论；原始创建人 UUID 不进入主要界面。
- 待复核原因保持 2–1000 字的现有合同，通过与驳回均需依据；创建人不可自审时不再展示无效输入框，改为中性说明并等待另一管理员。
- 已驳回状态明确需要从新的真实作业重新固定，不把旧样本改写为新结论。

## 模态与键盘

- 打开后标题获得焦点，背景进入 inert，Tab/Shift+Tab 在窗内循环。
- Escape 与两个关闭按钮关闭任务窗并把焦点归还“固定样本回放”触发点。
- 任一样本动作进行中禁止关闭并锁定同窗写入口；本批仅验证静态读取状态，没有触发这些写入。
- 代表按钮、输入和折叠入口高度至少 44px；390/760px 使用全高单列布局和固定底部说明/关闭区。
- 强制色模式保留弹窗、三步门、回放反馈和样本边界。
