# P08 实际 Vue C 组合 · 批次79

P08 新增审核用 Vite 转换，保留 `TenancyChooser.vue` 的组织目录读取、本地名称/slug 搜索、组织后并行读取工作区与团队、活动工作区才可提交 `/auth/context`，及空组织入口。界面重构为蓝色范围边界、组织目录与当前组织工作区分区，已归档项有明确不可进入文字；“当前账号”保持无 handler 的文字占位。

初始批次是在隔离的 Vite 转换中审核；之后用户明确授权剩余页面自动通过。生产实施不把审核转换留在运行链路：C 布局已直接接入真实 Vue 页面，并保留组织读取/搜索、组织下并行工作区与团队读取、活动工作区范围写入和无组织入口。组织选择不写入；仅活动工作区写入精确的 organization_id/workspace_id。个人空间创建仅维持原有接口与路由分支，不在本轮用真实账号提交。

真实 Vue 的桌面与390px E2E、选组织不写入、归档工作区禁用、精确范围请求和请求序号保护已在[生产 Vue 实施记录](P08-PAGE-COMPOSITION-IMPLEMENTATION.md)验证。局部界面状态来自测试拦截，不证明真实成员资格、RBAC、个人空间写入或正式 M07-03 验收。
