# 共享筛选抽屉：面板关联与减少动态效果下的首焦点

2026-09-12，main / af239b08。延续当前 C 改造，不提升任何页面或旧图的审核范围。

## 实际修改

`ResponsiveFilterDrawer.vue` 用已有 Vue `useId()` 为每个实例生成稳定面板 ID，
触发按钮的 `aria-controls` 与 section 的 `id` 连接。没有增加 props、调用方参数或依赖。
默认 responsive、平台显式 dialog、断点、提交关闭、筛选值与业务操作都保持。

真实浏览器进一步复现了减少动态效果下的首焦点失败：调用 focus 时关闭按钮及其祖先的
计算可见性为 hidden，稍后可见但焦点仍留在触发器。全局 signal-ledger 的减少动态效果
规则给所有元素设置 0.01ms 过渡；只给 surface 设 transition:none 仍失败，因为其后代
也会对继承的可见性产生过渡。局部将 surface 及其后代纳入原有 reduced-motion 禁用过渡
范围后通过。没有增加延时/重试，没有更改全局 CSS；普通动画模式保持。

`fixing-accessibility` 技能指导了展开控件关联和实际键盘验证。UI Skills/Playwright CLI
本地不可用，没有安装；永久验证脚本沿用项目已有 Vite、Vue 与 Playwright 依赖。
