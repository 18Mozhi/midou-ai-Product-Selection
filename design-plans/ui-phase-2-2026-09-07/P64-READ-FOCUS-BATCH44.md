## 改动与依据

实际 Vue 四组基线复现：首次错误或保留快照告警中的“重新核验”被激活后，原提示区移除，键盘焦点丢失。按 fixing-accessibility 技能作最小修复：load 的原单飞 guard 之后、状态清除之前，仅当两个重试按钮之一仍拥有焦点时，将焦点交给持续存在的顶部刷新按钮。目标与来源必须连接、可见且非 inert；用户已移焦不抢焦点；focus 被拒绝不滚动。目标在屏外或被遮挡才滚动居中。

顶部刷新改为 aria-disabled/aria-busy，等待时保留键盘焦点；已有 controller guard 继续拦截重复请求。局部 CSS 保留等待光标/淡化，C 审核皮肤使用灰色等待与蓝色焦点。原两处重试区域的生命周期、业务文案、15秒超时、安全重试、清除/保留规则、API 和权限不改。不在完成回调中自动抢回焦点。

同步原 E2E 的顶部禁用断言与读取状态驱动。Playwright 的 isDisabled/toBeDisabled 将 aria-disabled 也视为禁用，原“非 native disabled”断言误用了它而失败；改为检查真实 HTMLButtonElement.disabled，同时独立断言 aria-disabled。不能把该测试语义误差记为第二个产品故障。
