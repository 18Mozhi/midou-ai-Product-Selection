# P15 机会工作台异步读取归属补齐

## 范围

修复真实 `OpportunityWorkspace.vue` 在筛选、详情对象变更、路由缓存离页时，旧 GET 回执仍可能写入当前页面状态的问题。只处理读取归属，不改 API、字段、队列语义、权限、筛选规则或写入行为。

## 实施

- 使用组件读取代次为机会列表、详情、利润、成员选项、AI、下游和自动推荐配置读取提供归属检查；筛选/详情路由变化同步使旧代次失效。
- 对 KeepAlive 离页使当前代次失效；重新激活时重读。组件销毁也会失效未完成的读取。
- 详情与利润先等待并验证代次，再写入快照；旧失败不能更改当前请求编号、错误提示或主页面状态。AI/下游独立状态与请求编号也只由当前代次更新。
- 不取消网络请求、不自动重试，不更改服务端副作用；只是丢弃不再属于当前视图的回执。

## 验证

- 定向 Playwright：旧筛选成功晚于新筛选完成、离开详情后旧详情失败晚到；桌面 Chromium 与 390px 手机共 4/4 通过。
- `npm run typecheck:web` 通过。
- 完整 M04-02 回归、Web 构建、发布闭环在本次记录更新后执行；本地夹具不代表真实 RBAC、MySQL 或生产业务数据。

## 尚未覆盖

本记录只关闭 P15 核心列表/详情读回执归属的一部分，不等于关闭 OP06–OP10：完整键盘/读屏验收、跨页批量范围、真实 RBAC/数据库/ERP，以及生产业务验收仍分别处理。P18 各详情面板仍需自身异步归属验证。
