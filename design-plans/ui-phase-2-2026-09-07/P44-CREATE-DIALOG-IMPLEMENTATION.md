# P44 管理员创建弹窗实施

## 实施范围

将已审核的 `P44-CREATE-VUE-r1` 蓝白组合接入 `/platform-admin/admins` 真实 Vue 创建弹窗：桌面左侧平台说明栏与右侧白色表单并列，宽度不超过 760px 时上下堆叠；邮箱、临时密码、平台角色均关联就近说明。长表单继续由原生 dialog 自身滚动，操作栏随表单内容排列。

该实现只在 `tab === "admins"` 时启用。P43 用户创建弹窗、密码重置、原因弹窗以及其他页面的外观不使用新增 P44 样式。

## 保持不变

- 原五个条件字段、平台角色选项及运营管理员默认值。
- 原生必填、邮箱与密码长度校验，组织/角色联动和空值语义。
- 组件事件、创建 API 请求体、Idempotency-Key、权限与后端授权判断。
- 账号数据、OpenAPI、数据库 schema、环境变量、依赖和生产服务配置。

## 验证

`tests/e2e/m06-01-platform-accounts.spec.ts` 在管理员创建失败用例中核对桌面并排/手机堆叠布局、说明文案可见、平台角色 `aria-describedby` 指向说明节点，并继续检查密码上限与服务端错误保留行为。桌面 Chromium 和 390px mobile-390 定向用例各 1/1 通过；Web 类型检查与生产构建通过；文档门禁、静态分析、格式门禁及 202 项前端资源预算通过。

完整账号回归的目录标题失败来自测试预期与既有 P44 响应规则不一致：`PlatformAdminDirectoryMobile.css` 和目录实现合同都规定该标题只在 760px 及以下显示。E2E 已更正为检查 761px 隐藏、760px 显示，并保留桌面与移动目录/筛选交互覆盖；账号 E2E 桌面和 390px 均 50/50 通过，目录设计合同单测 4/4 通过。本次后续只更正测试预期与实施记录，没有新的运行时代码，故无需再次构建或部署。

本机拦截夹具只验证 Vue 展示及交互合同，不证明真实账号写入、MFA、RBAC 或正式 M07-03 生产验收。
