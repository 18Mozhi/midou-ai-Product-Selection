# P34 首次加载与后台刷新 · 实际 Vue C r2

原首次加载为410px居中留白和单行提示。本轮改为紧凑白色区、读取标题/说明和三条静态
装饰占位；桌面两列、手机单列。仍使用原state=loading，不改变请求开始/结束时机。
完整父script、后台刷新、重试、结果保留及前序反馈分支不改。仅审批页开启新展示，其他
view仍显示原加载文字与原样式；不是所有组织页一起换皮。

## 设计与语义边界

标题沿用“正在读取当前组织数据…”，说明“读取完成后显示审批记录和模板版本”。不显示
未知数量、百分比或预计时间；三条占位是aria-hidden装饰，不代表三条业务记录。
首次区域role=status，原父aria-busy保留；未做真实屏幕阅读器播报验收，不能据DOM属性
推断播报时序。两种动态效果偏好下均无动画/闪烁。后台不显示首次占位，原按钮变为禁用的
“正在刷新…”，保留旧内容及可编辑筛选。原生禁用按钮click不会增加读取。

r1目视发现标题仍受旧显示字体影响，r2显式采用C字体与700字重，并增加计算样式检查。
r1的162PNG和清单作为本次设计对照交付保留且固定哈希，不作为当前源或已批准证明；
r2独立目录，不覆盖旧图。原权限、登录与其余读取反馈的图和批准范围保持不动。
