## 本批落地

按 frontend-design 延续 C 方向：组织读取独立白区，深蓝三任务目录，白色结果工作区，创建入口不再把长表单摆在列表之前。客户端与回调创建移入原生填写窗，保留原 ConfirmDialog 二次确认。手机另补顶部/记录实际视口，以及填写窗底部图；长图里的固定底栏按浏览器截图位置呈现，不据此宣称真实滚动遮挡或真机验收通过。

按 fixing-accessibility 为新增填写窗增加原生背景隔离、可见且可用控件的 Tab 首尾约束、Escape/关闭还焦、进入原确认窗及取消后恢复草稿。组织错误移至组织字段；字段名保持稳定，必填/错误说明关联原校验。原生 dialog 单独使用时首端 Shift+Tab 未满足局部闭环，浏览器断言先失败，再补明确首尾约束。首版帮助/错误文字混入读屏名称也已由稳定名称修正；这不等于完整读屏验收。

审核变换仅给业务 script 增加 OpenCreateReview 导入；其余 script 逐字一致。三个 ResponsiveDataView 的完整块逐字保留，原行操作、字段、分页和查询处理没有改写。用户仍能在组织读取字段或创建字段中修改同一原始 organizationId；不得把未应用的组织输入当作已读取快照范围。独立行操作原因、密钥生命周期、晚响应归属、写成功读失败等仍待后续实现与验证，不因创建窗完成而推断通过。
