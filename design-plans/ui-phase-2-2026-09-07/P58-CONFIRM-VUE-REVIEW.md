# P58 · 十类配额变更确认窗 C 方向审核

## 独立预览范围

使用 ui-skills-root / frontend-design，深蓝操作标题与说明、白色影响/待提交信息、浅蓝目标说明、
浅灰提示和底部双按钮。桌面逐行左右比较，手机逐行“变更前 / 变更后”上下比较，长内容连续出图。
此包独立于此前编辑/创建预览：只转换生产源码中的 confirmDialogElement 模板，注入局部 CSS。
完整 script、原 styles、其他页面/弹窗模板不变，原影响计算、请求体、幂等键和提交行为不变。

新增只读展示直接来自真实 pending.body：方案名称/说明（仅含这些字段的方案操作）、
请求携带的版本（null/undefined 不显示，不猜当前/下一版本）及变更原因。不是新接口字段或输入。
原影响 rows 原样保留；空 rows 显示“本次未提供逐项前后值”，不宣称没有影响。
没有补算暂停/恢复/结束的状态差异或其他原影响算法未提供的信息。

## 覆盖十类实际入口

| 本地入口 | 原比较行数 | 样例来源与边界 |
| --- | --- | --- |
| 编辑后保存 | 1 | 原 E2E 方案，采集任务 100 → 125；名称/说明/原因是明确键入样例 |
| 启用方案 | 1 | 原数据克隆，仅方案改 draft、概要改草稿计数；不是新业务方案或真实可执行性证据 |
| 退役方案 | 1 | 原 active 方案，启用 → 已退役 |
| 首次分配 | 5 | 明确无分配变体，清空该组织调整/用量/有效额度；选择原 p1 并填原样例周期 |
| 调整分配/周期 | 5 | 原分配，结束改为 2026-10-01 08:00；新周期用量保持“变更后重新统计” |
| 暂停 | 0 | 原 active 分配，原影响函数只给范围/备注 |
| 恢复 | 0 | 原分配克隆为 suspended；原影响函数只给范围/备注 |
| 结束 | 0 | 原 active 分配，原影响函数只给范围/备注 |
| 人工调整 | 1 | 原分配，输入采集任务 +25；没有实际写入或生效认定 |
| 撤销调整 | 1 | 原 active 调整行入口，不等于真实时刻仍生效验证 |

基准 fixture 从 `tests/e2e/m06-06-commercial.spec.ts` 唯一 data/navigation 对象 AST 读取。
draft/suspended/unassigned 是三种显式本地显示变体，其他七种保持原数据；每组保存实际样例指纹。
保留原历史时间、p1/o1 合成标识，不以 UI 可以打开确认窗证明服务端业务资格、真实授权或版本正确。
