# P69 文件存储核验 · C 方向实际 Vue 实施

## 范围

将已批准的 FILES-C-r1 迁入真实 `/platform-admin/files` 页面。`FileResilienceCenter.vue` 保留原 GET、15 秒超时、单飞、403 清空、503/限流/超时保留快照、技术追踪与宝塔受管边界；只调整页面呈现并拆出 typed-props 展示组件：快照/发现、目录水位与活动索引、抽样完整性与同机恢复。导航壳层不再为本页重复输出通用标题。

样式采用蓝色页内运行范围和白色证据纸面，不使用渐变；桌面分区、手机单列，所有有效比例条仍受可用性、正容量及 0–10000 原始范围约束。API、状态规则、权限、数据库/文件格式、配置、依赖及任何写/恢复操作均未改变。
