## 设计与审核重点

桌面用蓝色个人状态目录和白色逐项工作队列；不是把P23全工作区列表改标题。状态目录明确“本人、当前工作区、不限到期日”，当前队列按实际排序显示任务、进度、期限与查看入口。汇总独立于搜索和分页，不自动推荐第一项，也不因搜索结果少而缩小统计口径。

手机目录改为两行状态入口，移除重复标题，新建与页标题同排。第一轮目检后压缩首屏重复信息，并把“左侧/右侧”改为“状态目录/任务队列”；控件禁用态覆盖主色按钮样式，避免禁用转交仍像可点击。按钮16px、辅助13px，44px触控；圆角8/12/16/18层级。减少动态效果模式禁用颜色过渡。

建议按总览→选择2项→五种批量弹窗→手机→失败恢复顺序审核。页面选择器只属于审稿工具，不接入生产。点击任务只显示独立P24导航意图，不把已有P23/P24图片重新计作P13交付。

## 数据与范围依据

- 原始数据来自未修改的 tests/e2e/helpers/business-tasks.ts：当前两条记录、本人summary、唯一成员与工作区名称。永久助手执行实际setup注册函数并读取惰性回调，不手填原始返回。
- 现有测试列表总数2、summary总数7，且一条todo继承35%进度；它们是独立接口夹具，不是一致数据库快照。原型原样保留并提示差异，不能称为真实工作区数据；日期/SLA保留当时观测，不按当前日期重算。
- 暂停/完成/取消、长标题、11项分页、空列表属于明确标记的合成布局场景，summary仅对这些样例集合计算；不得拿来证明真实任务或API成功。
- 交互筛选与排序仅针对当前离线样例，不等于服务端全量搜索。源仓库list/summary方法通过惰性pool验证SQL构造：本人、组织、工作区过滤，LIKE特殊字符转义，排序在分页前，summary不含搜索条件。未执行MySQL。
- 源TaskWorkspace函数执行验证setStatus/applyFilters/resetFilters/setPage/clearQuickCreate，以及新建、删除、五种批量请求body；源batchEligible对五种状态逐项验证。服务端鉴权、幂等客户端/锁/事务、真实HTTP和Vue生命周期未在本包重跑。

## 本页按钮、表单与状态合同

| 入口 | 本稿行为与条件 |
| --- | --- |
| 六种状态、搜索应用/重置、四种排序 | 保留status/query/sort/page语义和其他query；条件/分页变更清空选择；搜索草稿仅内存，选择行不丢草稿；修改排序同时应用当前输入 |
| 查看任务 | 独立/tasks/{id}，from含完整/work URL；点击仅预览目标，不加载伪详情 |
| 选择行/本页/清除 | 仅task:update；选择与查看分离；每页10项，不宣称跨页全选 |
| 新建 | 仅task:create；标题200、说明5000、四优先级、可选期限；不新增负责人字段；关闭保留本地创建草稿并只清快捷创建三query |
| 删除 | 仅task:update；原因必填500，当前任务version；文案区分列表删除与保留审计 |
| 五批量 | 仅task:update；调整负责人另需task:assign；暂停仅in_progress，继续仅paused，其余排除completed/cancelled；先显示已选/可执行/跳过 |
| 批量字段 | 继续不需要原因；其余原因500；延期必选日期，转交必选真实成员；不新增批量API |
| 弹窗通用 | 初始聚焦关闭；Tab/Shift+Tab循环，Escape/返回/遮罩关闭、归还入口焦点；原生字段校验与空白校验；输入保留的失败反馈在窗内 |
| 成员目录失败 | 任务仍可读，不虚构空名单/新成员；调整负责人确认禁用 |
| 读取失败/无权/过期/限流 | 不变成空或零；重新加载只记录意图，不模拟登录/权限恢复；loading显示未知数量 |
| 处理中/提交 | busy禁重复、字段锁定；关闭不代表取消已发送操作。本原型实际未发送请求，所有提交仅生成离线意图，列表和任务状态保持不变 |

七种弹窗各有正常图；创建有处理中与失败图、批量有失败代表图。七种表单都执行失败保留输入测试，但不是每种业务结果都已独立出图。部分成功/版本冲突/迟到结果、成功后刷新、全主题/密度与完整壳层仍待补，不能把本批当作P13所有状态完成。
