## 本批结构与事实

- 延续选定C的蓝色范围面、白色内容面、中文无衬线与圆角层次；列表不套用用户账号表头，详情保留独立页面语义，不照搬账号详情弹窗。
- 桌面详情将进度/期限/负责人和活动/评论分区；移动范围变成短顶区，信息纵排，弹窗在视口内可用。旧信号账页的零圆角、大编号和边框层叠不再作为设计约束。
- 移动目录将搜索/状态收进原生展开区，默认先看任务而不是整屏筛选；增加首个任务标题在844px首屏内的实际位置断言。筛选空结果图展开条件，便于定位和恢复；不改变筛选字段。
- 复用task-concept-data.js的单条隔离任务，与tests/e2e/helpers/business-tasks.ts哈希对应。标题、说明、35%进度、第2版、时间及负责人映射来自该样本；不捏造多条任务、统计或活动。样本不是当前线上数据。
- 搜索按当前标题/说明、状态本地筛选；排序保留原四个选项，单样本不能证明排序算法或分页。本人summary与工作区列表不混用；本提案不生成summary数字。
- 进度字段依据TaskDetailPanel：0–100整数、required说明、maxlength500；生产submitTaskAction的action/expected_version/progress_percent/progress_note不变。本原型不发POST，提交只演示HTML校验与关闭，不假装更新任务成功。
- 只读场景是设计变体，不是实际RBAC证明。顶部工具可切换场景，不使用伪身份令牌。
- 新建、批量暂停/继续/延期/调整负责人/取消，以及详情其他业务动作保留真实入口；点击仅在审核说明区提示未实现范围。它们不是可运行业务功能，不能计为已验动作。
