## 覆盖与操作

27 个基础/异常/忙碌场景；五分区×三主题×两密度共30个组合；资料真实hover/focus/pressed三图；14个动作各三种真实鼠标/键盘状态42图。合计102场景×两端204图。导航不适用disabled/busy，不虚构导航提交。五类读取/写入操作的禁用与忙碌使用对应真实锁定场景。

底部“设计审核工具”可选场景、模拟成功/失败/保持忙碌、主题及密度；保持忙碌后可切区，再点“完成挂起操作”。这些是审核控件，不是新增产品功能。外部链接只记录真实路由意图，不访问远端；分区href保留 `/me?section=…`，点击在内存切区，不模拟 Vue Router 或浏览器前进后退。

资料保留7个编辑字段、只读邮箱、expected_version；偏好保留五布尔字段及返回版本；改密只描述current/new请求键，不在诊断保存密码；会话按id撤销，无确认弹窗。组织令牌入口仅在有权限场景展示。资产分别使用topic、opportunity_id及/tasks原路由，不新增详情或筛选。

## 真实约束与设计差异

邮件开启使用实际通知校验器的503拒绝文案；已撤销/过期会话重试失败。所有记录为明确隔离样本，时间和状态不代表当前设备在线。刷新重载全部五来源，覆盖草稿；模拟成功不是服务器返回证据。

原型提出串行写入、源分区反馈、提交期间锁定与旧场景结果丢弃；真实 PersonalCenter 仍缺这些保护。读取异常采用明确未知态，区别于现有allSettled失败回填空/default；安全分区整块未知时原型隐藏密码表单，实际源码仍显示表单。这些行为差异待审，不能作为实现授权。未新增真实API、权限、数据库或邮件能力。

逐动作六态映射只覆盖该组代表控件，不代表每个重复入口、五导航变体、会话状态变体、输入类型、主题交叉状态均验收。通用六态样本板不自动计入动作覆盖。全站分母未冻结、用户批准未提升。
