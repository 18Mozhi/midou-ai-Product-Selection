## 同页交互与边界

同一浏览器文档内两个常驻 Shadow DOM 组件，不用 iframe，不跳转到旧稿。各组件保留原控制器/数据，作用域内 ID、标签引用和焦点隔离。局部样式由永久生成器机械转换，旧文件不重绘、不改 hash。组件样式不同的既有主题状态不冒充全页三主题/两密度统一验收。

顶部切区不销毁组件：近期记录未提交搜索草稿、质量区搜索/隐藏选择、各自分页和反馈保留在内存。原因窗仍遵循原稿的打开/取消重置规则，不声称取消后自动恢复全部原因草稿。原生弹窗打开时禁止切区；质量写入等待期间在窗内展开明确标注的审核工具，可返回模拟冲突、未知或写入后读取失败，避免只有控制台才能退出。

记录读取按最近100条返回集、20条本地分页；质量证据/问题为各自服务端总数与当前页，核对只看最近20次。两区数据来自不同时间的隔离夹具，绝不相加或伪造记录与证据关系。质量搜索保留原稿未trim的本地语义；记录导出只用已提交范围，不借质量选择项。

隐藏记录区的迟到读取仅更新该区及私有 URL 草稿，不覆盖当前质量 URL；切回再显示 entity/q/status/page。质量显示 view=quality，第二页补 quality_page。仅验证原型内 replace 与切区恢复，**不支持初始深链接还原、浏览器前进后退、刷新持久化或真实 Vue KeepAlive 验收**。

生产 PlatformDataCenter 仍用 v-if 装配 DataQualityCenter，切离质量会卸载；本稿常驻与迟到保护是待审改动，不是运行态修复。旧导出异步范围漂移、质量写/读提示竞争等真实问题仍未修。

## 验证与复用

`node scripts/build-ui-phase2-data-composed-c.mjs --write` 仅生成本包 scoped JS/CSS 和模板；不带参数逐字检查生成结果。修改源稿后必须重审新差异，不能以重新生成替代审批。

`node scripts/verify-ui-phase2-data-composed-c.mjs --smoke` 做最小连续交互检查，不写文件；`--capture` 生成正式图证据；无参数核对源/图指纹并重新执行双端 DOM 检查。复用现有 Playwright 和两段真实源码提取器，不新增依赖。

检查16px控件/13px辅助字、44px控件（复选框另按已有标签）、作用域内唯一ID/ARIA引用、无整页横向溢出、单模态及焦点返回；五类长窗底部按钮可见且命中，两个切区按钮真实hover/focus/pressed。检查切区草稿与隐藏选择、两区迟到结果隔离、未知导出锁写、质量写入与读取失败分开、quality_page恢复。另在768/1024/720检查代表性重排；720并非真实200%缩放。

全部 HTTP 请求、local/sessionStorage 写入与浏览器错误应为0。没有网络、授权签发、CSV下载、审计、SQL、权限或生产操作成功证明；后端/Python与本次纯设计组合无关，API/OpenAPI、配置/env、数据库、依赖、部署均不变，无需重启。
