## 复验与来源

`node scripts/verify-platform-notification-lifecycle.mjs` 默认不生成文件；运行两种宽度的18组真实父组件/客户端/路由交互，覆盖离页写入成功/失败、在页写后刷新、两个失败分页重试、首次读取失败与恢复。两种追踪都用键盘 Enter 展开，确认编号可见、焦点仍在原生 summary；检查无横向溢出、页面异常或业务网络请求。服务和浏览器在 finally 中关闭。

`--capture-review` 是仅用于审核材料的可选参数，保留4张PNG与manifest；固定输出本目录，目录存在时拒绝覆盖。已有本包时应使用默认复验，不删除或覆盖已审图片。manifest 保存图片原始SHA-256、175份实际加载源码/配置/锁文件指纹和18组结果，原源码演进后需另行明确新版本，不把旧图重新标成当前。
