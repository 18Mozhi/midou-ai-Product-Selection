## 设计与真实边界

- 使用 frontend-design 技能延续已选 C 的蓝色范围区、白色工作面、柔和圆角；弹窗按“操作名称 → 目标任务/影响范围 → 输入 → 底部操作”组织。危险操作有明确文字及红色按钮，不只靠颜色区分。
- 移动弹窗在真实390×844视口内展示，正文可独立滚动，操作区保持可见；输入控件16px、非复选控件至少44px，正文最小13px。取消、关闭、Escape都可退出，Tab双向循环并返回触发按钮。
- 字段依据 TaskWorkspace、TaskDetailPanel、TaskBatchActions：新建/编辑只有标题、说明、优先级、可选期限，不新增负责人字段；删除必填原因；进度0–100整数及500字说明；暂停/取消/延期/转交保留原因，延期/转交增加各自必填字段。原API、expected_version和权限规则未修改。
- 批量仍只有暂停、继续、延期、调整负责人、取消。继续不要求原因。当前唯一样本为进行中，故批量继续可执行0、跳过1；其他批量可执行1、跳过0。关联采集任务0基于样本没有该关联字段，不代表线上没有采集任务；不联动取消底层任务。
- 使用未变的 task-concept-data.js 及既有业务测试样本，日期按Asia/Shanghai展示。没有编造额外成员、任务、活动、成功记录或统计；单样本不能证明批量混合状态、多页或真实组织权限。
- 原开始/继续/完成单项操作没有确认表单，本批不凭空添加确认步骤。它们在真实Vue中的执行反馈仍待后续图稿/验证。
- 六种读取状态的标题和重新加载入口来自 TaskWorkspace；解释文案是待审设计文案，不是服务返回。重新加载只演示入口，不假装恢复服务。提交失败/忙碌是显式模拟，不冒充后端错误码、版本冲突或成功响应。
- 表单提交只执行浏览器输入校验并关闭，说明“未请求API”；字段、任务对象、存储均不持久化。审核目录用于集中查看变体，不是拟上线产品导航，首批HTML仍保留当时未实现按钮的提示。
