## 审核时需区分的现状和提案

- 源记录类型和质量页签按钮并没有 disabled 属性，刷新时处理函数早退。新原型部分可见禁用是待审改进；悬停命中也不意味着已有明显视觉反馈。
- 源重置条件为 `refreshing || (!queryDraft && !statusDraft)`，不是根据已应用条件判断。近期分页是本地切片，没有凭空增加请求忙碌态。
- 质量分页 busy 图仍显示可用下一页，原型通过处理函数防重；源 Vue 使用 refreshing 禁用。该差异保留供审核，未宣称已统一。
- 源下载直接申请授权后跳转；新确认窗、未知状态禁用和处理中呈现是提案，不是实际下载验收。
- 源问题复选框只在桌面，源质量技术信息只在手机详情；新增移动选择和桌面详情/技术位置是提案。源 inline aside 改模态、质量区常驻、页签清搜索和确认短语规则的差异仍见原合同，不因补图获批。
- 没有扩展所有行、全部字段状态、所有入口六态或完整主题/密度。没有验证真实 Vue、API、SQL、审计、下载文件、权限、历史导航或生产行为。
