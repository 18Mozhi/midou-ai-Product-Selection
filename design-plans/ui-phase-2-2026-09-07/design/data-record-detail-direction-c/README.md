## 字段与设计

沿选定 C 的蓝色范围区、白色事实面和就近只读详情；frontend-design 用于维持层级与手机长内容可达性。新补稿局部将“技术详情”展开控件提高到16px/44px并提供加减号，不修改旧包或生产共享样式。

| 实体 | 分类字段的真实含义 | 两个指标 |
| --- | --- | --- |
| 机会 | 分类 / 市场 | 证据 / 来源 |
| 竞品 | 站点 / 市场 | 版本 / 变更 |
| 供应商 | 供应商 / 地点 | 最小起订量 / 报价 |

每例核对标题、所属组织、工作区、分类/站点/供应商、市场/地点、状态、两个指标、更新时间、技术ID。六组详情字段均逐一滚动并做可见性/命中检测，技术ID与返回区另外核验。机会/竞品没有原始E2E数据夹具，使用现有真实仓储投影的合成结果；供应商原始隔离夹具单列，不能称实时客户数据。合成首行的0保留已有null/undefined转0，不编币种、单位或新测量。

三种普通合成样例与一种原始供应商夹具各3个图位（打开、字段、技术/返回）；三种长内容各8个图位（打开、六字段、技术/返回），双端合计72图。长文仅扩展明确的示例字符串，状态、指标、时间不变；进入新场景后恢复原始演示数据对象，避免污染其他组合场景。没有穷尽其他状态行、空值排列或所有主题密度。

## 验证与操作边界

`node scripts/verify-ui-phase2-data-record-detail-c.mjs --smoke` 做双端最小检查；`--capture` 生成本包正式PNG、图册与来源证据；无参数核对来源/PNG指纹并运行全部7样例的字段、模态、滚动、键盘循环、Escape/返回返焦检查。复用现有Playwright和源隔离数据生成器，不安装依赖，不启动本地服务，不请求HTTP，不访问数据库、不写浏览器存储；浏览器在finally关闭。

本包加载旧组合的控制器和样式，而非复制重写或改动旧包指纹；来源有变化会失败关闭。长字符串与审核工具仅是离线提案。源Vue桌面无“查看记录”模态，此入口仍待批准；源手机ResponsiveDataView的真实生命周期、所有消费者、读屏/软键盘、全主题/六态、权限、API/SQL/审计、生产部署均未通过本包验收。P54动作六态的102槽不因新增详情图自动映射，全局分母及用户批准保持原状态。

无环境变量/配置/API或持久化契约变更，无需重启或迁移。正式PNG/HTML/JS/CSS及验证脚本均为永久审核交付，不是临时测试产物。
