## 源码与提案边界

复用[原基础设计](../notification-direction-c/README.md)的数据/控制器/样式，不改原98图；[写按钮图册](../notification-controls-direction-c/README.md)60图保留。新navigation.css提供可见焦点、checkbox整行反馈、技术详情16px/44px区域；列表焦点内描边防止被容器裁掉。navigation.js在离线筛选重绘后将焦点返回同ID控件，这是新稿修正，不是生产Vue修复。

全部已读仍无body/筛选；未读行打开产生自动read意图，已读行不产生写意图；未收到回执不改变已读、处理状态、版本、行或汇总。分类/状态/分页只更新离线路由，重新加载只显示读取意图而不冒充服务恢复。来源链接只展示原站内地址加from，不访问目标页。

偏好入口和消息行在全局busy时禁用；详情关闭按钮及Escape在详情写入busy时均受阻；偏好取消在busy时仍可关闭且不取消PUT。等待关闭后触发器可能已禁用，焦点归属仍需真实Vue组合处理，不宣称已全面解决。分页仅按首/末页禁用，普通筛选、重载和技术详情不编造busy条件。

原夹具总数与分组列表、API分页100与当前Vue20的差异继续明示；21组分页及未读等扩展为合成布局状态。既有原型清除筛选入口属于旧提案，本批未纳入源码动作映射。页级requestId技术详情仍无本批专门图，不能与资源技术详情混算。
