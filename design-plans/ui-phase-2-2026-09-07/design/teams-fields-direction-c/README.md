| 字段 | 真实模型 | 约束与本批状态 |
| --- | --- | --- |

## 源码依据与提案边界

真实来源是 `OrganizationTeamPanel.vue` 七个输入模型、`OrganizationAdminCenter.vue` 三类写入接线及 `organization-admin-service.ts` 校验，均通过父级 evidence 来源哈希绑定。真实提取函数另由 `buildTeamsDesignData` 的五组检查覆盖。新稿复用旧团队离线夹具及 renderer，不改它们、旧 PNG 或生产代码。

四个创建字段在实际 Vue 提交中仍可编辑；本子稿仅解除旧离线稿的字段锁定，并展示忙碌说明，提交/取消继续禁用。本批只验证待处理时编辑快照，不决定同窗后续草稿如何处理，也不宣称修复 OG-G02 迟到成员操作回执归属问题。

创建提交按实际前端 trim 名称、流程键、原因；负责人和流程键为空字符串时，后端按现有可选语义转 null。任意非空流程键仍可保存，不新增存在性校验。活动成员仅按成员关系状态筛选，不把锁定账号排除。字段帮助与就地错误呈现为视觉提案，非现有 Vue 校验时机证明。

共享分配/移除原因窗不计入七字段；继承旧稿的 500 字前端上限与真实共享前端无 maxlength 的差异仍未获批，不能由本图册推导新字段策略。完整父接线/字段容器登记、全页真实 C 实施、其余状态与生产验收仍待推进。
