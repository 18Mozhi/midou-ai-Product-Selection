## 本轮样式与可达性修订

frontend-design用于细化普通按钮的按下背景、深蓝目录的按下反馈、链接悬停/焦点、原生技术summary的16px/44px触达。fixing-accessibility要求检查实际中心命中，不只检查DOM存在。

完整采图复现桌面阅读目录首项被固定标题覆盖：按钮在视口内，但中心命中标题。新包用ResizeObserver按标题实际高度定位桌面目录；手机目录固定在标题下面。章节scroll-margin同步计算标题/手机目录高度，检查跳转目标未被覆盖。只使用当前页面尺寸，不固定猜长标题高度；不修改路由、事实或审批动作。旧C包及生产没有迁入此修订。

截图取真实hover/focus/active，不注入伪状态类。默认态先原生blur，按下后移至窗内空白或页面空白释放，检查完整内存状态、弹窗、details与query均未误动作；分页禁用真实坐标点击为零变化。固定层在滚动后等待两帧再检查与截图。

## 点击验证和必须保留的差异

每个变体在1440/390各真实点击一次，共82检查。核对模板/请求/发布窗口、queue/filter/page、详情ID与query、提示清除、技术展开、章节选中、原资源/证据/安全通知route。所有点击零业务写入预览；重读只记录离线意图、不伪造读取成功；导航只显示原目标、不证明目标页面打开成功。

- 原Vue“全部”移除status后刷新回pending问题仍未修；原型保留显式空status。该图不是Vue URL缺陷已修证明。
- 分页使用旧21行合成样例，不伪造真实总量或证明后端分页。只读/无已发布模板检查的是原型入口可见性，不是服务端权限验收。
- 原Vue错误态不渲染队列组件；旧C提案左侧目录仍存在。本包只复验所列恢复按钮，不宣称错误态全部导航与源码一致。
- 非详情遮罩、顶部新增关闭、发布返回内存原因清理，均沿前批提案；源模板/请求关闭保留草稿，发布返回/Escape差异仍见原清单。未处理请求中关闭重开、读取/写入迟到归属。
- 源字段折叠被待审稿直接显示，不能为填满清单再复活旧布局；页级requestId未补绑定，不能拿资源技术详情冒充。
- 夹具目录模板v1/详情锁v3、节点/历史升级与成员显示名差异保留。证据不足只提示，超时不自动批准，写入规则不变。
