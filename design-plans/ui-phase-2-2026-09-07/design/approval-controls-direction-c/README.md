## 本批交付

5个代表写入按钮：批准并流转、驳回、保存模板草稿、发布模板、发起审批。27个适用代表视觉槽×1440/390为54PNG，另5个失败保留场景×双端10PNG，共64张上下文视口图。它们是64张新增设计图，不是生产功能或全页完成证明。

| 按钮 | 默认/悬停/键盘焦点/按下 | 独立禁用态 | 等待结果 | 失败保留 |
| --- | --- | --- | --- | --- |
| 批准并流转 | 四态均采原生浏览器状态 | 原因为空，DOM disabled | 点击后显示“正在批准…” | 保留原原因，重试预览同body |
| 驳回 | 同上，危险色区分 | 原因为空，DOM disabled | 点击后显示“正在驳回…” | 不把失败描述成审批已驳回 |
| 保存模板 | 四态均采原生浏览器状态 | 不补造空字段禁用 | 点击后禁用并显示“正在保存草稿…” | 保留单节点/成员/期限等输入 |
| 发布模板 | 同上，保持叠加窗上下文 | 不补造空原因禁用 | 点击后禁用并显示“正在发布…” | 原target修订与原因不改变 |
| 发起审批 | 同上 | 未单独采无发布模板变体 | 点击后禁用并显示“正在发起…” | 锁定类型/标题/资源ID保留 |

模板/发布源按钮仅busy禁用，发起还包括无发布模板；required不等于disabled。新包不把空字段画成禁用，也不把未采状态写成不适用。三组独立disabled槽仍待适用性/变体核对；本页从144待映射代表槽减少27至117，范围外不变。

## 风格与交互细化

frontend-design用于细化同一C语言：主动作蓝色按下加深，驳回悬停浅红/按下深红，键盘焦点独立描边，忙碌保留清晰文字并配非必需转圈标记；reduced-motion关闭旋转。触达范围≥44px、按钮文字≥16px，桌面/手机均检查中心命中与无横向溢出。

默认/hover/focus/pressed不是注入CSS伪类或复制通用按钮板，而是在对应详情/表单中真实鼠标与键盘采集。按下截图后移出按钮、在窗内空白处释放，确认没有意外生成写入预览或关闭弹窗。禁用按钮用真实坐标点击后校验零追加意图。

忙碌由真实点击既有原型按钮、生成真实字段的**离线请求预览**后进入本包pending状态，捕获请求快照并锁当前输入。只让触发按钮显示对应动作文字，另一个决定按钮保持原标签并禁用，避免驳回时仍像在批准。不是实时HTTP、后端成功或生产已经具备结果归属保护。

窗口内“模拟返回失败（审稿工具）”只供演示，非业务按钮，不计业务动作或控件分母。点击后解除本包锁定、显示失败、保留输入；再次点击原提交按钮，验证相同body生成第二次预览。没有模拟成功批准/发布/新增审批，没有改原事实、历史或版本。

## 必须保留的源码差异

- 原Vue未统一锁字段，也未修同实例A/B读写迟到、关闭后回流；本包等待/失败控制器只在设计页运行，不代表那些缺口已修。
- 关闭仍复用旧原型，不表示取消请求；跨窗口切换、关闭再重开期间的pending归属未完整实现或验收。切换审核场景会重置内存演示，不是用户数据保存策略。
- 模板/请求原Vue必填字段折叠、错误主要页级notice；直接展示字段与窗内错误沿原C提案，不冒充现状。发布返回/Escape的源草稿差异仍见语义清单。
- 决定继续发送原reason与expected_version；发布是reason.trim和expected_revision，没有额外action；模板单节点，发起类型随已发布模板锁定。证据缺失只提醒，不新增质量门。
- 夹具模板目录v1/详情锁v3、历史升级/节点字段、同ID名称的独立响应差异保持。无真实权限、数据库、审批事务、Worker、全主题/密度、软键盘或生产证据。

## 使用与验证

打开交互稿选按钮→“查看按钮”→填写内容→点击提交，进入等待演示→窗口内“模拟返回失败”→查看保留输入和再次提交。要换按钮，先关闭窗口再使用顶部审稿选择器。普通原型场景菜单继续可用，不代表全部场景受本包覆盖。

```powershell
node scripts/verify-ui-phase2-approval-controls-c.mjs --smoke
node scripts/verify-ui-phase2-approval-controls-c.mjs --capture
node scripts/verify-ui-phase2-approval-controls-c.mjs
```

smoke只验焦点/按下/禁用/等待/失败，不生成文件；capture生成本目录永久64PNG、gallery及evidence；无参数核对来源/图片哈希与全部原生状态。验证5类精确body、忙碌/空原因零重复意图、失败重试同body、原事实不变、HTTP/存储/控制台错误0；finally关闭浏览器，不启动服务或安装依赖。

生产Vue/CSS、API/OpenAPI、后端/Worker/Python、数据库/迁移、配置/env、依赖、权限和宝塔未改，无新运行参数或重启。新文件全为永久审核交付，没有一次性文件/日志/服务。原图/旧evidence/coverage审批字段不覆盖。
