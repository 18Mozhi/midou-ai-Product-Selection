## 本次设计

复用原 C 稿的蓝色目录、白色工作区目录/详情及原因窗，不改原控制器、数据或92张图。本子稿将焦点改为清晰蓝环加白色间隔；禁用使用稳定灰底/灰字，不靠整体降低透明度；归档入口红色描边、确认红底，恢复确认保留蓝底。选中标记与瞬态按下分别呈现；技术详情及原因说明16px，按钮热区至少44px。短背景过渡尊重 reduced-motion。

共36个列明控件/变体，146个单端状态，双端292张控件图，另4张原因窗局部组合图。18个动作代表对应80个状态，18附加变体对应66个状态；28个代表状态槽仍待适用性核对或补图，不宣称“每项全覆盖”。变体数不增加业务动作数。

| --- | --- |
