## 视觉细化与审核组合

frontend-design 用于维持已选 C 方向并细化交互层级：蓝色焦点线带白色隔离环、灰色禁用、选中底线/左边线与鼠标按下反馈分离，技术入口和编号改为 16px，热区至少 44×44。没有危险写入，不套用红色确认按钮。减少动态效果偏好下关闭过渡。

请优先看 [手机模板当前项键盘焦点](select-current-focus-390.png) 与 [桌面版本变化组合](composition-template_multi_diff-1440.png)。另有 [手机跨页保留详情](composition-template_page_two-390.png)；它说明目录翻页不改变当前详情，不暗示系统替用户重选模板。

原 90 张上下文图及其 JS/CSS/数据不改，新样式仅由本目录 index.html 引入。无新增业务弹窗；节点变化仍按 ordinal 和后端返回的前后字段，不新增保存、发布、回退或审批动作。

## 验证与使用

直接打开 index.html 或 gallery.html。审核工具选择控件/状态只准备场景；悬停、焦点、按下由鼠标/键盘原生触发，图册保存的是验证器真实触发时的截图，不用静态 CSS 类冒充原生状态。

- `node scripts/verify-ui-phase2-org-approvals-controls-c.mjs --smoke`：手机最小验证，不写文件。
- `node scripts/verify-ui-phase2-org-approvals-controls-c.mjs --capture`：两端生成图、哈希与图库。
- `node scripts/verify-ui-phase2-org-approvals-controls-c.mjs`：源图完整性校验后重放两端。
- `node --test tests/unit/ui-phase2-org-approvals-controls.test.mjs`：逐源对应、视口/状态绑定、只读边界及图源漂移检查。

240 项原生状态检查、57 次真实浏览器离线点击，检查热区/字号/水平溢出、禁用无副作用、选中标记、分页和返回焦点、原导航及两 GET 意图、事实不变；不访问 HTTP，不使用 Cookie 或浏览器存储。基于项目已有 Playwright，浏览器 finally 关闭，无开发服务器。
