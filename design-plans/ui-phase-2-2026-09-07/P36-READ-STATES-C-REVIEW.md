## 组合与语义

| 组合                                   | 设计中的内容边界                                                                 |
| -------------------------------------- | -------------------------------------------------------------------------------- |
| 首次读取等待                           | 不显示令牌记录、表单或占位数字；刷新禁用                                         |
| 首次 500 / 403 / 401 / 409 / 429 / 503 | 六类分别表达，不显示旧记录；保留刷新和重新加载两个真实入口                       |
| 后台读取等待                           | 显示“上次读取内容”，刷新禁用，不给出虚构进度或完成时间                           |
| 后台 500 / 409 / 429 / 503             | 保留上次内容并说明不代表最新结果；重试仍使用页头原有刷新入口，不额外增加业务按钮 |
| 后台 403 / 401                         | 隐藏原内容，分别提示权限或登录状态；不画出明文或创建表单                         |
