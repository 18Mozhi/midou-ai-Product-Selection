# P50 · 登录两段写入离页对账实际 Vue 实施 r1

## 本批范围

补齐 `/platform-admin/credentials` 登录导入在资产与运行档案两段写入期间离页、再返回缓存页时的结果归属。生产 `CredentialAssetCenter.vue` 现在会让已经提交的链继续完成，但不重放任一步；返回页先显示等待并锁定新修改，终态再依据写入结果重新读取三项凭证事实。C 方向蓝白视觉仍由审核宿主注入。**全部写入由本地 Playwright 路由拦截，未访问真实浏览器助手、后端、加密、数据库或生产环境，未部署。**

`wshobson/interaction-design` 用于约束离页连续性：离页关闭敏感窗口，不等于取消已经提交的服务器写入；未知与部分成功必须先重读事实，不能诱导用户重新导入或重复关联。

## 五种离页状态

- 等待中：返回缓存页显示“网页登录档案保存仍在等待服务器响应”，所有新凭证修改入口锁定。
- 两段成功：资产成功后只创建一次运行档案，随后只执行一次三资源重读，并显示完成反馈。
- 资产结果未知：不创建运行档案；重读后提示核对当前资料，避免重新导入或重复提交。
- 运行档案结果未知：保留已确认资产；重读后提示避免重新导入或重复关联。
- 运行档案明确失败：保留已确认资产和服务端请求编号；重读后指向现有“关联运行档案”恢复入口，无需重新导入。

## 变更边界

- 已改生产 Vue：登录链捕获发起页访问代次；离页后资产成功仍继续既定档案 POST；成功、未知和部分成功统一进入页级结果结算，并按需要重读事实。
- 未改 API 地址、方法、字段、两段顺序、幂等规则、权限、数据库、加密、环境变量或依赖；OpenAPI、`.env.example` 与迁移不适用。
- 明确资产失败且未确认写入时不发起档案 POST；明确档案失败仍重读，因为资产已确认保存。未知结果不自动重提。
