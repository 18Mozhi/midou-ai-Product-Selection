# P43 用户管理 C 方向生产实施

## 已实施

- 用户详情采用桌面蓝色账号身份/分区导航与白色滚动工作区；组织关系、平台角色、登录安全三部分可就地导航。手机改为单列内容，并将关闭详情操作固定在底部可达操作区。
- 用户创建、角色授予/撤销、组织关联、停用/恢复、改密和会话撤销继续使用既有字段、校验、请求与原因确认流程；没有新增 API、数据字段、权限规则或依赖。
- 创建与密码操作继续隔离旧窗口/旧路由的迟到结果；历史审核预览适配器在识别当前生产 C 结构时直接验证真实组件，避免把历史变换重复套用到当前模板。
- 组织关联样例缺少组织 ID 时明确提示资料不足，不推断组织资格，也不将其显示为已授权。

## 组件边界

- `PlatformAccountCenter.vue` 仍负责用户/管理员模式、路由、读取与数据动作接线；本批仅为用户/管理员模式添加独立 C 样式作用域。
- `PlatformUserDetailDialog.vue` 负责身份、分区导航、组织关系、角色、会话与详情操作呈现。
- `PlatformAccountDialogs.vue` 负责既有创建与改密弹窗的 C 方向上下文和布局，不改变提交合同。
- 预览辅助脚本和既有测试适配为当前生产 C 模板；E2E覆盖桌面/手机布局及账号动作入口。
