# P48 · 配置历史与回滚实际 Vue r1

## 本批范围

以真实 ProviderSourceCenter、ProviderSourceConfigurationDialog、配置版本类型和 M03-07 版本夹具为准，对“版本与回滚”任务窗做隔离评审实现。覆盖读取中、完整历史与差异、回滚原因不足、无可见差异和空历史五种状态。审核宿主只精确替换实际子 SFC 并注入专属 CSS；**生产 SFC、回滚 API、数据库、权限、环境、依赖和线上数据均未改，未部署。**

pbakaus/distill 用于压缩版本判断路径：来源身份、当前版和历史数量留在蓝色标题区；正文只保留安全说明、按需出现的恢复原因和一条版本时间线，不再把每项差异堆成多层卡片。

## 版本阅读与恢复

- 历史按一条纵向时间线排列；当前版本使用蓝色节点和“当前使用”，历史版本使用明确的“恢复第 N 版”。
- 四类允许展示的差异改为可读值：分钟、毫秒、次数和启用/停用；空旧值统一显示“未设置”。
- 版本没有可见差异时显示“与上一版本的可见采集设置一致”，不伪造变化。
- 加载、空历史时不显示没有作用的回滚原因；存在可恢复版本时才要求填写 2–500 字原因。
- 恢复按钮在原因少于 2 字时禁用；说明明确恢复会追加新的当前版本，不删除或覆盖历史。
- 顶部安全说明明确排除凭证、Cookie 和受限配置，未扩展服务端允许展示的字段。

## 模态与键盘

- 打开后标题获得焦点，背景进入 inert，Tab/Shift+Tab 在窗内循环。
- Escape 与两个关闭按钮关闭任务窗并把焦点归还“版本与回滚”触发点。
- 回滚进行中禁止关闭；代表按钮和原因框高度至少 44px，390/760px 使用全高单列布局。
- 强制色模式保留任务窗、隐私说明和版本差异边界。
