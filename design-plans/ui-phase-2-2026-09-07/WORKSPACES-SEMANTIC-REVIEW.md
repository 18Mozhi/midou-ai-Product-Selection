## 操作核对

| 区域 | 真实行为 | 细化时必须保留的边界 |
| --- | --- | --- |
| 刷新/重试 | summary 与工作区 GET；失败重试不绕过权限 | 父传给工作区的 busy 仅为 busy，不包含 refreshing；不能套用 P31 规则 |
| 创建入口 | 头部与空目录两入口；展开后聚焦名称 | 头部受 busy 禁用，空目录入口没有同样绑定；打开不清草稿 |
| 创建/取消 | trim 名称、slug、原因后交父函数；createBusy 防重复 | 取消只受 createBusy；失败保留，成功清空/收起；字段在等待时仍可编辑 |
| 三状态/重置 | 只筛已返回列表；筛选变化回第 1 页 | 重置清 query/status/sort，不清当前选择或创建草稿 |
| 选择与分页 | 每页 8 条，详情按完整数组找所选项 | 筛掉当前项仍保留详情；前后页没有新 GET |
| 归档/恢复 | 按所选状态确定 archive/restore，等待原因，再传版本化 POST | 活动默认项 UI 禁用且后端另有保护；没有删除/编辑工作区接口 |
| 团队/默认设置链接 | 分别进入 /org-admin/teams 与 /org-admin | 不直接更改会话工作区或组织默认值 |
| 技术详情 | 原生 details 展示 id/slug | 不计作弹窗、复制或业务写入 |

18 个动作的 108 个代表六态槽仍为未映射。导航与不呈现的禁用/忙碌状态需按真实属性另行分类，不能先画出禁用状态再反推行为；归档/恢复及头部/空态的额外变体仍须分别展开。

## 字段与组合

父层 6 个 v-model 属于 P29，明确排除于 P32 展示。P32 五个模型是 form.name、form.slug、form.reason、query、sort；另有共享原因输入，不混入本地五模型统计。

- 名称 required/120；slug required/63 且小写字母数字连字符、首尾非连字符。服务端会 lowercase，但浏览器 pattern 拒绝大写，不能冒称前端自动转小写。
- 创建原因 required/500，提交 trim；共享归档/恢复原因 trim 至少 2 字且前端没有 maxlength，服务端上限 500。旧 C 稿的 500 字保护是提案，不是当前前端事实。
- 查询仅 name/slug，不扩到 UUID、版本、成员数；排序三项固定为 name_asc/members_desc/updated_desc。
- 3 个源码容器：父层排除的资料 form、共享原因窗、工作区内联创建 form。16 个上下文引用不是 16 个弹窗。归档/恢复为同一个窗的两种业务调用。

## 定向证据与未修现状

新增 9 项永久单测。登记测试拒绝漏项、伪批准、缺手机图与过期源码；字段/容器按 AST 完整核对；函数 prop 名称变更会失败。实际函数以隔离 refs/computed、显式 watch 回调执行，证明搜索范围、筛掉选择后保留、空目录展开、trim 三字段、重复/取消保护与失败保留。不是挂载 Vue 响应性、原生表单有效性、真实网络或数据库证明。

另两项特征复现（不是修复证明）：创建成功会清除等待期间后来编辑的草稿；workspaceAction 在等原因前捕获 action、等原因后读取原对象的 id/version，因此原对象在期间被修改时会混用先前 action 与后来的 version。用户尚未明确相关策略，本批不改生产行为或安全边界。真实列表对象通常如何替换、跨组织上下文与完整请求生命周期仍须实测，不能由隔离可变对象测试推断发生频率。

最小验证曾因错误沿用 P31 的 busy || refreshing 假设失败；真实 P32 绑定为 busy，已按实际代码纠正测试预期并复验，不修改产品去迎合假设。
