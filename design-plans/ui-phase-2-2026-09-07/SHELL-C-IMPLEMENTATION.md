# NavigationShell C 方向生产接入

日期：2026-09-28。依据已审核的 C 导航壳构图与全阶段视觉授权，将共享成员、组织管理员、平台管理员导航壳接入真实 Vue。旧 `SHELL-VUE-C-PLATFORM-REVIEW.md` 仍是历史隔离预览证据；它的生产源码哈希不代表本次实现，历史图片未改写。

## 实际变化

- 桌面使用蓝色授权菜单侧栏与白色顶栏/工作区；当前菜单组展开，菜单名称、服务端授权过滤和目标路由仍来自既有 NavigationShell 代码。
- 收紧标题与范围条，移除旧页码/SIGNAL LEDGER 装饰和没有探针依据的“已连接 · 可复核”文案；不改页面事实、健康数据或权限结论。
- 840px 及以下使用同一个原生 `dialog` 导航树和四入口加“更多”底栏。抽屉打开时首焦关闭按钮、Tab/Shift+Tab 在真实可见焦点项间循环、Escape/关闭恢复焦点；切换到桌面时关闭模态并回到仍可见的品牌入口。
- 把菜单焦点枚举中的折叠 `details` 后代排除，避免几何上有矩形但不可聚焦的隐藏链接充当焦点环绕末项。
- 手机底栏标签使用16px文字与现有至少44px触控目标。P47 运维子导航在窄屏横向滚动，避免第二条纵向侧栏。

## 保持不变

`/me/navigation` 请求、登录/壳层守卫、服务端角色和能力过滤、路由/面包屑/主操作目标、KeepAlive 缓存策略、页面 API 和数据均未改。没有 API、OpenAPI、数据库、环境变量、依赖、RBAC 或持久化变更。未将本地夹具或静态资源检查描述为真实角色/业务验收。

## 验证

- `tests/unit/ui-phase2-shell-vue-preview.test.mjs` 验证生产 SFC 编译、唯一导航 DOM、现有权限/页面/操作入口及历史预览隔离。
- `tests/e2e/m02-03-navigation-shell.spec.ts`：desktop Chromium 23/23 与 mobile-390 23/23；覆盖成员、组织和平台壳、菜单搜索/空结果、四入口+更多、原生抽屉焦点循环/Escape/返焦/断点切换、文案/控件尺寸、深链与回跳。页面请求使用现有本地 fixture。
- Playwright 当前壳层截图基线已更新，分别对应本次实际生产 Vue。历史审核图与源哈希保持不变。

仍未由本批证明真实登录与 RBAC、生产探针、数据库或全部73页面/动作的正式签收；共享壳层 C 接入只完成 UI 全站基线的一部分。
