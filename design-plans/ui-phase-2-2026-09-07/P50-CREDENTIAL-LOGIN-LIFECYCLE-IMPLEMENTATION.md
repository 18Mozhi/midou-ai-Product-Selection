# P50 · 登录材料生命周期实际 Vue 实施 r1

## 本批范围

在当前 `CredentialAssetCenter.vue` 中修复登录材料的异步归属和两段写入反馈，并以真实 App、ProviderRuntimeSurface、CredentialAssetCenter 与 M03-02 合同做隔离回放。生产 Vue 的交互逻辑已修改；C 方向蓝白视觉仍由审核宿主注入，不作为已部署样式。**未调用真实浏览器助手、后端加密、数据库或生产环境，未部署。**

`wshobson/interaction-design` 用于约束异步反馈：材料读取可取消且只归属于当前窗口/来源/方式；两段保存进行中不可关闭或换目标；网络中断导致结果未知时不允许直接重提，以免重复创建资产。

## 七种生命周期状态

- 来源切换清空：已准备的文件材料在切换到第二来源后立即失效，文件提示恢复默认，保存禁用。
- 文件迟到结果隔离：读取未结束时关闭，再打开并切换来源；旧文件完成后不能回填新窗口。
- 助手迟到结果隔离：助手请求发出后关闭，再打开并切换来源/方式；旧助手成功消息不能启用新窗口保存。
- 凭证资产保存中：标题关闭、取消、来源、方式、文件/外部入口和提交全部锁定，主按钮明确显示当前保存阶段。
- 凭证资产结果未知：提示“可能已经保存”，要求关闭并刷新核对，禁止重新导入或重复提交。
- 运行档案结果未知：明确资产已保存、第二段结果未知，禁止重新导入或直接重复关联。
- 运行档案明确失败：明确资产已保存但档案未创建，指向“刷新数据 → 关联运行档案”的既有恢复路径，不再创建资产。
