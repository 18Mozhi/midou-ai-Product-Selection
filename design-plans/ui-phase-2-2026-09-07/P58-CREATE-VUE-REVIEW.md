预览转义连字符后拒绝三种非法样例，并接受小写、数字、连字符、下划线。源码正则语言等价测试
含 80/81 字符边界。生产尚未修复该原生约束；服务校验未改变，也未执行真实提交。

首次验证错误地假设末控件一次 Tab 即回关闭按钮，实际不成立。保留原生路径观测：baseline
正反向均 BODY → BUTTON；可滚动 review 正向 BODY → DIALOG → BUTTON，反向 DIALOG → BODY → BUTTON。
浏览器焦点与文档焦点不能混同，这里只证明三站以内重新到原控件；不是严格焦点闭环通过。
Escape 与取消均关闭并回原入口，打开仍为原生 modal；没有新增键盘拦截或改共享模态。

保存中、提交错误的窗内可达性、旧写结果归属、实际创建/版本/幂等/审计、软键盘、完整主题密度、
