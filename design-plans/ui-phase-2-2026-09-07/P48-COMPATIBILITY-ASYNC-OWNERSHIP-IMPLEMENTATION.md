# P48 兼容矩阵读取归属实施

2026-09-28，修正来源兼容矩阵只读请求的迟到响应竞态。`ProviderSourceCenter` 为每次打开矩阵分配操作代次，并同时校验当前代次与 provisioned source ID；关闭对话框和组件卸载都会使在途结果失效。成功、失败和 `finally` 反馈只允许当前矩阵操作更新，避免旧响应替换新来源矩阵/错误/request ID，或清除新读取的忙碌状态。

没有取消或重放 GET，也没有改变 `/platform/provider-adapters` 请求、响应字段、来源启用规则、权限、数据库或外部接口合同。关闭后再次打开仍发起既有只读 GET。

验证：兼容矩阵关闭/重开竞态新增两个 Playwright 实际 Vue 场景，分别验证旧成功不能覆盖新来源成功矩阵，以及旧成功不能覆盖当前 409 错误追踪。桌面 Chromium 每个场景通过；390px 手机每个场景通过。完整 `tests/e2e/m03-07-provider-sources.spec.ts`：桌面19通过、1条既有跳过；手机20通过。`npm run typecheck:web` 通过。场景响应全部由 Playwright 本地拦截生成，不证明生产 RBAC、MySQL、真实页面观测或正式 M07-03 验收。

本修复仅关闭兼容矩阵弹窗关闭/重开这一读取归属缺口；其他 P48 异步生命周期、SC48/PR-G01、真实权限/来源验收和全73页收官继续开放。
