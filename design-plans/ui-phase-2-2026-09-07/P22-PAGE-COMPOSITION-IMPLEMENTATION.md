# P22 成本规则 C 方向生产实施

## 范围

本批将蓝白成本规则工作台迁移到真实 `/sourcing/cost-rules` 与 `CostRuleConsole`：身份与准备度、规则版本目录、显式费用、汇率依据、审批链、详情与动作区。

## 保留运行合同

- 保留 `GET /cost-rules` 及既有筛选、选中项、分页、角色与能力检查。
- “生效”只表示费用版本处于有效状态，不等同于单次机会成本或利润门槛通过。
- 费用、费率、生效日期和来源事实显式呈现，不用默认零值掩盖缺失数据。
- 审批、发布、回滚继续沿用现有状态、角色和 `expected_revision` 约束；本批不新增 API、数据库结构或权限规则。

## 实施内容

- 启用 `cost-console--review` 作用域，并将页面主标题提升为唯一 `h1`。
- 以蓝色标题区、白色/浅蓝色台账区、扁平控件、明确焦点和移动端单列布局重构成本规则页面。
- 保留现有生产组件和数据绑定，仅调整页面编排、层级、状态和响应式样式。
