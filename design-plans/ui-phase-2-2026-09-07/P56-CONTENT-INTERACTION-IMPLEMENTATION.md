# P56 · 内容审核 C 方向交互实现

日期：2026-09-12
路由：`/platform-admin/content`
状态：真实 Vue 已实现并完成本地夹具验证；视觉项按用户统一授权通过；真实 MySQL/RBAC/审计与完整生产验收待办。

## 实现结果

- 用深蓝三步审核路径、钴蓝页面身份和冷白事实台账替换旧的通用标题、KPI 卡片与同款表格结构。
- 桌面以主题、组织/工作区、市场、信号/来源、热度/置信度、状态和审核动作组成七列台账；手机以摘要进入同一记录的完整事实，字段不缩水。
- 筛选草稿、已应用条件、成功快照和当前请求目标分离；刷新、翻页或筛选等待时仍明确旧快照范围，失败不把草稿冒充已应用条件。
- 空目录与筛选无结果分开；筛选无结果仍保留同查询的五项状态统计。首次权限拒绝使用温和说明且不展示旧内容。
- 审核窗冻结记录、目标状态、原因和版本。原因仍为 trim 后 2–300 字，同状态提交继续允许；不新增正文编辑或归档写入。
- 审核提交单飞，旧请求不能关闭后来打开的窗口；错误保留在当前窗口，未取得 HTTP 结果时提示先重读，写成功但列表刷新失败显示双结果。
- KeepAlive 离页中止读取并失效旧回包，返回页面后只执行一次新读取；已发送 PATCH 不因关窗或离页被误称取消。

## 动作闭环

[action-reviews/P56.json](action-reviews/P56.json)把13个专用组件源位置归并为7组：

| 动作         | 范围                                      |
| ------------ | ----------------------------------------- |
| CT56-LOAD    | 顶部刷新与首次失败重试                    |
| CT56-FILTER  | 打开筛选、应用、重置及空结果清除          |
| CT56-REVIEW  | 桌面/手机记录进入审核，冻结当前记录与目标 |
| CT56-PAGE    | 上一页、下一页与服务端页码收束            |
| CT56-TRACE   | 展开本次读取追踪编号                      |
| CT56-CANCEL  | Escape、顶部关闭和底部取消                |
| CT56-CONFIRM | 原因校验、单飞 PATCH 与当前窗口结果归属   |

另有5个父级/共享转发候选在[内容、通知与接口证据合同](content-notification-evidence-contract-review.md)显式绑定，不重复计为业务动作。页面没有正文编辑、归档写入或删除；API 路径、请求字段、权限、SQL、事务与审计合同未改。
