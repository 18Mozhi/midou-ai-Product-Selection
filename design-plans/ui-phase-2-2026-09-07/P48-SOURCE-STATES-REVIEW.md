# P48 · 来源目录首次读取状态实际 Vue r1

## 本批范围

以当前真实路由 `/platform-admin/providers/sources`、ProviderRuntimeSurface → ProviderSourceCenter、现有 HTTP 状态映射及 M03-07 的 146 条权威 fixture 为准。本批覆盖读取中、空目录、登录失效、权限不足、请求频繁、依赖不可用和普通失败七种首次读取状态。Vite 只在审核宿主中精确变换当前 SFC 并加载 P48 状态 CSS；**生产 SFC、脚本、API、权限、数据库和数据均未改，未部署**。

pbakaus/clarify 用于按“发生了什么 → 可以做什么 → 必要技术信息”收敛文案，避免重复提示和内部错误码成为主信息；jakubkrehel/better-accessibility 用于稳定 `aria-live` 宿主、原生按钮/详情、44px 目标、键盘激活和恢复焦点。

## 状态与恢复

- 首次读取只说明正在获取来源、准备状态和最近采集信息，不虚构百分比、阶段或完成时间，也不显示空的统计/筛选区。
- 空目录明确“读取成功但没有来源”，与失败、权限拒绝和筛选无结果分开；提供“重新加载目录”。
- 登录失效提供“重新登录”，进入项目已验证的 `/login`，不再次请求来源目录。
- 权限不足采用温和措辞“当前权限还不能读取这些内容”，并允许权限调整后重新加载；没有暗示用户当前可以自行提权。
- 429 与 503 延续现有 `blocked` 映射和三次安全 GET 重试，但分别显示“请求较为频繁”和“依赖服务暂时不可用”；500 独立为读取失败。
- 请求编号只在“技术详情”中渐进展示。除登录失效外，键盘触发恢复时焦点先移到持续页面标题；恢复 146 条目录后保持该焦点。失败状态不再同时显示全局消息和状态内重复消息。
