# P23 导出任务视图 C 方向实施

## 范围

将 `/tasks?view=exports` 的既有异步导出目录接入 P23 的蓝色说明区、白色结果区与窄屏单列结构。此处是导出状态目录，不是创建/下载流程。

## 组件边界

- `TaskWorkspace.vue`：继续持有路由视图、导出读取、权限判定、读取代次和错误状态；把已读取的数据及现有时间格式函数作为 props 传入。
- `TaskExportJobsPanel.vue`：只呈现导出记录、状态说明、报表中心导航与空态；没有 API 调用、写入或本地副作用。

## 保留的运行合同

- 保留工作区原来的 `GET /report-exports`、`report:read` 可见性与 `view=exports` 查询参数。
- 保留服务端导出状态、类型、排队位置/估算时间与 `updated_at` 的原始语义。
- 保留每条记录和空态跳转到现有 `/reports` 的链接；不增加生成、重试或下载入口。
- 未改 API、OpenAPI、数据库、环境、依赖、权限及报表行为。

## 实施内容

- 桌面目录采用状态、类型/下一步、更新时间、入口分列，状态使用文字标签，不靠颜色单独表达。
- 手机目录将同一记录改为单列卡片，保留完整说明和 44px 导航目标。
- 空态明确说明目录用途，并提供报表中心入口。
- 通过 typed props 将展示职责从仍负责路由和异步请求的 `TaskWorkspace` 中分离。

## 验证范围

E2E 使用本地夹具，不代表真实导出任务、权限或下载成功。定向导出用例桌面/手机各 2/2；完整 M05-01 桌面 Chromium 与 390px 手机各 22/22。另有业务单测 3/3、Web 类型检查与生产构建（541 modules）、前端预算（202 assets）、静态分析（447 files）、文档/路由（73 routes）、运行文档和格式门通过。浏览器核验成功/等待重试/过期状态、链接目标、空态、44px 操作高度和页面宽度。
