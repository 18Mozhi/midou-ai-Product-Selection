# P26 通知中心 C 方向生产实施

## 范围

本批将已审核的蓝白通知收件箱迁移到真实 `/notifications` 页面与 `NotificationCenter.vue`：通知范围标题、实时连接状态、摘要、分类/处理状态筛选、消息目录、详情抽屉和通知偏好窗。

## 保留的运行合同

- 通知目录、摘要和偏好继续使用既有读取路径与实时事件流。
- 详情继续调用 `GET /notifications/{id}`；未读详情仍按既有版本合同执行已读动作，已读详情不会产生自动写入。
- 开始处理、关闭、重新打开、全部已读和偏好保存继续使用现有动作字段、版本字段与权限错误状态。
- 本批不新增 API、数据库字段、Worker、SSE 事件或权限规则。

## 实施内容

- 在生产组件上启用 `notification-center--review` C 方向作用域，并将页面主标题升级为单一 `h1`。
- 统一蓝色标题区、白色摘要/筛选/列表、浅蓝详情事实区、零圆角控件和键盘焦点样式。
- 补齐桌面四列摘要、移动双列摘要、详情抽屉及通知偏好窗的响应式布局。

## 验证证据

- `node --test tests/unit/notification-page-preview.test.mjs`：通过。
- `node scripts/verify-notification-page-preview.mjs --capture-review r2`：1440/390 各 4 项检查通过，生成默认与详情双端 4 张审阅图，零自动写入。
- Web 类型检查、格式检查、生产构建与宝塔部署在本批提交前完成。

真实会话、RBAC、未读自动已读、处理动作、偏好真实持久化、SSE 稳定性、分页/异常、读屏完整回归和正式 M07-03 生产证据不在本批假设为已验收。
