# P50 · 凭证与网页登录实际 Vue 首批布局 r1

## 本批范围

以真实 App、ProviderRuntimeSurface、CredentialAssetCenter 与 M03-02 E2E 合同为准，对 P50 默认凭证页和“配置网页登录”默认操作面进行隔离评审。浏览器使用真实路由和未改写的生产 SFC，只在审核 Vite 宿主中注入 P50 专属 CSS；**生产组件、事件、API、权限、加密、数据库、扩展、环境与依赖均未改，未部署。**

`dammyjay93/interface-design` 用于锁定凭证保管场景的层级：平台安全管理员先确认来源覆盖、加密资产和运行档案，再进入一次明确的网页登录导入任务。蓝色只承担页面身份、来源边界和主动作，白色连续台账承载事实；不沿用旧版渐变卡片墙和四个无差别主按钮。

## 页面与操作面

- 顶部深蓝身份区明确“平台安全资料库”，页面说明继续保留“密码和登录状态不会回显、采集任务只能临时使用”的真实边界。
- “配置网页登录”是唯一白底主动作；下载助手、关联档案和新建通用资产降为同级描边动作，刷新与最近读取时间独立放置。
- 三项概要改为一条连续事实栏；资产用一行保管台账呈现来源、指纹、密钥/资产版本、轮换和有效期，轮换与撤销就近但不抢主任务。
- 运行档案和兼容矩阵各为连续白色分区。兼容状态仍只按现有来源绑定、资产有效期与运行档案状态计算，没有改称真实登录或采集健康。
- 登录操作面桌面采用“蓝色格式说明 + 白色来源/方式/文件/来源确认”，移动端按同一 DOM 顺序转为单列；底部取消和“加密保存并启用”始终可见。
- 默认未选择文件时保存按钮保持禁用；三种原有方式、来源选择、文件输入、外部登录页入口和现有文案均未改。
