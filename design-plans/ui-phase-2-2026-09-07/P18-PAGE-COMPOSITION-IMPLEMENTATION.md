## 2026-09-28 · 决定窗迟到回执隔离

决定 POST 回执绑定提交时的决定窗代次；用户关闭并重新打开决定窗后，旧成功回执不得关闭新窗。机会详情离开/停用时，旧写入回执不再更新当前页的忙碌状态、提示或追踪编号；并发写入以当前页面代次计数，避免先完成的请求提前解除仍在途请求的忙碌态。旧 POST 不会被取消，成功仍按现有流程重读机会，未改变 API、原因、版本、权限或决定业务规则。

受控 Vue E2E 覆盖旧决定成功不关闭新窗口，桌面 Chromium 与390px各1/1。证据只覆盖本地延迟响应；其他详情子面板、真实组织/工作区/RBAC、生产写入及 M07-03 仍未验收。

## 2026-09-28 · AI 排队回执遵从当前页签

AI 分析 POST 在途期间若用户主动切换到“结论”等其他分区，成功后仍正常刷新机会并提示任务已排队，但不再强行切回 AI 分区。以提交时的页签意图代次判定是否仍可自动打开 AI 页；未改变 API、队列副作用、权限或事实数据。

受控真实 Vue E2E 在桌面 Chromium 与390px各1/1；本地 POST 回执只证明交互归属，不代表真实 Worker 完成、AI 结果、RBAC 或生产验收。

## 2026-09-28 · 机会弹窗键盘边界

真实 Chromium 回归首次发现原生机会对话框从首个关闭按钮按 Shift+Tab 时未回到末尾操作控件。为 ERP 导入、手工创建、人工决策三类本地弹窗增加 P18 范围内的显式 Tab / Shift+Tab 边界循环；Escape、取消、表单字段、提交 handler、权限与请求合同不变。

机会决定的观察/驳回变体，以及 P15 创建、ERP 导入调用方在桌面和390px移动端通过回归；Escape 关闭决策窗后焦点回到原触发按钮，取消不发送决定 POST。局部 E2E 是浏览器键盘证据，不等同于屏幕阅读器、真实 RBAC 或生产验收。

## 2026-09-28 · 成本复核人读取失败与 GET 重试

成本复核人目录读取现在拥有独立 loading/ready/error 状态。失败不再静默显示为空选项，而是在字段旁呈现服务端操作提示和追踪编号；成功返回空数组会明确显示“当前没有可选成本复核人”。仅在当前详情/读取代次下可重试 `/cost-input-reviewers`，且复核人未就绪或无候选时成本提交禁用；重试不触发任何写入，也未改变 API、权限或资格规则。桌面 Chromium 与390px真实 Vue回归均验证默认安全GET重试耗尽后展示错误、禁用提交、显式只读GET重试成功及名单恢复。真实RBAC/SQL/资格与生产验收仍需独立证明。

## 2026-09-28 · 成本复核内联表单随快照失效

成本复核原因表单现在保存打开时的 review ID 与记录版本；刷新后记录消失、变为不可复核或版本改变时，立即关闭表单并清除尚未提交的原因。提交 handler 再校验条目可复核、ID 和版本一致，事件继续携带打开表单时的 `expected_version`。没有改写入 URL/body、权限、复核资格或服务端状态机。`tests/e2e/m04-04-profit.spec.ts` 成功复核场景在重读后断言表单已关闭、旧“通过”入口消失且最新记录 `data-status=approved`；完整 M04-04 E2E 桌面 Chromium 与390px手机各10/10通过。响应由本地夹具控制，不证明真实 RBAC、数据库并发结果或正式 M07-03。

## 2026-09-28 · 成本观测时间本地时区

成本 `observed_at` 默认值现在用浏览器当前 `getTimezoneOffset()` 转为本地 `datetime-local` 文本，保留到分钟；既有提交转换 `new Date(value).toISOString()` 仍保留原 API 语义。Asia/Tokyo 实际 Vue E2E 检查默认值距当前时刻小于两分钟，并断言 POST 的 `observed_at` 等于该输入所代表的 ISO 时刻。未改业务时间范围、其他日期字段、历史数据或 API；服务端跨时区规则与真实提交验收仍待。

## 2026-09-28 · 状态恢复按钮归属

机会详情状态面板不再让所有主按钮统一触发 `load`。`expired` 的“重新登录”进入既有 `/login`，携带 `authentication_required` 和当前详情完整路径；`empty`、`forbidden`、`not_found` 使用明确的“返回机会列表”；`error`/`blocked` 保留主重试，并把次动作绑定为返回机会列表。无权态不再显示没有对应工作流的“申请权限”。共享 `UiStatePanel` 仅增加可选 `hideSecondary` 显示参数，默认消费者行为不变；未新增路由、API、权限或业务申请流程。

新增 3 条实际 Vue Playwright：401 登录重定向、403 单次读取后返回列表、503 安全 GET 自动重试耗尽后显式重试。`M04-02` 桌面 Chromium 与 390px 手机全套各 21/21，`npm run typecheck:web` 通过。夹具不证明真实认证、权限、数据库或 M07-03；P18 的决定/成本/AI真实写入、跨组织权限和其他全站验收仍待。

## 2026-09-28 · 利润读取失败保持详情可用

机会详情读取成功而利润分析 GET 失败时，错误现在局限在“利润与成本”面板，显示服务端操作提示与追踪编号，并提供只重试利润 GET 的入口；已成功读取的旧利润快照在显式重试失败时保留。切换机会/新一轮详情读取会清空利润快照以隔离数据归属。利润 401 仍进入现有登录过期页面；其它利润读取错误不再遮蔽机会详情。M04-02 定向实际 Vue E2E 桌面 Chromium/390px 共4/4通过，覆盖503局部错误与 GET-only 恢复以及401全页过期态。无 API/OpenAPI、权限、数据库或写入合同变化；本地响应夹具不证明真实权限、数据库或 M07-03。

## 2026-09-29 · 分析事实三分区真实 Vue 接入

将 INSIGHTS-C-r1 的概览关联/评分、市场、竞争、风险工作面接入真实 `OpportunityDetailInsights.vue`。竞品和供应候选的 GET、读取状态、失败恢复分别呈现；单一数据源失败不会遮蔽另一来源，重试只重新读取所选来源，失败时清空该来源旧计数/明细。竞品仅筛选当前机会关联记录，最近快照明确区分零值与缺失值。市场只显示接口已有证据/来源总数与覆盖状态；风险等级与覆盖状态分开，不编造逐项风险事实。

新增挂载 Vue 的 M04-02 回归覆盖供应读取失败但保留竞品事实、供应单源 GET 恢复、竞品/供应无权限时不发请求，以及市场/风险事实边界；定向测试桌面Chromium与390px手机各2/2通过。未改 API/OpenAPI、权限、数据结构、配置、依赖及业务写入。夹具验证不代表真实 SQL/RBAC、外部采集或 M07-03 生产验收；P18 AI、血缘、经营复盘与其余操作状态仍未完成。
