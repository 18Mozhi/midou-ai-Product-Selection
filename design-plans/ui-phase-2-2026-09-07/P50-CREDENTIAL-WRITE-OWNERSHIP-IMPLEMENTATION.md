# P50 · 通用凭证写入归属实际 Vue 实施 r1

## 本批范围

修复新建凭证、更新资料、关联运行档案和撤销资产在离开 `/platform-admin/credentials` 后仍把迟到回执写回缓存实例的问题。生产 `CredentialAssetCenter.vue` 已将四类写入绑定到发起页面、编辑器/撤销目标和操作代次；共享 `ConfirmDialog.vue` 增加默认关闭的 busy 与状态反馈能力。**写请求不会因离页取消或自动重放；未访问真实后端、加密、数据库或生产环境，未部署。**

`wshobson/interaction-design` 用于约束可中断反馈：长写入必须明确等待和锁定，离页只终止本地编辑会话，不虚构服务器写入已取消；返回后的反馈以原请求结果和重新读取事实为准。

## 已实施行为

- 四类写入捕获页面访问代次、编辑器代次与提交目标；迟到回执不能关闭或清空后来打开的界面。
- 写入等待期间，刷新、配置登录、关联档案、新建、更新、撤销及空态创建入口禁用；返回缓存页显示“上一项仍在等待服务器响应”。
- 离页后的成功回执重新读取三项凭证事实，再显示“已完成”；网络结果未知也重新读取，并明确要求核对后再操作。
- 离页后的明确 HTTP 失败不发起无意义重读，保留服务端 `action_hint` 与请求编号作为页级恢复提示。
- 当前档案编辑失败继续保留字段并在弹窗内显示反馈；撤销请求发出后取消、重复确认和 Escape 均锁定，失败后恢复原确认内容并显示红色错误区。
- `ConfirmDialog` 的新增属性均有安全默认值，未传入的其他十个调用方行为不变。
