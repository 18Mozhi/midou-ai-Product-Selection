# P50 · 登录材料六状态实际 Vue 评审 r1

## 本批范围

在 P50 首批蓝白布局上，以真实 App、ProviderRuntimeSurface、CredentialAssetCenter 和 M03-02 E2E 合同验证三种既有导入方式的材料反馈。审核宿主精确变换真实 SFC 并注入隔离 CSS；**生产组件、API、权限、加密、数据库、浏览器助手、环境、依赖和线上数据均未改，未部署。**

`wshobson/interaction-design` 用于把反馈分为“校验失败 / 正在读取 / 材料就绪”，并保持动作可取消、状态可理解、材料不回显。浏览器助手读取不再借用“加密保存中”标签；读取期间锁定来源、方式、外部页面和重复读取，但取消仍可用。

## 六种状态

- Cookie 文件已就绪：显示文件名和“内容不会在页面回显”，保存按钮可用。
- Cookie 文件格式错误：保留原 `.json/.txt/.cookies` 校验文案，保存继续禁用。
- 浏览器读取中：来源、方式、打开页面和读取按钮锁定，按钮显示“读取中…”，取消可用。
- 浏览器读取成功：只显示 Cookie 数量和下一步，不显示名称、值或 JSON；保存按钮可用。
- 浏览器无可用 Cookie：保留先登录再读取的恢复说明，保存继续禁用。
- 完整档案已就绪：显示 `.tar.gz` 文件名和不回显边界，保存按钮可用。

登录窗内部改为“固定标题 + 独立滚动材料区 + 固定底部操作”。手机长说明、来源确认和反馈增加后，取消及“加密保存并启用”仍位于视口内；桌面继续保持左侧蓝色说明和右侧白色操作区。
