# 平台工作区旧断言纠偏与深链合同复核

2026-09-12。延续 C 方向实施的测试收尾，不改变页面设计或业务行为。

## 失败与根因

修改前定向运行稳定复现两项失败：

1. `platform-completion.test.mjs` 只在旧管理父组件/记录列表查找“审核热点内容”。
   当前父组件已挂载 `PlatformContentCenter` 并把 `review` 交给 `beginReview`；
   实际审核标题位于 `PlatformContentReviewDialog`，父级通过 `reviewItem` 打开、
   `submitReview` 保存。旧测试的组件位置假设过期，不是审核标题丢失。
2. `platform-data-center.test.mjs` 要求数据质量页使用 `params.get`，但当前页面
   从 Vue Router 的 `route.query` 经 `queryValue` 读取，并在初次读取之后调用
   `openInitialDeepLink`。`evidence`、兼容 `evidence_id` 和 `issue_id` 仍存在。
   旧断言把原实现写法误当作深链行为合同。

本次没有为恢复旧测试而把当前组件拆分或路由逻辑改回旧版。

  无关或已不再挂载的源文件中找到相同文案就算通过。保留投递、接收邮箱、采集任务
  状态、图表以及图标名称检查。
- 数据测试保留原状态、20 条分页、超时快照、导出路由/审计/OpenAPI/Feature Map
  断言，更新为当前查询辅助函数，并检查挂载时先读数据、再处理初始深链的顺序。
- 新增 3 项行为单测，借助既有 TypeScript 依赖从实际 SFC 提取并执行
  `queryValue` 和 `openInitialDeepLink`，不是复制一份测试实现。覆盖 12 组输入：
  两个证据键及优先级/空值回退、问题在当前页或不在当前页、缺省/空/非法/非字符串值。
  检查打开的证据编号、目标页签、查询条件和不同提示；不改变当前 ID 校验或扩展匹配。

这是实际函数的隔离合同测试，不宣称完整 Vue Router 生命周期、真实 API、权限或数据库验收。
