# P73 页面不存在 · 恢复入口规格

状态：已按用户“剩余全部通过”授权自动采纳 C 方向并实施；W02；公开 fallback `/:pathMatch(.*)*`，`NotFoundPage.vue`。依据见[状态与404合同](../state-recovery-contract-review.md)及[实施/部署记录](../P73-PAGE-COMPOSITION-IMPLEMENTATION.md)。独立蓝色恢复说明、当前路径与安全目标区已替代旧轨道/渐变/巨型404；导航记忆、真实权限与 HTTP 状态合同未改变。

## 1. 用户与导航

未登录与已登录访问者均可进入未知地址恢复页。目录标为fallback、notFound=true、shell=null、cachePolicy=none，无本页sessionRequired。404不推断角色、不展示业务导航壳层；恢复目标自身继续按真实会话和权限合同处理。

## 2. 任务与字段来源

唯一任务是说明当前路径不存在并返回已登记入口。requestedPath取route.path，超过96字符显示前93字符加省略号；title仍是完整path，不含query/hash。recentDestination解析导航记忆，解析失败或匹配notFound改为/home。标题取目标meta.title，无标题使用“最近页面”。本组件无API；该结论仅覆盖停留本页，点击去业务页后不能继续宣称零请求。SPA返回404画面不等于HTTP响应码必为404。

## 3. 桌面构图方向

待审新稿以恢复说明和一个主行动为首屏核心，品牌返回为弱入口，当前路径作为次级诊断信息。旧轨道、渐变、巨型装饰404及卡片舞台不默认保留；不把权限不足、网络失败或登录过期混成404。元信息不能抢占恢复动作，不增加搜索接口、联系支持表单或未存在的业务功能。

## 4. 移动构图方向

短标题→原因→当前路径→主行动纵向编排，主次链接触控尺寸一致且视觉分级。长路径截断显示但完整title可核对，不能泄露query；长中文与200%缩放不遮挡。无移动底部业务导航、表单或软键盘交互。

## 5. 动作及条件

NF-BRAND始终RouterLink到/home；NF-RETURN始终存在，目标为recentDestination.fullPath。最近目标path不等于/home时显示“返回最近页面”并增NF-HOME次链接；path等于/home时主链接叫“返回今日行动”，不重复次链接。现有/home带query的主目标仍保留fullPath，不私自统一丢弃。无浏览器history.back按钮，不因旧稿“返回”字样编造该动作。

## 6. 弹窗与校验

无弹窗、表单、提交或撤销行为。getLastValidRoute先拒绝非相对路径及协议相对值，router.resolve再拒绝已注销目标；storage不可用回退/home。只证明当前已测输入，不宣称整个URL清洗面已安全认证。真实敏感路径本身仍可能出现在文本/title，生产截图必须用隔离未知路径，不能仅因过滤query就省略脱敏。

## 7. 状态与权限矩阵

未知短/长路径、无最近目标、合法最近目标、已注销目标、非法存储值、storage读取失败、刷新/前后退均适用。本页没有业务加载、列表空态或接口错误态；到达其他页面后的401/403由目标页负责。生产/ui-states应落在该恢复页且不暴露演示入口，单独留证。

## 8. 状态连续性

mounted和route.fullPath变化后nextTick聚焦h1；正常路由afterEach记忆完整合法目标，notFound不覆盖最近路径。本页计算读取的是导航模块缓存，不直接监听跨标签storage；新的页面加载才重新读存储。刷新仍是未知页，不能假装导航已修复。恢复链接保留真实目的URL，但页面可见文案只露目标标题，不露最近query。

## 9. 响应式与效果

1440/390、768/1024、780邻界、200%缩放和长路径。主行动44px热区、16px正文，焦点环和h1程序焦点保留。新稿独立采用获审令牌，三主题/两密度按适用性验证，不靠CSS隐藏链接代替权限判定。动画非必需且遵循reduced-motion；截图需等待实际字体与样式稳定。
