# P54 证据与质量 · C 方向真实 Vue 实现

状态：实现与本地双端夹具回归完成；视觉依用户 2026-09-24 全局授权自动通过。已随整站构建 `06ae38230de2b5b7a35b89727aa22432387030d5` 上线；`DataQualityCenter` JS/CSS 线上 HTTP 200，SHA-256 与本地构建一致。范围为 `/platform-admin/data` 的“证据与质量”，与“近期记录”共同构成 P54 数据中心；这不等于真实数据库、权限、文件或生产业务验收。

## 实现范围

- 采用“原始证据 → 规范版本 → 字段来源 → 质量问题”的蓝色核对路径；白色工作区分为证据、质量问题和核对运行三个任务，不沿用旧等权卡片布局。
- 平台级计数、当前页保留风险、最近 20 次核对指标和观测时刻分别说明，不把当前页数字包装成全局总量或合成总分。
- 证据完整溯源改为原生 `dialog`，同一响应内分段展示原始证据、规范记录、字段来源、关联质量问题和技术标识；桌面和手机入口共用详情代次、中止、焦点圈定、Escape 与返焦。
- 单问题解决原因改为独立原生 `dialog`；提交前的 `ConfirmDialog` 接收忙碌与失败状态。写入成功与后续列表重读失败分别保留，不互相覆盖。
- 桌面和手机均可选择开放问题；批量预览冻结动作、问题 ID/版本、原因、成员和影响范围。无 HTTP 结果进入未知态，成功重新读取前禁止同一动作重复提交。
- 受控下载按证据单飞；无 HTTP 结果锁定该证据的重复授权，成功重新读取后解除。应用只负责签发授权并发起浏览器下载，不伪造下载后完整性回执。
- `quality_tab`、`quality_page`、`quality_q`、`quality_run` 与 `evidence` 进入路径受限 URL 状态；切换近期记录后返回，质量工作态仍保留。读取和详情分别使用代次与 `AbortController`，KeepAlive 停用时中止等待 GET。
- 控件使用明确禁用、就近说明、礼貌反馈、44px 命中区、键盘焦点和 reduced-motion 约束。
